## 2. 재제작 비용 계산 공식 제안

### 공식 A: 기공소 월간 재제작 손실액 (한국 기준)

```
월간 재제작 손실 = 월 케이스 수 × 재제작률 × (재료비 + 인건비)

구성 요소:
- 재료비 (단위: 원)
  - 지르코니아 크라운: 약 30,000~50,000원/개 (재료 원가 추정)
  - PFM 크라운: 약 15,000~25,000원/개 (재료 원가 추정)
  - 귀금속 (Gold): 국제 시세 연동, 약 80,000~150,000원/개
- 인건비 (단위: 원)
  - 기공사 평균 시급: 약 18,000~21,000원 (연봉 3,765만원 ÷ 2,080시간)
  - 크라운 1개 제작 시간: 8시간 (총 공정, 대기시간 포함)
  - → 크라운 1개 인건비: 약 144,000~168,000원
```

**예시 계산 (중소 기공소 기준)**

```
가정:
- 월 케이스 수: 200개 (크라운 기준)
- 재제작률: 10% (국내 평균)
- 크라운 평균 기공료: 80,000원 (기공소 수취 기준 추정)
- 재작 시 재료비+인건비 손실: 60,000원/개

월간 재제작 손실 = 200개 × 10% × 60,000원 = 1,200,000원/월
연간 재제작 손실 = 1,200,000원 × 12 = 14,400,000원/년
→ 연간 기공료 매출 대비 손실률: 약 7.5% (매출 1,920만원 기준)
```

### 공식 B: 기회비용 포함 손실 (더 보수적인 접근)

```
총 손실 = 직접 손실 + 기회비용

기회비용 = 재제작에 투입된 시간 × 시간당 기공료
= (재제작 케이스 수 × 평균 제작시간) × (기공료 / 제작시간)
```

**예시**:
- 월 재제작 20개 × 8시간 = 160시간 소요
- 160시간 동안 처리 가능한 신규 케이스 = 20개
- 20개 × 80,000원 = 1,600,000원 기회비용
- → **총 손실 = 직접손실 1,200,000원 + 기회비용 1,600,000원 = 2,800,000원/월**

### 공식 C: 재제작률 1%p 개선 시 절감액 (세일즈 피치용)

```
1%p 개선 절감액 = 월 케이스 수 × 1% × 단위 손실액
= 200개 × 1% × 60,000원 = 120,000원/월 = 1,440,000원/년
```

## 3. 재제작 원인 분석

### 국내 원인 분류 (치의신보 기준)

| 원인 | 비중 |
|------|------|
| 인상체 및 재료 변형 | **92.2%** |
| 치과에서 부정확한 정보 제공 | 68.6% |
| 기공사 제작과정 오류 | 62.7% |
| 환자 구강 환경 변형 | 40.2% |
| 배달 과정 중 보철물 손상 | 7.8% |

> 복수 응답 방식으로 합계가 100% 초과. 인상체 오류가 압도적 1위.

### 글로벌 원인 분류 (Dandy 설문, n=137 dentists, 2025)

| 원인 | 비중 |
|------|------|
| 부정확한 인상/스캔 | 34% |
| 기공소 제작 오류 | 31% |
| 환자 해부학적 문제 | 12% |
| 기타 | 23% |

### VCAD 케이스 스터디 - 원인 세부 분류

60% 이상의 재제작이 **생산 시작 전 단계**에서 발생:
1. 불완전하거나 일관성 없는 처방전
2. 교합 등록 누락 또는 대합 스캔 불완전
3. 쉐이드(색상) 커뮤니케이션 모호
4. 납품 후 피드백 지연

> **CrownOps 인사이트**: 재제작의 60%+는 운영 관리 개선(처방전 디지털화, 커뮤니케이션 표준화)으로 예방 가능.

- 논문 URL: https://pmc.ncbi.nlm.nih.gov/articles/PMC7005880/
- 샘플: 205명 치과의사, 3,750개 단일 크라운
- **평균 재제작률: 3.8%** (표준편차 5.8%)
- 범위: 0%~42%
- 재제작 케이스 집중: 전체 42%의 치과의사에서 발생
- 주요 거절 이유:
  1. 근심/원심 불접촉 (37건)
  2. 변연 불적합 (34건)
  3. 심미 불량 (28건)
  4. 도재 파절 (23건)
  5. 크라운 부적합 (14건)
- 추정 원인:
  1. 기공소 오류 (46건)
  2. 인상 변형 (24건)
  3. 색상 불일치 (21건)

- 94%가 재제작 경험 있음

## 8. CrownOps 피치용 핵심 메시지

### "Pain Point" 수치화 (투자자/고객용)

> **"국내 기공소는 평균 10%의 재제작률로 운영되고 있으며, 이는 글로벌 평균(4%)의 2.5배입니다. 중소 기공소 기준 월 200케이스를 처리할 때 재제작으로 인한 직접 손실과 기회비용을 합산하면 월 약 280만원, 연간 약 3,360만원의 손실이 발생합니다. CrownOps는 처방전 디지털화와 커뮤니케이션 표준화를 통해 이 손실의 60% 이상을 예방할 수 있습니다."**

### 시장 규모 근거 (TAM/SAM/SOM 산정)

> **기준**: 영업 중 기공소 4,663개소 (공공데이터 확정) × 기공소 1개소 연간 재제작 손실액
> **환율**: USD 1,380원 / EUR 1,510원 (2026.07 기준, 해외 수치 참고용)
> ⚠️ **국내 수치 우선 원칙**: TAM/SAM/SOM은 국내 데이터 기반으로 산정. 해외 수치는 벤치마크 참고용.

| 구분 | 계산식 | 금액 (연간) | 설명 |
|------|--------|-----------|------|
| **TAM** | 4,663개소 × 약 2,800만원 | **약 1,306억원** | 전체 영업 중 기공소 재제작 손실 총합 |
| **SAM** | TAM × 70% | **약 914억원** | 중소형 기공소 (2~10인) 타겟 |
| **SOM** | SAM × 5% | **약 46억원** | 초기 3년 목표 점유 시장 |

> - 기공소 1개소 연간 재제작 손실: 월 200케이스 × 재제작률 10% × (재료비+인건비+기회비용) ≒ **약 2,800만원/년**
> - SAM 70%: 전체 기공소 중 중소형(2~10인) 비중 추정
> - SOM 5%: 초기 3년 누적 목표 점유율
> - 상세 계산은 `(26.07.20) 기공소 리메이크 손실 계산 모델 v2.xlsx` ③ TAM·SAM·SOM 시트 참조
