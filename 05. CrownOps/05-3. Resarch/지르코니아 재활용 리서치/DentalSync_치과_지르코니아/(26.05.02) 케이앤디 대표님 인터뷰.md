# 케이앤디 치기공소 대표님 인터뷰 준비안

**인터뷰 대상:** 케이앤디 치기공소 대표님  
**목적:** 실제 지르코니아 디스크 조각 발생량, 분리보관 가능성, 수거 파일럿 조건, 현장 제약을 확인한다.  
**핵심 태도:** 대표님을 설득하기보다, 기공소가 왜 지금까지 버리는 것이 합리적이었는지 이해한다.

---

## 1. 이번 인터뷰의 핵심 목표

| 목표 | 왜 중요한가 | 반드시 얻을 결과 |
|---|---|---|
| 월 발생량 확인 | 사업 규모와 수거 경제성의 시작점 | 월 디스크 사용량, 조각 발생량 |
| 디스크 조각 분리 가능성 확인 | MVP의 핵심 | 디스크 조각만 따로 모을 수 있는지 |
| 실제 폐기 방식 확인 | 문제 강도와 법규 확인 | 현재 폐기 비용, 폐기 주기, 처리 방식 |
| 파일럿 동의 확보 | 검증 결과를 만들기 위함 | 2주 파일럿, 샘플 kg, 사진/측정 허가 |
| 현장 마찰 확인 | 수거 모델 설계에 필요 | 용기 크기, 위치, 직원 동선, 보상 필요성 |

---

## 2. 인터뷰 전에 공유할 30초 설명

> "저희는 치과에서 쓰는 지르코니아 디스크가 밀링 후 조각과 분진으로 버려지는 구조를 보고 있습니다. 다만 처음부터 분진까지 다루면 오염과 안전 문제가 커서, 이번에는 깨끗한 디스크 조각만 따로 모을 수 있는지부터 확인하고 싶습니다. 오늘은 참여 의향보다 실제 발생량, 현재 처리 방식, 분리보관이 얼마나 귀찮은지 같은 현실적인 데이터를 얻고 싶습니다."

---

## 3. 반드시 얻어야 할 것

### 3.1 숫자

| 정보 | 기록 단위 |
|---|---|
| 월 지르코니아 디스크 사용량 | 장/month |
| 디스크 종류별 비율 | 3Y, 4Y, 5Y, 멀티레이어, 브랜드 |
| 월 남는 디스크 조각량 | kg/month 또는 봉투/통 기준 |
| 월 밀링 분진량 | kg/month 또는 집진기 비움 주기 |
| 현재 폐기 비용 | 원/month |
| 현재 폐기 주기 | 매일/주간/월간 |
| 수거 가능한 최소 주기 | 주 1회/격주/월 1회 |

### 3.2 물리적 조건

| 정보 | 확인 방법 |
|---|---|
| 수거함을 둘 공간 | 현장 사진 또는 위치 설명 |
| 조각과 분진이 실제로 분리되어 나오는지 | 밀링기 주변 관찰 |
| PMMA/왁스/레진과 섞이는지 | 사용하는 재료와 작업 흐름 질문 |
| 금속 버/기타 잡물질 혼입 가능성 | 작업대, 폐기통 관찰 |
| 직원이 분리보관할 수 있는지 | 누가, 언제, 몇 초 걸리는지 확인 |

### 3.3 파일럿 동의

| 얻을 것 | 목표 |
|---|---|
| 2주간 디스크 조각만 모아보기 | 가능/불가능 |
| 샘플 제공 | 최소 500g~1kg 이상 |
| 사진 촬영 허가 | 작업장, 수거함, 조각 상태 |
| 수거량 측정 허가 | 전자저울로 g/kg 기록 |
| 익명 인용 허가 | 발표 자료에 "수도권 치기공소 대표 인터뷰" 등으로 사용 |

## 4. 질문지

### 4.1 현재 작업 흐름

1. 지르코니아 보철 작업은 하루 또는 한 달 기준 어느 정도 물량이 나오나요?
2. 지르코니아 디스크는 한 달에 보통 몇 장 정도 사용하시나요?
3. 디스크 종류는 3Y, 4Y, 5Y, 멀티레이어 중 어떤 것이 많나요?
4. 디스크 조각은 밀링 후 어떤 형태로 남나요?
5. 조각과 분진은 실제 현장에서 따로 나오나요, 아니면 이미 섞이나요?

### 4.2 현재 폐기 방식

1. 지금 지르코니아 조각과 분진은 어디에 모이고 어떻게 버리시나요?
2. 일반 쓰레기, 사업장폐기물, 별도 업체 처리 중 무엇에 가깝나요?
3. 폐기 비용이 따로 발생하나요?
4. 집진기는 얼마나 자주 비우나요?
5. 폐기물 처리에서 현재 가장 귀찮은 부분은 무엇인가요?

### 4.3 디스크 조각만 분리하는 MVP

1. 분진은 제외하고 디스크 조각만 따로 모으는 것이 가능할까요?
2. 가능하다면 어느 위치에 수거함이 있어야 가장 자연스러울까요?
3. 직원이 조각을 따로 넣는 데 몇 초 이상 걸리면 귀찮다고 느낄까요?
4. 조각만 따로 모으면 PMMA, 왁스, 레진, 금속이 섞일 가능성은 얼마나 줄어들까요?
5. 디스크 브랜드나 종류별로 조각을 나눠 모으는 것은 현실적으로 가능할까요?

### 4.4 참여 조건

1. 무료 수거만으로도 충분한가요, 아니면 소액 보상이 있어야 하나요?
2. 수거 주기는 어느 정도가 적당할까요?
3. 수거함은 어느 정도 크기여야 방해가 안 될까요?
4. 수거하는 사람이 지켜야 할 현장 매너나 시간대가 있나요?
5. 이런 활동을 기공소 홍보나 ESG 자료로 남기는 것에 관심이 있나요?

### 4.5 샘플과 실험

1. 오늘 또는 다음 방문 때 디스크 조각 샘플을 받을 수 있을까요?
2. 2주 동안 디스크 조각만 모아보고 무게를 재는 파일럿이 가능할까요?
3. 저희가 세척, 건조, 분쇄, 성분분석 후 결과를 공유드리면 도움이 될까요?
4. 혹시 소결로를 유상 또는 협업 형태로 사용할 수 있는 가능성이 있을까요?
5. 지르코니아 조각을 모을 때 꼭 피해야 할 재료나 상황이 있나요?

### 4.6 마무리 질문

1. 이 아이디어가 현장에서 실패한다면 가장 큰 이유는 무엇일까요?
2. 대표님 입장에서 "이 정도면 해볼 만하다"는 조건은 무엇인가요?
3. 지르코니아 사용량이 많은 다른 기공소나 밀링센터를 소개받을 수 있을까요?
4. 오늘 이야기와 사진/수치를 발표 자료에 익명으로 사용해도 괜찮을까요?

## 7. 절대 조심할 것

| 하지 말 것 | 이유 | 대신 할 것 |
|---|---|---|
| "돈이 될 것 같아서요"만 강조 | 폐기물 거래로 보일 수 있음 | 연구용 검증과 자원순환 파일럿으로 설명 |
| 분진을 맨손으로 만지기 | 흡입/안전 리스크 | 디스크 조각만, 장갑/마스크 사용 |
| 사진을 허가 없이 찍기 | 신뢰 훼손 | 촬영 전 허가 |
| "무조건 사갈 업체가 있다"고 말하기 | 아직 미검증 | "샘플 테스트 가능성을 확인 중" |
| 대표님 의견을 반박하기 | 현장 현실이 더 중요 | 왜 그런지 사례를 요청 |
| 참여 의향만 묻기 | 듣기 좋은 답변이 나옴 | 실제 발생량과 지난 행동을 묻기 |

## 10. 인터뷰 후 바로 해야 할 일

1. 샘플을 받은 경우 날짜, 장소, 상태, 무게를 즉시 기록한다.
2. 조각과 분진을 절대 섞지 않는다.
3. "대표님이 실제로 한 말"과 "우리 해석"을 분리해서 정리한다.
4. 2주 파일럿이 가능하면 수거함 위치와 회수 날짜를 확정한다.
5. 린캔버스의 공급량, 채널, 비용구조, 위험가설을 업데이트한다.
