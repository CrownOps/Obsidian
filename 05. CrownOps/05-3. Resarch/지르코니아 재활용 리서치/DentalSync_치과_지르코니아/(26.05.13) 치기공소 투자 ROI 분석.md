## 3. 월 운영 손익 세부 내역

### 3-1. 매출 측 가정

| 항목 | 값 | 근거 |
|---|---:|---|
| 크라운 단가 (기공소 출고가) | 80,000원/개 | 💭 한국 기공소→치과 B2B 출고가 직접 자료 없음. 환자 단가(50~80만원)와 미국 기공소 가격($30~$42 ≈ 4~6만원) 사이 중간값으로 추론 [출처 1, 4] |
| 월 생산량 (8시간, 가동률 70%) | 808개 | 🧮 사용자 원본 자료 기반 |
| 월 생산량 (24/7, 가동률 70%) | 1,781개 | 🧮 사용자 원본 자료 기반 |
| 월매출 (8시간) | 6,464만원 | 🧮 808 × 80,000 |
| 월매출 (24/7) | 14,248만원 | 🧮 1,781 × 80,000 |

**단가 8만원 가정의 위험성**:
- 한국 기공계는 덤핑 시장 구조. 덴탈아리랑은 *"기공료의 비밀적 특성과 통계 미작성으로 덤핑 기공소가 드러나기 어렵다"* 라고 보도 🔍 [출처 2]
- 나무위키도 *"치과기공소 소장들의 기공료 낮추기 경쟁으로 1980~1990년대보다 더 낮아진 보철물 수가"* 라고 서술 🔍 [출처 3]
- 미국 기공소 풀 컨투어 지르코니아 출고가 $30~$36 (약 4.2~5만원) 🔍 [출처 4]

## 5. 핵심 한계 명시

1. **장비 세부 가격은 대부분 추론** — KISTI의 5축 밀링머신 자료만 직접 출처 있음. 실제 견적 입수 필수.
2. **한국 기공소 직접 출고가 통계 부재** — 덴탈아리랑이 *"대외비로 여겨지는 기공료의 비밀적 특성과 기공소 현황의 통계가 제대로 작성되지 않는다"* 라고 명시 [출처 2]. 단가 8만원은 합리적 추론이지만 검증 안 됨.
3. **24/7 리메이크율 2%는 미래 목표치** — Spear Education 전미 평균 4% 대비 절반 수준. 시스템 성숙 전 초기 1~2년은 5~10% 보수적으로 잡는 게 안전.
4. **운전자본 3개월은 사용자 요청값** — 실제 결제 주기 자료 없음. 거래처별 1~6개월 편차 가능.
5. **세금은 법인세 22%만 단순 적용** — 부가세, 지방세, 4대보험 가산은 별도 추가 필요.
6. **5년 후 잔존 가치(장비, 사업권) 미반영** — 회계 ROI만 산출. NPV/IRR은 별도 분석 필요.
