## 1. Executive Summary

우리 팀은 처음에 폐의약품 재활용을 검토했지만, 회수 후 활용처와 시장 규모가 작다는 한계를 확인했다. 이후 의료폐기물 시장으로 확장했으나, 규제 강도가 높고 재활용 자체가 막히는 경우가 많았다. 그래서 비급여 의료행위에 쓰이는 물품 중 의료폐기물이 아닌 케이스를 찾았고, 치과 CAD/CAM 공정에서 발생하는 지르코니아 디스크 조각과 분말을 발견했다.

현재 결론은 다음이다.

> **초기 MVP는 분진 전체가 아니라, 깨끗한 미소결 지르코니아 디스크 조각만 수거해 세척·건조·분쇄·분석한 뒤 재생 YSZ계 세라믹 보조 원료로 공급하는 것이다.**

블라스트 그릿이나 구형 비드는 고부가 가능성이 있지만, 소결, 입도 제어, 파쇄율, 재사용 횟수, 분진 발생량 등 검증해야 할 항목이 많다. 반면 내화재/세라믹 원료 공급은 단가가 낮을 수 있으나, 성분표와 샘플 테스트 중심으로 빠르게 고객 반응을 확인할 수 있다.

따라서 현재 전략은 다음과 같다.

1. **1차 검증:** 디스크 조각 기반 내화재/세라믹 보조 원료 공급 가능성 검증
2. **2차 병행 검증:** 소량 블라스트 각형 그릿 샘플 제작 및 고부가 가능성 확인
3. **장기 확장:** 치과 외 세라믹 스크랩, 산업용 지르코니아 부산물, 구형 비드, 고급 세라믹 원료로 확장

## 2. 문제 정의

### 2.1 표면 문제

치과 CAD/CAM 밀링 과정에서는 지르코니아 디스크 조각과 분말이 계속 발생한다. 그러나 현재 국내에는 이를 체계적으로 분리 수거해 산업 원료로 연결하는 인프라가 거의 없다. 기공소 입장에서는 그냥 버리면 끝나는 잔재이고, 산업 바이어 입장에서는 조성·오염·입도·공급 안정성이 보장되지 않은 불확실한 원료다.

### 2.2 진짜 문제

이 문제는 단순히 “쓰레기가 버려진다”가 아니다.

> **고순도 세라믹 자원이 분리수거, 품질표준, 구매처 연결 부재 때문에 일반폐기물처럼 빠져나가는 구조가 문제다.**

핵심 원인은 다음과 같다.

| 원인 | 설명 |
|---|---|
| 수거 밀도 부족 | 기공소마다 발생량이 작고 흩어져 있어 수거 경제성이 낮다. |
| 품질 표준 부재 | 3Y/4Y/5Y, PMMA, 왁스, 금속, 분진이 섞이면 바이어가 꺼린다. |
| 시장 미스매치 | 기공소는 폐기물로 보고, 산업 고객은 규격 원료를 원한다. |
| 낮은 폐기비용 | 기공소 입장에서 지금 당장 강한 고통이 아닐 수 있다. |
| 법규 불확실성 | 반복 수거·가공·판매 시 폐기물 처리/재활용 인허가 확인이 필요하다. |

우리 팀의 탐색 경로는 다음과 같다.

```text
폐의약품
  -> 회수 후 활용처와 시장 규모가 작음

비급여 의료행위 주변부
  -> 의료폐기물이 아닌 케이스가 일부 존재
```

## 7. MVP 공정

현재 가장 현실적인 1차 공정은 다음이다.

```text
치기공소 디스크 조각 수거
  -> 육안 선별
  -> 에어블로우 1차 제거
  -> 물/초음파 세척
  -> 정제수 또는 DI water 최종 헹굼
  -> 105도 건조
  -> 조분쇄
  -> 자력선별
  -> 목표 입도 분쇄/체분급
  -> XRF/XRD/LOI/입도표 작성
  -> 샘플 제공
  -> 내화재/세라믹 업체 배합 테스트
```

디스크 조각만 대상으로 할 경우, 500~600도 열처리는 무조건 필수라고 단정하기보다 A/B 테스트가 좋다.

| 샘플 | 처리 조건 | 목적 |
|---|---|---|
| A | 세척 + 105도 건조 | 최소 공정으로도 원료 테스트가 가능한지 확인 |
| B | 세척 + 105도 건조 + 500~600도 열처리 | 유기물/오염 제거 효과와 LOI 개선 확인 |

## 8. LOI와 수율

LOI는 `Loss On Ignition`, 즉 강열감량이다. 일정 온도로 가열했을 때 줄어드는 질량 비율을 의미한다. 지르코니아 자체가 날아가는 것이 아니라, 수분, PMMA, 왁스, 레진, 바인더 등 유기물이 제거되면서 질량이 줄어든다.

사업적으로 LOI는 단순 분석값이 아니라 원가와 수율을 바꾸는 핵심 변수다.

```text
열처리 후 잔량 = 투입량 x (1 - LOI)
최종 판매가능량 = 투입량 x (1 - LOI) x 정제수율 x 입도수율
실제 kg당 처리원가 = 총 처리비 / 최종 판매가능량
```

예시:

| LOI | 정제수율 | 입도수율 | 투입 100kg 기준 판매가능량 | 해석 |
|---:|---:|---:|---:|---|
| 3% | 90% | 80% | 69.8kg | 깨끗한 디스크 조각, 양호 |
| 5% | 85% | 70% | 56.5kg | 문헌상 유기물 손실 수준 반영 |
| 10% | 80% | 60% | 43.2kg | PMMA/왁스 혼입 높은 현실 시나리오 |
| 15% | 75% | 50% | 31.9kg | 혼합 폐분말, 그릿화 위험 |

현재 기준:

- **GO:** LOI 반영 후 최종 판매가능량 60% 이상
- **주의:** 40~60%
- **STOP:** 40% 미만

## 9. 시장 규모 추정

### 9.1 공급 기준 시장

국내 치과용 지르코니아 블록/디스크 시장은 업계 자료 기준 연 250억~300억 원 규모로 추정된다. 평균 디스크 단가와 중량을 역산하면 국내 구매량은 다음과 같다.

| 기준 | 추정 규모 | 해석 |
|---|---:|---|
| 국내 치과용 지르코니아 구매량 | 87~295톤/년 | 디스크 시장규모와 평균 단가·중량 역산 |
| 기준 시나리오 구매량 | 125~197톤/년 | 내부 보수 추정 |
| 폐지르코니아 잠재량 | 88~158톤/년 | 70~80% 폐기율 적용 |
| 밀링 분말 잠재량 | 38~59톤/년 | 30% 분말 발생 가정 |
| 초기 회수 가능량 | 4~24톤/년 | 총량의 5~15%를 파일럿 접근 가능량으로 가정 |

팀원 보고서에는 국내 전체 잔재 447톤/년, 신품 원가 환산 224억 원이라는 공격적 추정도 있다. 발표에서는 이 숫자를 **매출 시장 규모**가 아니라 **매몰 자원 규모**로만 쓰는 것이 안전하다.

### 9.2 수요 기준 시장

| 기준 | 추정 규모 | 해석 |
|---|---:|---|
| 국내 내화재 전체 시장 | 2025년 약 13.656억 USD | 큰 시장이지만 전부 우리의 시장은 아님 |
| 우리가 접근 가능한 SAM | 재생 ZrO2 보조 원료/첨가재 테스트 시장 | 고객 실매입가 확인 전까지 보수적으로 봐야 함 |
| 1차 SOM | 1~5개 공급처, 연 1~10톤 처리 | 발표 전후 파일럿 현실 목표 |

초기 사업은 대형 소재회사의 주원료 사업이 아니라, **소량 고순도 세라믹 스크랩을 등급화해 파는 재생 원료 사업**으로 보는 것이 맞다.

## 10. 제품 루트 비교

현재 고민한 주요 루트는 세 가지다.

1. 내화재/세라믹 보조 원료
2. 블라스트 각형 그릿
3. 구형 지르코니아 비드

### 10.1 비교표

| 비교축 | 내화재/세라믹 보조 원료 | 블라스트 각형 그릿 | 구형 비드 |
|---|---|---|---|
| 포지션 | 원료/첨가재 | 연마재 완제품 | 고부가 연마재 완제품 |
| MVP 속도 | 빠름 | 중간~느림 | 느림 |
| 가공난이도 | 낮음~중간 | 높음 | 매우 높음 |
| 필요 공정 | 세척, 건조, 분쇄, 체분급, 분석 | 열처리/소결, 파쇄, 정밀 체분급, 성능 테스트 | 볼밀링, 분무건조, 소결, 체분급 |
| 소결 필요성 | 우리 공정에서는 선택적 | 대체로 필요 | 필수 |
| 평균 단가 가설 | 1,000~7,000원/kg | 3,000~18,000원/kg | 30,000~100,000원/kg 잠재 |
| 가격 방어력 | 낮음~중간 | 성능 없으면 낮음 | 성능 있으면 높음 |
| 품질 리스크 | 조성, LOI, Fe 오염 | 입도, 파쇄율, 분진, 재사용 횟수 | 구형도, 밀도, 내구성 |
| 고객 접근성 | 샘플 문의 쉬움 | 성능 검증 필요 | 장비/데이터 없으면 어려움 |
| 현재 판단 | 1차 MVP | 2차 병행 검증 | 장기 옵션 |

### 10.2 핵심 판단

> **내화재 원료 공급은 “돈이 제일 되는 길”이라기보다 “가장 빨리 검증 가능한 길”이다.**

> **블라스트 그릿은 “단가가 높은 길”이지만, 성능 데이터가 없으면 저가 중국산 세라믹 미디어와 비교되어 가격 방어가 어렵다.**

> **구형 비드는 가장 고부가 가능성이 있지만, 분무건조·재소결·구형도·밀도·성능 데이터를 모두 증명해야 하므로 지금 당장 MVP로 삼기엔 무겁다.**

## 11. 가격 가설

### 11.1 내화재/세라믹 원료

| 품목 | 공개 가격대 | 원화 환산 | 의미 |
|---|---:|---:|---|
| zircon sand/flour | 800~2,100 USD/MT | 약 1,180~3,090원/kg | 일반 내화/세라믹 원료 기준 |
| fused zirconia | 1,800~1,950 USD/MT | 약 2,650~2,870원/kg | 공개가 기준 |
| monoclinic/fused zirconia grain | 5,200~5,300 USD/MT | 약 7,640~7,790원/kg | 특수 고순도 원료 구간 |

우리 원료가 일반 zircon sand 대체재로 보이면 1,000~3,000원/kg으로 눌릴 수 있다. 반대로 ZrO2 고함량, Fe2O3 저함량, LOI 낮음, 입도 안정성이 확인되면 3,000~7,000원/kg 테스트 여지가 있다.

### 11.2 블라스트 미디어

| 등급 | 가격 가정 | 조건 |
|---|---:|---|
| 저가 경쟁 구간 | 3,000~8,000원/kg | 성능 데이터 부족, 중국산과 비교 |
| 현실적 진입 구간 | 8,000~12,000원/kg | 기본 입도/청정도 확보 |
| 성능 검증 구간 | 12,000~18,000원/kg | 재사용 횟수, 분진, 표면조도 검증 |
| 프리미엄 니치 | 20,000원/kg 이상 | Zirblast/Microblast급 성능 근거 필요 |

## 12. 원가 구조와 수익성 가설

초기 원가 구조에서 가장 중요한 것은 `수거비`, `처리비`, `분석비`, `최종 판매가능 수율`이다.

| 비용 | 내용 | 확인 방법 |
|---|---|---|
| 수거비 | 용기, 택배/방문 수거, 라벨링 | 케이앤디 파일럿 |
| 세척/건조 | 물, 정제수, 초음파, 건조기 | 실험 기록 |
| 분쇄/체분급 | 장비 대여, 소모품, 오염 관리 | 가천대/외주 견적 |
| 분석비 | XRF, XRD, LOI, SEM/EDS | 공동기기원 견적 |
| 인허가/법규 | 연구용 샘플과 상업 수거 구분 | 지자체/허가업체 문의 |
| 영업비 | 샘플 발송, 고객 방문, 성적서 작성 | 파일럿 기록 |

1차 샘플 3종을 `XRF + XRD + SEM/EDS + TG-DTA`로 확인하는 비용은 대략 30만~80만 원 수준으로 볼 수 있다. 이 분석비는 고객 신뢰와 가격 협상을 위해 반드시 필요한 비용이다.

## 13. ESG와 탄소크레딧 판단

초기부터 탄소크레딧을 “같이 준다”고 말하는 것은 위험하다. 탄소크레딧은 방법론, 등록, 모니터링, 제3자 검증이 필요하기 때문이다.

현실적인 초기 ESG 제공물은 다음이다.

| 단계 | 제공 가능 자료 | 설명 |
|---|---|---|
| MVP | 회수량 리포트 | 기공소별 kg, 수거일, 처리 상태 |
| 샘플 테스트 | 재생 원료 사용량 리포트 | virgin 원료 대체 가능량 추정 |
| 사업화 | 폐기 회피량/재생 원료 투입량 리포트 | 고객 ESG 자료로 활용 |
| 장기 | LCA 기반 감축량 산정 | 탄소크레딧 가능성 검토 전 단계 |

따라서 발표에서는 다음처럼 말하는 것이 안전하다.

> “초기에는 탄소크레딧이 아니라 재생 원료 사용량 기반 ESG 감축량 추정 리포트가 현실적이다.”

## 14. 법규와 윤리 리스크

현재 가장 조심해야 할 리스크는 폐기물 수거/재활용 인허가다.

| 구분 | 현재 판단 |
|---|---|
| 환자 접촉 전 디스크 조각 | 의료폐기물 가능성은 낮아 보이나, 현장·법규 확인 필요 |
| 연구용 샘플 수거 | 소량, 동의서, 익명 처리, 연구 목적이면 상대적으로 안전 |
| 반복 상업 수거 | 폐기물 수집·운반·재활용업 이슈 발생 가능 |
| 사업화 단계 | 허가업체 제휴 또는 지자체/환경부 질의 필요 |

윤리적으로도 과장 표현을 피해야 한다.

| 위험한 표현 | 바꿀 표현 |
|---|---|
| 전량 재활용 가능 | 디스크 조각부터 MVP 검증 |
| 내화재 업체가 바로 산다 | 샘플 테스트 가능성을 확인 중 |
| 탄소크레딧 제공 | 재생 원료 사용량 리포트 제공 |
| 3Y/4Y/5Y 섞여도 상관없다 | 혼재 허용 첨가율을 테스트 |
| 신품가 224억 시장 | 매몰 자원 규모와 실제 판매 시장을 분리 |

## 15. 5대 제품/서비스 체크포인트

| 체크포인트 | 현재 답변 | 아직 비어 있는 검증 |
|---|---|---|
| Desirability | 기공소는 조각 처리 부담을 줄이고, 산업 고객은 저가 재생 ZrO2계 원료를 테스트할 수 있다. | 기공소가 실제로 분리보관을 해주는지, 수요처가 샘플을 요청하는지 |
| Viability | 원료 수거비가 낮고 내화재/세라믹 원료로 팔 수 있으면 kg 마진이 가능하다. | 실제 매입가, 처리비, 수율, 반복 물량 |
| Feasibility | 디스크 조각만 대상으로 하면 세척, 건조, 분쇄, 체분급, 분석으로 MVP가 가능하다. | 장비 접근성, 오염도, LOI, 분쇄 후 입도수율 |
| Usability | 수거함 하나에 디스크 조각만 넣는 방식이면 기공소 업무 흐름에 끼어들 여지가 작다. | 직원 동선, 수거함 위치, 라벨링 부담 |
| Ethics | 환자 접촉 전 조각만 다루고, 분진은 MVP에서 제외하며, 탄소크레딧을 과장하지 않는다. | 의료폐기물/일반폐기물 해석, 연구용 샘플 동의, 상업 수거 인허가 |

## 18. 향후 실행 계획

### 18.1 1주차: 공급 샘플 확보

1. 케이앤디 치기공소에서 디스크 조각 샘플 500g~1kg 확보
2. 가능하면 다른 기공소 2곳 이상 추가 확보
3. 샘플은 절대 섞지 않고 수거처·날짜·상태를 라벨링
4. 조각, 분진, PMMA/왁스 혼합분을 구분 보관

### 18.2 1~2주차: 기본 전처리 및 분석

1. 육안 선별
2. 에어블로우
3. 물/초음파 세척
4. 정제수 또는 DI water 헹굼
5. 105도 건조
6. A/B 샘플 제작: 열처리 없음 vs 500~600도 열처리
7. XRF, XRD, LOI, 입도표 작성

### 18.3 2주차: 수요처 샘플 영업

1. 내화재/세라믹 원료 업체 10곳 문의
2. 샘플 요청 3곳 이상 확보 목표
3. 요구 스펙, LOI 허용치, 입도, 샘플 필요량, 매입가 확인
4. 블라스트 업체 10곳에는 각형 지르코니아계 그릿 테스트 가능성만 병행 확인

### 18.4 3주차: GO/STOP 판단

| 판단 기준 | GO | STOP |
|---|---|---|
| 공급 | 2주 파일럿에서 1개소 1kg 이상 또는 대형처 월 10kg 가능성 | 분리보관 불가, 샘플 확보 실패 |
| 공정 | LOI 10% 이하, 판매가능 수율 60% 이상 | LOI 15% 이상, 수율 40% 미만 |
| 수요 | 10곳 중 3곳 이상 샘플 요청 | 샘플 요청 거의 없음 |
| 가격 | 내화재 3,000원/kg 이상 가능성 | 1,000원/kg 이하만 가능 |
| 법규 | 연구용 샘플과 사업화 경로 구분 가능 | 상업 수거 경로가 막힘 |

## 부록 A. 디스크 조각 MVP 세척·정제 SOP

### A.1 목표

초기 MVP의 목표는 “완벽한 고순도 분말 생산”이 아니다. 목표는 **수요처가 샘플 테스트를 받아볼 수 있을 정도로 오염을 줄이고, 처리 이력을 남긴 재생 YSZ계 원료 샘플**을 만드는 것이다.

### A.2 준비물

| 준비물 | 목적 | 비고 |
|---|---|---|
| 지퍼백/샘플통 | 수거처별 분리 보관 | 날짜, 장소, 디스크 종류 라벨 필수 |
| 장갑/마스크/보안경 | 분진·파편 안전 | 디스크 조각이라도 분쇄 전후에는 필수 |
| 에어건 또는 블로워 | 표면 먼지 1차 제거 | 분진 날림 주의 |
| 초음파 세척기 | 표면 오염 제거 | 2~3L 이상, 40kHz급이면 MVP 가능 |
| 수돗물 | 1차 세척 | 흙먼지·가루 제거용 |
| 정제수/DI water/증류수 | 최종 헹굼 | Ca, Mg, Na, K, Cl 잔류 최소화 |
| 건조기/오븐 | 105도 건조 | 수분 제거 및 건조감량 기록 |
| 전자저울 | 공정 전후 질량 기록 | 0.1g~1g 단위 |
| 자석/자력선별 도구 | 금속성 혼입물 제거 | 조분쇄 후에도 재확인 |

### A.3 단계별 절차

```text
1. 수거처별 샘플 분리
2. 육안 선별
3. 에어블로우
4. 수돗물 세척
5. 초음파 세척 5~15분
6. 정제수/DI water 최종 헹굼
7. 105도 건조
8. 건조 전후 무게 기록
9. 조분쇄
10. 자력선별
11. 체분급
12. A/B 샘플 제작
13. XRF/XRD/LOI/입도 분석
```

### A.4 수돗물 vs 정제수 판단

1차 세척은 수돗물로 해도 된다. 단, 최종 헹굼은 정제수, DI water, 증류수 중 하나를 쓰는 편이 좋다. 이유는 수돗물 속 미네랄이나 염소 성분이 건조 후 표면에 남으면 XRF/EDS 분석에서 불필요한 오염으로 보일 수 있기 때문이다.

| 단계 | 물 종류 | 이유 |
|---|---|---|
| 1차 세척 | 수돗물 가능 | 비용 낮고 먼지 제거에 충분 |
| 초음파 세척 | 수돗물 또는 정제수 | MVP는 수돗물 가능, 정밀 분석 전에는 정제수 권장 |
| 최종 헹굼 | 정제수/DI water/증류수 권장 | 잔류 이온 최소화 |

### A.5 초음파 세척기 조달

초기에는 구매보다 대여 또는 학교 장비 활용이 좋다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| 학교/연구실 장비 대여 | 비용 거의 없음 | 일정 조율 필요 |
| 저가형 2~3L 세척기 | 15만~25만 원 수준 | 온도/출력 안정성 낮을 수 있음 |
| 실험실급 3L 이상 | 세척 안정성 좋음 | 50만 원 이상 가능 |

MVP 기준 최소 권장 스펙은 `2~3L 이상`, `40kHz`, `타이머`, `스테인리스 바스켓`, 가능하면 `가열 기능`이다.

## 부록 B. TAM/SAM/SOM 정리

TAM/SAM/SOM은 시장규모를 세 단계로 나누어 보는 방식이다.

| 용어 | 의미 | 우리 사업 적용 |
|---|---|---|
| TAM | 전체 가능한 시장 | 국내 치과용 지르코니아 잔재 전체 또는 내화재 전체 시장 |
| SAM | 우리가 제품/채널로 실제 접근 가능한 시장 | 재생 ZrO2계 보조 원료/첨가재 테스트 시장 |
| SOM | 초기 몇 년 안에 현실적으로 확보 가능한 시장 | 파일럿 기공소·대형 밀링센터 기반 실제 회수량 |

### B.1 공급 기준 TAM/SAM/SOM

| 구분 | 추정 | 설명 |
|---|---:|---|
| 공급 TAM | 폐지르코니아 잠재량 88~158톤/년 | 국내 지르코니아 구매량 기준 보수 추정 |
| 공격적 TAM | 447톤/년 | 팀원 보고서 수치. 발표에서는 매몰 자원 규모로만 사용 |
| 공급 SAM | 38~59톤/년 + 디스크 조각 일부 | 밀링 분말 및 접근 가능한 조각 중심 |
| 초기 SOM | 4~24톤/년 | 총량의 5~15%를 초기 회수 가능량으로 가정 |

### B.2 매출 기준 TAM/SAM/SOM 예시

실제 매출 시장은 신품가 기준 224억 원이 아니다. 우리가 파는 것은 신품 디스크가 아니라 재생 원료다.

| 시나리오 | 물량 | 단가 | 연매출 |
|---|---:|---:|---:|
| 초기 보수 | 4톤/년 | 3,000원/kg | 1,200만 원 |
| 초기 중간 | 10톤/년 | 3,000원/kg | 3,000만 원 |
| 초기 상방 | 24톤/년 | 7,000원/kg | 1억 6,800만 원 |
| 공급 TAM 하방 | 88톤/년 | 3,000원/kg | 2억 6,400만 원 |
| 공급 TAM 상방 | 158톤/년 | 7,000원/kg | 11억 600만 원 |

해석:

- 치과 지르코니아만으로는 초대형 시장이라고 말하기 어렵다.
- 초기에는 “작지만 실험 가능한 고순도 세라믹 스크랩 시장”이다.
- 장기 확장은 치과 외 세라믹 스크랩까지 넓힐 때 가능하다.

### B.3 수요 기준 TAM/SAM/SOM

| 구분 | 추정 | 해석 |
|---|---:|---|
| 수요 TAM | 국내 내화재 전체 시장 13.656억 USD 수준 | 너무 큰 전체 시장, 우리 직접 시장 아님 |
| 수요 SAM | 재생 ZrO2계 보조 원료/첨가재 테스트 시장 | 고객 요구 스펙과 단가 확인 전까지 보수적 |
| 초기 SOM | 1~5개 수요처, 연 1~10톤 | 실제 샘플 테스트와 반복 구매 여부로 결정 |

## 부록 D. 제품 루트별 상세 공정

### D.1 내화재/세라믹 보조 원료 루트

```text
디스크 조각 수거
  -> 세척
  -> 건조
  -> 조분쇄
  -> 자력선별
  -> 입도 분급
  -> 성적서 작성
  -> 샘플 제공
  -> 고객 배합 테스트
```

핵심은 완제품을 만드는 것이 아니라 **원료로 테스트 가능한 상태**를 만드는 것이다.

| 항목 | 판단 |
|---|---|
| 소결 | 우리 공정에서는 필수 아님. 고객 공정에서 소성/용융 가능 |
| 핵심 데이터 | XRF, XRD, LOI, 입도, 수분, 사진 |
| 고객 질문 | 몇 wt%까지 넣을 수 있는가 |
| GO 기준 | 10곳 중 3곳 이상 샘플 요청, 3,000원/kg 이상 가능성 |

### D.2 블라스트 각형 그릿 루트

```text
디스크 조각/분말 수거
  -> 세척/열처리
  -> 소결 또는 재소결
  -> 파쇄
  -> 정밀 체분급
  -> 자력선별
  -> 블라스트 테스트
  -> 표면조도/분진/파쇄율/재사용성 평가
```

블라스트는 제품 단가가 높을 수 있지만, 단순 원료보다 훨씬 많은 검증이 필요하다.

| 항목 | 판단 |
|---|---|
| 소결 | 각형 그릿으로 쓰려면 대체로 필요 |
| 핵심 데이터 | 입도, 파쇄율, 분진, 재사용 횟수, 표면조도, 오염 |
| 가격 리스크 | 중국산 세라믹 미디어와 비교됨 |
| GO 기준 | 12,000원/kg 이상 지불 가능성, 성능 우위 확인 |

### D.3 구형 지르코니아 비드 루트

```text
폐분말 수거
  -> 전처리
  -> 볼밀링(D50 < 2um)
  -> 슬러리화
  -> 분무건조
  -> 소결
  -> 체분급
  -> 구형도/밀도/경도/내마모성 평가
```

구형 비드는 장기적으로 가장 고부가 가능성이 있지만, 지금 당장 MVP로 하기에는 장비와 데이터 요구가 크다.

| 항목 | 판단 |
|---|---|
| 핵심 장비 | 볼밀, 분무건조기, 소결로, 체분급기 |
| 장점 | 성공 시 30,000~100,000원/kg 잠재 |
| 리스크 | 구형도, 밀도, 소결 조건, 재사용성 검증 필요 |
| 현실적 위치 | 장기 R&D 옵션 |

## 부록 E. 장기 확장 전략

치과 지르코니아는 좋은 출발점이지만, 치과만으로는 공급량 한계가 있다. 장기적으로는 “치과 폐지르코니아 재활용 회사”가 아니라 **고순도 세라믹 스크랩 등급화·재원료화 회사**로 확장해야 한다.

### E.1 확장 가능한 원료

| 원료 | 발생처 | 가능성 |
|---|---|---|
| 치과 지르코니아 디스크 조각 | 치기공소, 밀링센터 | 초기 MVP |
| 치과 밀링 분진 | 집진기, 밀링기 | 2단계. 오염/분진 관리 필요 |
| 실패 보철물 | 기공소, 치과 | 법규·오염 확인 후 장기 검토 |
| 산업용 지르코니아 세라믹 스크랩 | 세라믹 부품 제조사 | 공급량 확장 가능 |
| 내화재 폐재 | 유리·철강·시멘트 공정 | 이미 재활용 시장 일부 존재, 경쟁 확인 필요 |
| 알루미나/YSZ 혼합 세라믹 스크랩 | 정밀 세라믹 업체 | 등급화 가능성 |

### E.2 확장 순서

| 단계 | 목표 | 이유 |
|---|---|---|
| Phase 1 | 디스크 조각만 수거·분석·샘플 판매 | 오염 낮고 검증 빠름 |
| Phase 2 | 분진 포함 여부 판단 | 물량은 늘지만 안전/오염 리스크 증가 |
| Phase 3 | 내화재/세라믹 원료 반복 공급 | 안정 매출과 수요처 요구 스펙 확보 |
| Phase 4 | 블라스트 그릿 제품화 | 고부가 반복 소모재 가능 |
| Phase 5 | 구형 비드/R&D | 높은 단가, 높은 기술 허들 |
| Phase 6 | 치과 외 산업 세라믹 스크랩 | 공급량 한계 극복 |

### E.3 회사 포지셔닝 변화


## 부록 F. 발표용 스토리라인

### F.1 2차 발표 핵심 구조

1. 우리는 폐의약품에서 시작했지만 시장 규모와 활용처가 작았다.
2. 의료폐기물은 규제상 재활용이 막히는 경우가 많았다.
3. 그래서 비급여 의료행위 주변부에서 의료폐기물이 아닌 고가 소재를 찾았다.
4. 치과 CAD/CAM 지르코니아는 디스크 한 장의 상당 부분이 조각과 분말로 버려진다.
5. 문제는 기술보다 수거 밀도, 품질 표준, 구매처 연결의 부재다.
6. 그래서 우리는 분진 전체가 아니라 깨끗한 디스크 조각만 먼저 본다.
7. 1차 제품은 내화재/세라믹 보조 원료, 2차 옵션은 블라스트 그릿이다.
8. 다음 검증은 말이 아니라 숫자로 한다: 수거량, LOI, 수율, 샘플 요청, 실매입가.

### F.2 발표에서 보여줄 것

| 자료 | 목적 |
|---|---|
| 문제정의 그림 | 왜 이 문제가 단순 환경문제가 아닌지 설명 |
| 린캔버스 이미지 | 비즈니스 구조 한눈에 제시 |
| 가치제안캔버스 이미지 | 공급 고객/수요 고객을 분리해 보여줌 |
| 샘플 사진 | Show, don't tell |
| 무게 측정표 | 실제 발생량 근거 |
| LOI/입도 결과 | 공정 가능성 근거 |
| 고객 답변 캡처 | 샘플 수요 근거 |

### F.3 발표에서 피할 말

| 피할 말 | 이유 |
|---|---|
| “전량 재활용됩니다” | 분진/혼합물 미검증 |
| “바로 수익 납니다” | 실매입가와 수율 미확인 |
| “탄소크레딧 드립니다” | 방법론·검증 전 |
| “3Y/4Y/5Y는 상관없습니다” | 용도별 스펙 확인 필요 |
| “224억 시장입니다” | 신품가 환산이지 실제 매출 시장 아님 |

## 부록 H. 지금 팀이 가진 가설 목록

### H.1 공급 가설

| 가설 | 현재 상태 | 검증 방법 |
|---|---|---|
| 대형 기공소는 월 10kg 이상 디스크 조각을 만들 수 있다 | 미검증 | 케이앤디/교수님 인터뷰 |
| 디스크 조각만 따로 모으는 행동은 30초 이내면 가능하다 | 미검증 | 2주 파일럿 |
| 무료 수거만으로도 초기 협조가 가능하다 | 미검증 | 대표님 인터뷰 |
| 분진은 오염 리스크가 커서 MVP에서 제외해야 한다 | 강한 가설 | 현장 샘플 비교 |

### H.2 공정 가설

| 가설 | 현재 상태 | 검증 방법 |
|---|---|---|
| 디스크 조각은 세척+건조만으로도 내화재 샘플 가능성이 있다 | 미검증 | A/B 샘플 테스트 |
| 500~600도 열처리는 LOI와 냄새/색상 개선에 도움이 된다 | 가능성 높음 | 열처리 전후 질량·사진·LOI |
| 자력선별은 조분쇄 후 더 효과적이다 | 가능성 높음 | 선별 전후 질량 |
| 최종 판매가능 수율 60% 이상이면 1차 검증 지속 가능 | 기준 설정 | 실제 공정 기록 |

### H.3 수요 가설

| 가설 | 현재 상태 | 검증 방법 |
|---|---|---|

| 내화재 원료는 3,000원/kg 이상이면 계속 볼 만하다 | 기준 설정 | 실매입가 문의 |
