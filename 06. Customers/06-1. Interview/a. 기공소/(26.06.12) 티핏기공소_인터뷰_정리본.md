# 기공소 대표 미팅 정리

**일시**: 2026.05.12 (화) 오전 10:10 / 93분 49초
**참석자**: 기공소 대표(참석자 1), 은지(참석자 2), 동료 1(참석자 3), 동료 2(참석자 5)
**장소**: 기공소 (서울 추정 / 11층 사무공간 + 작업장 투어 포함)

---

## 미팅 개요

링크드인/메일을 통한 콜드 컨택으로 성사된 미팅. 가천대 GCS(코코네스쿨) 학부 창업팀이 "지르코니아 디스크 배치 최적화 SaaS(Dental-fit)" 아이템을 들고 현직 기공소 대표를 만나 문제 정의 검증 및 인사이트를 듣는 자리.

대표는 **본인도 동일한 문제의식을 갖고 자동화·AI 전환을 직접 추진 중인 인물**로, 단순한 인터뷰이가 아니라 잠재적 협업자/멘토/고객 모두에 해당하는 포지션. 내일이 GCS 학교 심사 발표이기 때문에 이 미팅이 사업 방향 최종 판단의 핵심 데이터가 됨.

---

## 대표 프로필 (참석자 1)

- 기공사 출신, 오스템임플란트 영업사원 경력 보유
- 30세에 기공소 창업, 현재 매출 약 2억 원, 영업이익률 25~30%
- 동시에 **다른 헬스케어 스타트업에서 5년째 스쿼드장으로 활동** (시드 → 시리즈 C까지 직접 목격, 직원 20명 → 200명 규모 성장 경험)
  - 해당 스타트업은 위워크 선릉 2호점 입주, 사내 클로드 코드 맥스 사용, AI 미사용 개발자 정리 사례 보유
- 본인 기공소도 클로드 코드로 직접 코딩하며 백엔드 학습 중
- 기술보증기금 5~7억 보증 가능 수준, 내년에 확장 이전 + 법인 전환 + 개발자/마케터 채용 예정
- OKR(3-3-9) 시스템으로 기공소 운영 중

## 대표의 핵심 비전

> "기공소의 미래는 무조건 자동화다."

**1차 자동화 목표 (대표가 그리는 그림)**:
CAD 디자인 완료 → 디자인 파일이 폴더에 자동 저장 → AI가 폴더 감지 → CAM 자동 nesting + 계산 완료 → 로봇 팔이 밀링기에 디스크 자동 장착

**2차 목표**: 디스크 체인저 + 로봇 팔로 24/7 무인 가동 (현재 새벽 3~7시 장비 유휴 시간 제거)

## 1. 문제 정의에 대한 대표의 관점 (중요 - 사업 방향 수정 시사점)

### 은지팀의 가설 vs 대표의 진단

| 구분 | 은지팀의 초기 가설 | 대표의 현장 진단 |
|---|---|---|
| 핵심 폐기 원인 | 보수적 spacing, 비효율 배치, partially-used disk 회피 | **배치 효율은 곁들이는 수준. 진짜 문제는 휴먼 에러로 인한 "잘못 깎음"** |
| 발생 빈도 | 매일 누적되는 비효율 | 일주일에 2~3회 잘못 깎는 사고 (10명 이상 규모 기공소는 무조건 발생) |
| 비교 단위 | 디스크 사용률 % | 컵에 모아두면 한 달 만에 가득 참 |

### 휴먼 에러의 실제 양상 (대표가 직접 묘사)

- 디자이너가 폴더에 파일 빼놓음 → CAM 거는 사람이 드래그로 일괄 업로드 → 중복 파일/누락 파일/잘못된 어버트먼트 매칭 미체크
- 어버트먼트 종류가 많은데(덴티움 vs 메가젠 vs 디오 등) 육안 확인 실패 시 잘못 밀링 → 환자 구강 내 안 맞음
- 두 개를 의도적으로 깎은 케이스(원장 비교용)를 잊고 하나만 출하 → 나머지 폐기
- 신터링 후 박스에 남은 잔재를 추적해봐도 "이게 왜 깎였지?" 모르는 경우 다수
- 14T 디스크에 12T용 짧은 크라운을 그냥 걸기 (디스크 바꾸기 귀찮아서) → 소모량 증가
- 현재 캠 담당자 1명이 4~5대 장비를 혼자 핸들링 중 → 부하

### 대표의 진단을 그대로 옮기면

> "지르코니아 효율은 곁들이는 거고, 진짜 문제는 휴먼 에러. **잘못 깎는 게 더 문제예요.**"
> "이게 나만 문제인가? 다른 기공소는 문제라고 생각도 안 하고 있어요."
> "하루 단위로 보면 문제 없지. 근데 1년 치 쌓으면 어마어마한 시간과 돈이에요."

### Dental-fit 방향에 주는 시사점

- "배치 최적화"라는 프레이밍은 보완은 되지만 **메인 페인포인트가 아닐 수 있음**
- 휴먼 에러 방지(중복 체크, 어버트먼트 매칭 검증, 디자인-CAM 핸드오프 자동화)가 **더 큰 가치 제안**
- 결국 양쪽 다 해결하는 방향 = "CAM nesting 자동화 + 휴먼 에러 방지" 통합 솔루션으로 포지셔닝 가능

## 2. 시장 사이즈에 대한 솔직한 대화

- 국내 전체 기공소 시장: 보수적 6천억, 풀어줘도 8천억 (대표 추정)
- 은지팀도 데스크 리서치 통해 이미 인지하고 있던 부분
- 지르코니아 단일 영역만 보면 시장이 너무 작음

### 대표가 제시한 사이즈 확장 전략

> "지르코니아로만 보면 작아요. 근데 **소프트웨어 산업으로 보면** 그걸 퍼뜨릴 수 있잖아요. 클라우드 파는 거랑 똑같아요."

- **국내 → 미국/중국/유럽 SaaS 글로벌 확장** (Glidewell이 보고 있는 것과 같은 그림)
- **PC당 라이센스 모델**: 디자이너 컴퓨터 1대당 50만 원 → 20명 규모 기공소면 월 1천만 원 단위
- **개원 패키지 번들**: 컨설팅 업체와 제휴 → 신규 기공소 오픈 시 자동 도입
- **건당 토큰 과금**: 덴트버드(서울대/카이스트, 디자인 AI)가 건당 1~3달러 모델로 운영 중인 사례 참조

### 가격 가이드 (대표 견해)
- 초기 진입: 월 10만 원
- 효과 검증 후: 월 30~50만 원
- 벤치마크: 3Shape Implant Studio (서지컬 가이드) 연 180만 원, 임플란트 디자인이라 라인 락인 효과로 계속 결제됨
- 핵심: **"디자이너가 이거 없으면 취업 안 한다"** 수준의 락인을 만들면 기공소 오너가 안 깔 수 없는 구조

## 3. 경쟁 환경 / 업계 구조 인사이트

### 국내 경쟁/유사 솔루션
- **하이퍼덴탈**: 고가 nesting 시스템. 보급되어 있지만 느림 (밀링은 빠른데 캠 자체가 느림)
- **Arum (한국타이어 자회사) ApexMill**: 캠 소프트웨어. 대표 기공소는 ApexMill로 전환 검토 중 (사용감 + 속도 우수)
- **3Shape**: API 제공함 (은지 멘션) → SaaS 연동 가능성 있음
- **DentBird (덴트버드)**: 서울대/카이스트 출신 창업, AI 디자인 자동화. 대표 기공소도 6개월 테스트했으나 업데이트/대응 속도가 느려 사용 중단. "스타트업스럽지 않고 대기업스럽다"고 평가

### 해외 벤치마크
- **Glidewell (미국, 글로벌 3위)**: 반자동화 완료, 디자인-CAM-밀링 라인업 자체 구축. 모던덴탈그룹(중국) 등에 매각/협업 시도 중

### 한국 기공소의 구조적 제약
- **기공소는 법인 설립 불가** (의료법상 기공사/치과의사만 운영 가능)
- 예외: 1999~2000년 행정 실수로 법인 등록된 일산/부산 두 곳
- 현재는 "신체보정용 정형외과 의료기기" 카테고리 하위로 우회 등록
- → **투자 유치 자체가 구조적으로 막힘** → 보수성과 정체의 근본 원인
- 글로벌 확장 시 미국/호주/동남아 법인 설립으로 우회 가능

## 4. 대표가 직접 제안한 협업 가능성

> "어느 정도 타협점이 되면 저는 제가 개발 안 하고 **제가 쓸 용의가 있거든요**."

- 대표 본인이 클로드 코드로 직접 개발 시도 + 헬스케어 스타트업 본사 AX 팀장(다음 달부터 협업 예정)과의 라인 보유
- Dental-fit이 일정 퀄리티에 도달하면 **본인 기공소를 베타 사이트로 사용 가능**
- 본인 기공소 = 4천 개 이상 거래처 보유 → MVP 검증 + 초기 레퍼런스 확보 채널
- 어드바이저/도메인 자문 가능

### 단, 조건이 있음

> "그냥 대충 하고 시간 끌다가 빠져버리면 가천대 이미지만 나빠지는 거예요. 본인 마음속에서 끓어오르는 미친 놈 같은 게 있어야 돼요."

- 본인은 "생존을 위해 무조건 한다"는 명분이 명확함
- 학생팀에게 묻는 것: **"왜 이걸 끝까지 할 거냐"** 에 대한 진정성 있는 답

## 6. 작업장 투어 (1시간 16분~)

- 사이드(쉐이드) 통일 운영: 모든 디스크를 A2로만 깎고 스테인+컬러링으로 마무리 → 재고/실수 최소화
- 디스크 체인저 장비로 야간 자동 밀링 중 (새벽 3시까지 가동, 3~7시 유휴)
- 부러진 디스크/낀 디스크/잘못 깎인 잔재 실물 다수 확인
- 어버트먼트 종류별 분류 보관함 운영 중 (덴티움/메가젠/디오 등)
- 1500~1600°C 신터링 퍼니스 가동 중
- 공간 운영 철학: "장 만들면 그 안에서 뭐 할지 모름. 다 터놓는다" → 위워크 스타일 + 제조업 감시 효율

## 7. 액션 아이템 (이 미팅에서 합의/언급된 것)

### 즉시 (오늘~내일)
- [ ] **내일 GCS 심사 발표 자료 작성** → 완성 후 대표에게 사전 검토 요청 (대표 OK)
- [ ] 발표 결과에 따라 사업 방향 최종 확정 (Dental-fit 계속 vs 팀 재편성)

### 단기
- [ ] **대표와 추후 연락 채널 유지** (필요 시 연락 OK 확답 받음)
- [ ] 부천대학교 배윤정 교수 (학과장) 추가 인터뷰 (이미 진행 완료, 이 미팅이 2번째 기공소)
- [ ] KND 덴탈 (은평구 기공소) 이미 방문 완료 - 동일 방향 컨펌

### 중기 (피벗/확장 검토)
- [ ] 솔루션 방향 재검토:
  - 단순 "배치 최적화" → "CAM 자동화 + 휴먼 에러 방지 통합"으로 프레이밍 확장 검토
  - 디자인-CAM 핸드오프 자동화 (파일 누락/중복 검증)가 페인포인트로 더 적합한지 검증
- [ ] 비즈니스 모델: PC당 라이센스 + 월 구독 + 업데이트 추가 과금 구조 검토
- [ ] 글로벌 확장 로드맵: 한국에서 검증 후 미국/중국/동남아 진출 (법인 구조상 한국 내 확장 한계)
- [ ] OKR(3-3-9) 시스템 학습 후 팀 운영에 도입 검토 (가천대 황선 교수 수업에서 확인 가능 - 동료 5 언급)

### 잠재 협업
- [ ] Dental-fit MVP 완성 시 대표 기공소를 베타 테스트 사이트로 활용 협의
- [ ] 대표 본사 AX 팀장과의 간접 네트워킹 (대표가 다음 달부터 협업 시작 예정)

## 9. 미팅 종합 평가

- 잠재 베타 고객 + 어드바이저 + 도메인 파트너의 자원을 한 인물에게 동시 확보 가능
- 가격 가이드, BM 구조, 락인 메커니즘까지 구체적 청사진을 무료로 공유받음

**리스크/주의 신호**
- 대표 본인이 같은 영역을 직접 개발 중 → **잠재 경쟁자 가능성도 병존**
- 시장 사이즈 한계 명확 (국내 8천억 이하, 지르코니아만은 더 작음) → 글로벌 + 소프트웨어 확장 없이는 매력도 낮음
- 한국 법인 구조 제약 → 투자 유치/확장에 구조적 천장
- "휴먼 에러 방지"로 페인포인트가 이동할 경우 기존에 만든 nesting 알고리즘(spiral greedy + shapely)의 활용도 재검토 필요
