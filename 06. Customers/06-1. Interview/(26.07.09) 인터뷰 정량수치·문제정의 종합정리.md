# Part 1. 정량 수치 총정리

## 1-1. 리메이크·휴먼에러 빈도 (가장 중요한 문제 강도 지표)

| 수치 | 내용 | 출처 |
|---|---|---|
| **주 2~3회** | 잘못 깎는(오가공) 사고 발생 빈도. "10명 이상 규모 기공소는 무조건 발생" | 티핏 대표 |
| **한 달** | 잘못 깎인 잔재를 컵에 모으면 가득 차는 데 걸리는 기간 | 티핏 대표 |
| **1/140** | 리메이크 비율. "6개월 동안 한 번도 없다가 12개짜리(브릿지) 한 번 와요. 그러면 이제 140분의 1이 되는 거야" | 강냉이닷컴 대표 |
| **하루 1~2건** | 국내 최대급 기공소 '라인'의 추정 리메이크 건수 ("하루에 한두 건은 무조건 일어날 것") | 강냉이닷컴 대표 [검증 필요] |
| **5~10% 미만** | 치과가 체감하는 보철물 리메이크 비율 | 마이엠 개원의 |
| **30~40%** | 기공소 거래처 변경을 고려하게 되는 실수율 임계치 | 마이엠 개원의 |
| **3개월에 1건** | 월 50건 의뢰 기준 리메이크 체감 빈도 ("리메이크 거의 없어요. 세 달에 한 번 정도") | 서울앞선치과 원장 |
| **월 단위 반복 + 피드백 2~3회 무개선** | 거래 기공소를 교체하는 조건 | 서울앞선치과 원장 |
| **1개월 내 풀림** | 임플란트 어버트먼트 표기/매칭 오류 시 장착 후 문제 발생 기간 (실제 경험 사례) | 서울앞선치과 원장 |
| **10% → 5%** | 검증 SW로 리메이크율을 절반으로 줄인다는 가치제안 시뮬레이션 ("기존에 10%였다면 2분의 1 줄여서 5%") | 이마고웍스 인터뷰 중 팀 논의 |
| **치과 3곳 동시 이탈** | 배송 오류(케이스 뒤바뀜) 1건으로 네트워크 치과 3개 거래가 한 번에 끊긴 사례 | 강냉이닷컴 대표 |
| **20% 초과** | CAD 매칭 편차 자동 경고 요청 임계값 ("20% 넘어가서 안 맞다고 알려주면 좋을 것 같아요") | 강냉이닷컴 직원(5년차) |

## 1-2. 리메이크 1건의 비용 구조

| 수치 | 내용 | 출처 |
|---|---|---|
| **8~10만 원/장** | 지르코니아 디스크 1장 가격 (T당 책정, 평균 약 10만 원) | 강냉이닷컴 대표 |
| **1~2주** | 디스크 1판을 소진하는 데 걸리는 기간 | 강냉이닷컴 대표 |
| **6개월 내 0% / 6개월~1년 50% / 1년 후 100%** | 리메이크 비용 청구 정책 (6개월 내는 기공소 전액 부담, 환자 통증 케이스는 기간 무관 기공소 전액 부담) | 강냉이닷컴 대표 |
| **8만 원/건** | 리메이크 1건당 버려지는 소재 비용 ("발생하실 때마다 소재를 8만 원씩 버리시지 않습니까") | 이마고웍스 인터뷰 중 논의 |
| **환자 청구 0원** | 리메이크 비용은 환자에게 청구하지 않고 치과/기공소가 감수 | 마이엠 개원의, 서울앞선치과 원장 |
| **리메이크 1건 = 디스크 + 인건비 + 전기세 + 배달비 + 신뢰 손상** | "커스텀 어버트먼트도 새로 만들어야 되고, 지그도 만들어야 되고, 인건비도 들어가고 전기세도 들어가고" | 강냉이닷컴 대표 |

## 1-3. 기공소 운영·경영 수치

| 수치 | 내용 | 출처 |
|---|---|---|
| **매출 약 2억 원, 영업이익률 25~30%** | 티핏기공소 운영 실적 (0원에서 시작) | 티핏 대표 |
| **거래처 4,000개 이상** | 티핏기공소 누적 거래처 수 | 티핏 대표 |
| **영업이익 15% = "미쳤다" / 10% = 준수 / 5% = 생존 우려** | 제조업 관점 영업이익률 기준 | 티핏 대표 |
| **2인 (19년차 대표 + 5년차 직원)** | 강냉이닷컴 운영 인원 (과거 직원 6명 이상 → 건강 이슈 후 축소) | 강냉이닷컴 |
| **캠 담당 1명이 장비 4~5대** | CAM 담당자 1인이 감당하는 밀링 장비 수 → 부하 상태 | 티핏 대표 |
| **새벽 3~7시** | 디스크 체인저로 야간 밀링 후에도 남는 장비 유휴 시간 | 티핏 대표 |
| **지르코니아 90%** | 기공소 작업(주문)에서 지르코니아가 차지하는 비중 ("지르가 90%라고 하면 됩니다") | K&D 소장 |
| **두 달에 5~6만 원** | 폐기물 업체 처리 비용 (분류 안 하면 무료 수거 업체는 수거 거부) | K&D 소장 |
| **자동화 20~30% → 목표 80%+** | 현재 기공 작업 자동화 수준과 K&D 소장이 그리는 목표 ("작업 수준이 지금은 한 2~30%밖에 안 되는데 나는 이거를 자동화를 한 80% 이상으로 올리고 싶다") | K&D 소장 |
| **사람 작업 비중 약 50%** | "사람이 만드는 거는 한 50%, 기계가 다 만들어" | K&D 소장 |
| **납기: 짧으면 2~3일** | "그것도 경쟁력이에요" | 강냉이닷컴 대표 |
| **월 1회** | 협회 학술회 개최 주기 / 기공사 보수교육은 연 1회 의무 | K&D 소장 / 배은정 교수 |
| **전국 기공소 약 7,000곳** | K&D 소장 추정 ("탈탈 털어서 기공소가 몇 군데? 7천 정도") | K&D 소장 [검증 필요] |
| **재료별 분리 가능한 대형 기공소: 전국 ~10곳** | 인원 100~200명 규모로 재료별 분리 배출이 가능한 곳 | K&D 소장 [검증 필요] |

| **한 학년 130명 중 취업 1명 수준** | 치기공과 졸업생의 기공소 취업 실태에 대한 K&D 소장 주장 ("130명 졸업하면 한 명 할까 말까") — 배은정 교수는 "너무 비약"이라 반박 (부천대 졸업생 연 20명→60여 명 배출) | K&D 소장 vs 배은정 교수 [상충] |

# Part 2. 문제정의 — 인터뷰 인용 기반 수치화

## 2-1. 치기공소가 겪는 페인포인트

### P1. 휴먼에러로 인한 오가공(잘못 깎음) — 핵심 페인포인트
- **빈도: 주 2~3회** (10인 이상 기공소), **누적 손실: "1년 치 쌓으면 어마어마한 시간과 돈"**
> "지르코니아 효율은 곁들이는 거고, 진짜 문제는 휴먼 에러. **잘못 깎는 게 더 문제예요.**" — 티핏 대표
> "하루 단위로 보면 문제 없지. 근데 1년 치 쌓으면 어마어마한 시간과 돈이에요." — 티핏 대표
- 양상: 디자이너가 폴더에 파일을 빼놓음 → CAM 담당이 드래그 일괄 업로드 → **중복 파일·누락 파일·잘못된 어버트먼트 매칭 미체크** → 잘못 밀링 → 환자 구강 내 부적합. 비교용으로 2개 깎은 케이스를 잊고 1개만 출하해 나머지 폐기, "이게 왜 깎였지?" 모르는 잔재 다수, 14T 디스크에 12T용 크라운을 걸어 소모량 증가 등 (티핏 대표 묘사)
- **인지 격차**: "이게 나만 문제인가? 다른 기공소는 문제라고 생각도 안 하고 있어요." — 티핏 대표 → 문제는 실재하나 고객이 체감 못하는 것 자체가 GTM 리스크

### P2. 치과발(發) 데이터 오류로 인한 '억울한 리메이크'
- **리메이크의 대부분이 치과 측 휴먼에러**라는 것이 강냉이닷컴 대표의 진단이며, 방문 당일 2건을 실시간 목격:
  - 사례 ① 스캔바디 육각(hex) 각도 오류 — 재스캔 데이터도 동일 오류. "다운받아, 검증을 해보자" → 데이터 각도 비교로 즉시 판별 가능 (SW 자동화 직접 가능)
  - 사례 ② 마진 짧음 — 잇몸이 경계부를 덮은 스캔 오류. 기공물은 정상인데 재제작
> "단순하게 데이터 에러가 아니라 휴먼 에러예요. 사람이 잘못한 일… 환자한테도 피해고 기공소에도 2차 피해, 필요 없는 제작을 해야 되는 상황이 생겼잖아요." — 강냉이닷컴 대표
> "잘 만들었으나 스캔을 (이렇게밖에) 안 나오게 한 거잖아. **우리는 억울하게 다시 만들어야 되는 상황이.**" — 강냉이닷컴 대표
- **비용 부담: 6개월 내 리메이크는 기공소가 100% 부담** (6개월~1년 50%, 통증 케이스는 무기한 기공소 부담) → 치과 오류여도 기공소가 손해를 떠안는 구조. **"억울한 재제작을 데이터로 소명"할 수단 부재**가 핵심 니즈

### P3. 의뢰 접수·누락 알람의 공백
- 가장 보편적인 스캐너(TRIOS)의 채널인 **3Shape Communicate에는 알람 기능이 없음** → 의뢰서를 받아야(보통 다음날) 스캔이 온 줄 알게 되고, 의뢰서 미발송 시 **누락돼도 모름**
> "3s는 (알람이) 없어요. … 오늘 스캔을 했는데 저는 내일 의뢰서를 받잖아요." — 강냉이닷컴 대표
- 반면 DS Core(CEREC)는 당일 자동 메일 발송 → 채널별 비대칭. 진행 상태 관리는 **수기 일지 + 빨간 펜 V자 체크**가 전부, 디지털 이력 없음

### P4. 의뢰서 정보 불명확·모순 → 전화 디스커션
> "위에는 답이 이걸로 왔는데 아래는 다른 답이 왔었잖아요. … 전화해서 확인을 하죠." — 강냉이닷컴 대표
- 의뢰서는 종이/메일 혼재, 클라우드 의뢰 정보는 **기공소가 수정 불가(읽기 전용)**. 쉐이드 미기재는 클레임 주요 원인. 환자명 오기(김홍철→'홍천') 같은 오타도 현장에서 발생
- 치과 측도 재확인 연락 인정: 피니싱 라인 안 보임, 보철 두께 얇음, 쉐이드 부족, 인상/스캔 불량 시 (마이엠·배정윤 교수 공통)

### P5. 저수가 치킨게임과 해자 부재
- 제품 차별화 불가(금니·은니·지르코니아·틀니 4종 동일) → 가격 경쟁만 존재. **최저 수가 2만 5,400원**(안산 사례), 면허만 있으면 개업 가능해 진입장벽 없음
> "멍청하게 치킨 게임을 해가지고 판이 어지러워진 거죠. … 결국은 빚만 남으니까." — 강냉이닷컴 대표
- **디스크 1판 8~10만 원, 1판에 1~2주** 소요되는 원가 구조에서 "직원 월급은 오르는데 단가는 낮아지는" 모순 (강냉이닷컴)

### P6. 숙련 인력 부족과 교육 비용
- 신입 교육 **1년 이상**, 실수령 220만 원 요구 시 고용주 부담 **월 270~280만 원**, 그런데 "278만 원어치 일할 것 같아? 못해" (K&D 소장)
- 졸업생 취업률 극저(K&D 소장 주장 "130명 중 1명 할까 말까" [교수 반박 있음]), 빌드업 숙련자는 **연봉 8,500만 원**까지 상승 → 자동화 니즈의 근원
> "다 알아서 기계가 할 거고… 지금은 한 2~30%밖에 안 된다. 나는 이거를 자동화를 한 80% 이상으로 올리고 싶다." — K&D 소장

### P7. 장비 유휴와 생산성 한계
- 야간 자동 밀링에도 **새벽 3~7시 유휴**, CAM 담당 **1명이 장비 4~5대** 핸들링 (티핏)
- 티핏 대표의 1차 자동화 그림: CAD 완료 → 폴더 자동 감지 → CAM 자동 네스팅 → 로봇팔 디스크 장착 → **24/7 무인 가동**

### P8. 보수적 도입 문화와 레퍼런스 부재
> "약간 뭔가의 검증이 필요할 것 같아요. 대형 기공소나 어느 정도 사람들이 아는 기공소가 사용했는데 좋다더라… 밑바닥부터 하는 게 아니라 먼저 베이스를 다 다져놔야 고객이 유입이 되는 거예요." — 강냉이닷컴 대표
- 신재료·신기술은 **"구강 내 1년 생존 확인 후 도입"**. SW 추가 지출에도 보수적 → 초기 무료 파일럿 필수 (직원도 동일 의견: "맨 초기에는 그냥 무료로 써보시라고")

### P9. 구조적 규제 제약
- **기공소는 법인 설립 불가**(의료법상 기공사/치과의사만 운영; 예외 2곳은 행정 실수) → **투자 유치가 구조적으로 막힘** → 업계 보수성·정체의 근본 원인 (티핏 대표)
- 치과-기공소 간 **거래 중개 마진·알선 금지** → 플랫폼 비즈니스 수익화 제약 (글라우드)

| 검증된 레퍼런스 후 도입 | "대형이 써서 에러가 줄었다 + 치과가 인정 → 공신력" | 강냉이닷컴 대표 |
| 숙련공정(빌드업 등) 자동화 장비 | 쉐이드 입력 → 파우더 자동 계량·도포·건조 구상 | K&D 소장 |
| 합리적 가격 | 월 10만 원 진입 → 효과 확인 시 30~50만 원 | 티핏 대표 |

### ② 기공사(직원, 실사용자)
- **원하는 것**: CAD 매칭 편차 **20% 초과 시 자동 경고**(자발적 요청), 케이스별 보철물 종류/이름 자동 분류·검색("첫 번째 건 되게 좋다")
- **거부하는 것**: 작업자 추적 기능 — "좋게 말하면 책임소재 명확화지만 우리 입장에선 **감시 용도가 하나 늘어나는 것**"
- **부담**: SW 학습 비용 ("한 명이 익혀 다시 가르치는 부담. 그래도 어쩔 수 없이 쓰게 된다"), 치과마다 다른 요구 스타일로 신입 에러 누적 → 거래 끊김

### ③ 치과 개원의
| 니즈 | 근거 인용/수치 | 출처 |
|---|---|---|
| 품질 > 납기 > 가격 | "품질이 제일 중요해요." / "제시간 내에, 품질 좋게만 오면 돼요." | 서울앞선치과 원장 |
| 재제작 없는 안정성 | 리메이크 5~10% 미만이면 수용, 30~40%면 교체 검토 | 마이엠 개원의 |
| 기존 거래처 유지(소통 노하우) | "이 원장님 핸드폰으로 찍으면 이렇게 보인다"는 쉐이드 해석 경험 축적 → 리메이크율이 낮아져도 교체 안 함 | 마이엠 개원의 |
| 납기 단축 가치 낮음 | 임시치아가 있어 "하루 빨리"보다 "딱 맞게"가 중요. 납기 1주(3일~2주) | 마이엠 개원의 |
| 기공료 인상 회피 | 기존 기공소의 AI 도입은 긍정, 단 "기공료가 올라갈 수 있다"는 우려 | 마이엠 개원의 |
| 임플란트 부품 매칭 정확성 | 표기 오류 → 1개월 내 풀림 경험 | 서울앞선치과 원장 |

### ④ 대학병원 보철과 교수 (배정윤)
- 니즈: **체어타임 단축**("매칭 오류·네스팅 오류 상태로 제작된 보철물은 구강 내 시적 시 조정 시간이 길어짐"), **환자 신뢰 유지**("파일 누락이나 중복 밀링으로 배송 일정 지연 시 환자와의 신뢰가 깨짐"), 데이터 오류 사전 차단, 오배송·작업 매칭 실수 방지
- 조건: **환자 안전, 책임 소재, 의료 데이터 보안, 기공 업계와의 상생**
- 실패 예측: "바쁜 상황에서 케이스를 일일이 매칭하고 상태를 업데이트하는 과정 자체가 시간 낭비일 수 있음" → 수동 입력 최소화 요구

### ⑤ 치공학과 교수 (배은정)
- 니즈: **양질의 라벨링 데이터**("AI 허브 데이터는 실제로 쓸 만한 게 거의 없어요"), 의료데이터 사전 승인(IRB/병원 협력) 구조, 기공사 R&D·페이퍼워크 지원("아이디어는 많은데 특허·개발로 풀 방법을 모름"), 인력 양성(1~3년차 이탈 방지)
- 배치 알고리즘 수용성: "안 쓸 이유는 없을 것 같아요. 다만 가격대가 문제" — 남는 자투리보다 더 아낄 수 있어야 지불 성립

### ⑥ 환자
- 문제: 재내원 부담("바쁜데 왜 또 와야 하냐"), 신뢰 저하("왜 내 것만 안 맞냐"), 색조 민감("앞니 두 개 색조가 조금만 안 맞아도 사람들은 엄청 예민합니다" — 배은정 교수)
- 니즈: 빠른 것보다 **안 아프고 잘 맞는 보철** (마이엠), 방문 횟수 축소(글라우드의 원데이 보철: "환자가 두 번 방문하지 않게 해주겠다")

### ⑦ 업체(이마고웍스·글라우드 등 솔루션 기업)
- 니즈: 기공소 보수성 극복(도메인 전문가 영입 — "자문위원이 20~30명"), 명확한 ROI 증명, 규제 대응
- 문제: 기공소장 설득 난이도("본인의 아집 내지는 그간의 경험을 더 중시"), 치과-기공소 중개 수익화 금지, 프리랜서 기공사 대상 긴 교육 매뉴얼, 시장 성장 한계("나이가 많은 사람들이 늘어나서 커진다 정도 말고는 크게 커질 거라는 생각은 안 든다" — 글라우드)

# Part 3. 검증된 가설 vs 깨진 가설 (정량 근거 요약)

## 검증된 것
1. **휴먼에러성 오가공은 실재하고 반복적** — 주 2~3회(티핏), 현장 방문 당일 2건 실시간 목격(강냉이닷컴)
2. **리메이크는 발생하며 기공소가 비용을 떠안는다** — 1/140(강냉이), 5~10%(마이엠), 6개월 내 기공소 100% 부담
3. **치과의 1순위는 품질** — "품질 > 납기 > 가격" (서울앞선치과·마이엠 공통), 반복 리메이크는 거래 단절의 직접 원인(월 단위 반복+2~3회 피드백 무개선 시 교체)
4. **가공 전 검수·의뢰 누락 감지는 기공소가 원하는 기능** — 대표 즉답 1·2순위 + 직원의 20% 임계값 경고 자발 요청

## 깨진(약해진) 것
1. **"배치 효율(네스팅 최적화)이 핵심"** → "효율은 곁들이는 거고, 진짜 문제는 잘못 깎는 거예요" (티핏 대표)
2. **"납기 단축이 강한 구매 요인"** → 하루 단축 가치 낮음, 임시치아 존재 (마이엠)
3. **"리메이크 감소만으로 치과가 기공소를 바꾼다"** → 14년 거래·소통 노하우가 더 강함 (서울앞선·마이엠)
4. **"치과 직접 과금 가능"** → 직접 지불 의향 약함, 오히려 기공료 상승 우려 (마이엠) → **기공소 B2B SaaS**로 방향 수렴
5. **"리메이크가 치과 전반에서 매우 빈번하다"** → 잘 관리되는 1인 치과는 3개월 1건 수준 (서울앞선치과)
6. **"시장이 충분히 크다"** → 국내 6천억~8천억, 지르코니아 단독은 더 작음 → 글로벌 SaaS/소프트웨어 확장 없이는 천장 (티핏 대표·마이엠 개원의 공통 경고)

## 남은 확인 과제 (수치 공백)
- 기공소당 정확한 리메이크율의 분포 (현재 1/140, 주 2~3회, 5~10% 등 표본별 편차 큼 — 규모별 표준화 필요)
- 전국 기공소 수(7,000곳 주장)의 공식 통계 교차검증
- 리메이크 사유 중 파일/매칭/정보 오류가 차지하는 비중 (배정윤 교수 후속 질문으로 남김)
- JustScan 패키지 가격(8천만/1억), 대형 기공소 하루 1~2건 리메이크의 실측치
