# 부천대 치기공학과 교수님 인터뷰 준비안

**인터뷰 대상:** 부천대 치기공학과 교수님  
**목적:** 치과 지르코니아 잔재의 현장 발생 구조, 소재 특성, 수거 가능성, 기술 리스크, 네트워크를 검증한다.  
**핵심 태도:** 아이디어를 설득하러 가는 자리가 아니라, 우리가 틀릴 수 있는 지점을 찾으러 가는 자리다.

---

## 1. 이번 인터뷰의 핵심 목표

| 목표 | 왜 중요한가 | 반드시 얻을 결과 |
|---|---|---|
| 지르코니아 잔재 발생 구조 파악 | 공급량 추정의 출발점 | 디스크 조각, 분진, 실패 보철물, PMMA 혼입 여부 |
| 디스크 조각 MVP의 타당성 확인 | 분진 제외 전략이 맞는지 확인 | 디스크 조각만 모으는 것이 현실적인지 |
| 3Y/4Y/5Y 혼재 리스크 확인 | 수요처 스펙 대응에 중요 | 혼재가 내화재/연마재에서 얼마나 문제인지 |
| 현장 안전/윤리 확인 | 분진 취급은 건강 리스크가 있음 | MVP에서 제외할 것과 주의사항 |
| 네트워크 확보 | 파일럿 공급처와 전문가 소개 필요 | 기공소/밀링센터/재료업체 추천 2~3곳 |

---

## 2. 인터뷰 전에 공유할 30초 설명

> "저희는 치과 CAD/CAM 공정에서 나오는 폐지르코니아를 보고 있습니다. 처음에는 분진까지 포함해 재활용을 생각했는데, 지금은 오염과 안전 리스크가 낮은 디스크 조각만 먼저 수거해서 산업용 세라믹 원료로 테스트하는 방향을 검토 중입니다. 오늘은 아이디어 평가보다, 실제 현장에서 이게 말이 되는지와 저희가 놓친 리스크를 듣고 싶습니다."

## 3. 반드시 얻어야 할 것

### 3.1 정량 정보

| 얻을 정보 | 질문 방식 |
|---|---|
| 일반 기공소의 월 지르코니아 디스크 사용량 | "보통 디지털 기공소는 한 달에 디스크를 몇 장 정도 쓰나요?" |
| 대형 밀링센터의 월 사용량 | "대형 밀링센터는 어느 정도부터 대형이라고 보나요?" |
| 디스크 한 장에서 남는 조각 비율 | "밀링 후 남는 링/조각은 보통 얼마나 생기나요?" |
| 분진과 조각의 비율 | "분진과 조각 중 실제로 더 많이 쌓이는 것은 무엇인가요?" |
| PMMA/왁스/레진/금속 혼입 빈도 | "지르코니아 잔재가 다른 재료와 섞이는 상황이 자주 있나요?" |

### 3.2 기술 정보

| 얻을 정보 | 질문 방식 |
|---|---|
| 디스크 조각의 상태 | "밀링 전 디스크 조각은 프리소결 상태로 보면 될까요?" |
| 세척/건조만으로 충분한지 | "디스크 조각만 모으면 열처리 없이도 원료 테스트가 가능할까요?" |
| 소결 필요 여부 | "블라스트 그릿으로 쓰려면 소결이 어느 단계에서 필요하다고 보시나요?" |
| 3Y/4Y/5Y 구분 가능성 | "기공소가 디스크 종류별로 조각을 분리해줄 수 있을까요?" |
| 분석 필수 항목 | "업체에 보여주려면 XRF, XRD, LOI, 입도 중 무엇이 가장 중요할까요?" |

### 3.3 네트워크 정보

| 얻을 정보 | 질문 방식 |
|---|---|
| 인터뷰 가능한 기공소 | "이 주제를 검증하기 좋은 기공소나 밀링센터를 2~3곳 소개받을 수 있을까요?" |
| 소재/세라믹 전문가 | "내화재나 세라믹 원료 쪽으로 질문할 만한 교수님/업체가 있을까요?" |
| 장비 접근 | "초음파 세척, 건조, 분쇄, 소결, 분석을 학교나 주변에서 어디까지 해볼 수 있을까요?" |

## 4. 질문지

### 4.1 현장 구조 이해

1. 치기공소에서 지르코니아 디스크는 보통 어떤 작업 흐름으로 사용되나요?
2. 밀링 후 남는 것은 디스크 조각, 분진, 실패 보철물 중 어떤 형태가 가장 많나요?
3. 현장에서는 이 잔재를 지금 어떻게 버리나요?
4. 지르코니아 잔재를 따로 모으는 기공소가 있나요, 아니면 대부분 섞어서 버리나요?
5. 기공소 입장에서 이것이 불편한 문제인가요, 아니면 거의 신경 쓰지 않는 문제인가요?

### 4.2 디스크 조각 MVP 검증

1. 저희가 분진을 제외하고 디스크 조각만 먼저 보겠다는 전략이 현장적으로 맞아 보이나요?
2. 디스크 조각만 따로 모으려면 작업자에게 어떤 동선이 추가될까요?
3. 디스크 조각이 PMMA, 왁스, 레진, 금속과 섞일 가능성은 어느 정도인가요?
4. 디스크 브랜드나 3Y/4Y/5Y 종류별로 조각을 분리하는 것이 가능할까요?
5. 현장에서는 디스크 조각을 얼마나 오래 보관할 수 있을까요?

### 4.3 소재와 공정 리스크

1. 치과용 지르코니아 디스크 조각은 산업용 세라믹 원료로 볼 때 어떤 장단점이 있나요?
2. 3Y/4Y/5Y가 섞이면 어떤 용도에서 문제가 될 가능성이 큰가요?
3. 단사정계/정방정계 문제가 내화재나 연마재 용도에서도 의미가 있을까요?
4. 텅스텐 카바이드 버 마모분이 실제로 많이 섞일까요?
5. 디스크 조각만 대상으로 하면 세척, 건조, 분쇄, 자력선별 중 무엇이 필수라고 보시나요?
6. 500~600도 열처리는 꼭 필요할까요, 아니면 디스크 조각에서는 비교 실험으로 충분할까요?
7. 블라스트 그릿으로 가려면 소결, 파쇄율, 입도, 분진 중 무엇이 가장 큰 허들일까요?

### 4.4 시장과 수요처

1. 치과 재료 업계에서 이런 폐지르코니아를 다시 치과용으로 쓰는 것은 현실적으로 얼마나 어려울까요?
2. 치과용 재생 블록보다 산업용 원료부터 가는 전략이 맞다고 보시나요?
3. 내화재, 연마재, 세라믹 필러 중 어느 쪽이 가장 먼저 테스트해볼 만할까요?
4. 산업 업체가 요구할 최소 성적서는 무엇일까요?
5. 이런 재생 원료가 거래되려면 교수님이 보시기에 가장 먼저 증명해야 할 데이터는 무엇인가요?

### 4.5 법규와 윤리

1. 환자 접촉 전 디스크 조각은 의료폐기물이 아니라고 봐도 될까요?
2. 학교 연구용 샘플로 기공소에서 조각을 받는 것은 어떤 절차가 필요할까요?
3. 상업적으로 반복 수거할 때는 어떤 인허가나 책임 문제가 생길 수 있을까요?
4. 분진을 다룰 때 학생 팀이 특히 조심해야 할 안전 문제가 있나요?

### 4.6 마무리 질문

1. 오늘 이야기 중 저희 가설에서 가장 위험한 부분은 무엇인가요?
2. 저희가 다음주 안에 꼭 실험하거나 물어봐야 하는 한 가지는 무엇인가요?
3. 이 주제를 검증하기 위해 소개받을 수 있는 기공소, 밀링센터, 소재 업체가 있을까요?
4. 인터뷰 내용을 익명으로 발표 자료에 반영해도 괜찮을까요?

## 7. 인터뷰 후 바로 해야 할 일

1. 30분 안에 핵심 발언을 원문에 가깝게 정리한다.
2. "사실", "추정", "교수님 의견", "다음 확인 필요"로 나눈다.
3. 린캔버스에서 바뀌어야 하는 칸을 표시한다.
4. 소개받은 사람에게 당일 연락한다.
5. 디스크 조각 MVP 공정표에 반영한다.
