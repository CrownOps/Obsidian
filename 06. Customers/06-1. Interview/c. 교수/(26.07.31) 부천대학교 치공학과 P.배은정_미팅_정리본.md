## 1. 핵심 피드백 요약

### ✅ 긍정 평가
- **스캔 오류 탐지 방향성은 맞다.** 구강 스캔 데이터 품질 자동 판정은 아직 시스템화된 솔루션이 없어 시장 공백 존재
- 교수 연구실 학생들도 동일 주제(불량 스캔 복원 방법) 실험 중 → 현장 니즈 실재 확인

### ⚠️ 전략 수정 제안: **기공소보다 치과를 1차 타겟으로**

> "1차적으로는 치과를 타겟팅해서 하는 게 괜찮을 것 같다. 구독 서비스도 기공소보다 치과가 더 안전할 수 있다."

- **이유:** 스캔은 치과 위생사가 찍음. 오류를 치과에서 먼저 걸러야 근본 해결
- 치과 위생사들은 스캔 교육 부족 → 스캔 가이드/피드백 서비스 수요 실재
- 치과 시장이 기공소 시장보다 훨씬 크고 결제력 있음
- 신정훈 교수님도 동일하게 치과 타겟 권고했다고 확인

### ⚠️ OCR 경쟁사 존재 확인
- 김이안 대표 (여성 창업가): 기공소 협력으로 데이터 대량 확보 후 OCR 솔루션 런칭 → 이미 안정화 단계
- **결론:** OCR 단독으로 차별화 어려움 → OCR은 기본 기능으로 두고, 스캔 품질 판정 + 교합 분석을 핵심 차별점으로

### 💡 기능 추가 아이디어 (교수님 제안)
| 기능 | 설명 |
|------|------|
| **스캔 가이드** | 스캔 방법(악궁 스캔 순서, 변연 확보 방법)을 실시간으로 안내 |
| **바이트(교합) 분석** | 상하악 + 바이트 데이터로 하중 분포 스펙트럼 시각화 → 기공사 제작 계획 수립에 활용 |
| **메시 오류 탐지 + 보완** | 스캔 데이터의 삼각메시 구조 분석 → 오류 탐지에서 나아가 자동 보완까지 |
| **서비스 분리** | 치과용 (스캔 품질 판정 + 가이드) / 기공소용 (교합 분석 + 케이스 매칭) 별도 패키지 구성 |

## 2. 데이터 확보 관련

### 현황
- 의뢰서(OCR): 어느 정도 확보, 정확도 ~80%
- 스캔 파일: 사실상 없음 → **가장 큰 병목**

### 교수님 제시 방법
1. **AI Hub (aihub.or.kr) 공공 데이터 활용**
   - 파노라마(2D)뿐 아니라 최근 오럴 스캔(3D) 데이터도 올라오고 있음
   - 다운로드 후 라벨링 재작업 필요할 수 있음 (기존 서울대 데이터 라벨링 품질 불량 사례 주의)
2. **이희영 학생 아버지 기공소 (안양) → 데이터 협력 루트**
   - 경기도 기공소 회장급 → 규모 큰 기공소 데이터 접근 가능성
   - 교수님이 직접 연결 중개 의향 표명
3. **IRB 심의 면제 신청**
   - 구강 스캔 데이터는 의료 데이터 → 본격 수집 전 IRB 심의 면제 취득 필수
   - 심의 면제 루트로 진행하면 복잡하지 않음

## 6. 기타 인사이트

- **기공소 CAD 소프트웨어 시장 구조:** 3Shape(독자), Exocad(오픈, 스캐너 회사들과 번들), Imagix 등 → API 개방 여부는 기본적으로 막혀 있으나 오픈소스 CAD 솔루션 존재
- **학생 실습 오류 패턴:** 포인트 설정 실수(치아↔잇몸 혼동)가 대표적 → 오류 발생 시 프로그램이 이유 설명 안 해줌 → **에러 안내 기능 수요 시사**
- **인상체득 vs 디지털 스캔:** 아직 혼재. 인상체득도 기공소에서 스캔으로 변환 → 어차피 스캔 파일 나옴
- **구독 가격:** 50만원은 부담스럽다는 반응. 대형 기공소 타겟 시 가능하나 초기 진입 가격 전략 재검토 필요
