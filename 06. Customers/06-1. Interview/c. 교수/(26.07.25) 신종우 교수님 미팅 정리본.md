## 핵심 피드백 요약

### 긍정적 반응

- 팀이 16곳 기공소 인터뷰 + 논문 기반 리서치를 직접 수행했다는 점에 명시적으로 칭찬 ("너무 대견하다", "멋있다")
- "기공소가 을이니까 구매자"라는 비즈니스 로직에는 수긍
- 스캔 대조(설계 검증 단계) 아이디어에 대해 "그게 첫 번째 문제와 가장 가깝다"는 방향성 긍정
- 후속 미팅 적극 제안 ("언제든지 나를 이용해", "연구실 문 열려 있다", 8월 10일 이후 상시 가능)
- 제자(김기수 소장)에게 즉석 전화를 걸어 현장 검증 — 네트워크 즉시 제공

### 문제정의 수정 제안 (가장 중요)

교수가 발표 도중 정면 반박하며 제시한 논리:

> "커뮤니케이션(의뢰서) 문제보다 스캔·인상 채득 자체가 리메이크의 1차 원인이다."

단계별 논리:
1. 인상재 경화 중 움직임 → 재료 자체가 변형 ("애초에 변형이 아예 변형")
2. 석고 모형 제작 시 스파츄레이션 워킹타임 무시, 조기 이형 → 2차 오차 누적
3. 디지털 스캔도 동일 구조: 각도·가려짐 오차, 위생사가 영업사원에게 대충 배움
4. 치과 의사 본인도 스캔 데이터를 읽지 못해 품질 검증 주체 부재
5. 결론: 기공사가 아무리 정교하게 작업해도 "패시브 핏" 불가능

**CrownOps에 갖는 의미:** 현재 솔루션(의뢰서-STL 매칭, 재료·쉐이드 누락 확인)은 리메이크 원인 연쇄의 3~5단계를 다루지만, 교수가 지목한 핵심 원인(1~2단계)은 더 앞단에 위치한다.

### 기능 아이디어 — 국시원 AI 채점 시스템 제안

교수가 직접 제안한 신규 아이템:

> "정답 모델을 3D 데이터로 만들어두고, 응시자 제작물 스캔을 갖다 집어넣으면 AI가 즉시 어느 부분이 문제인지 점수로 뽑아준다."

배경:
- 치과기공사 국시원 실기시험이 현재 교수들의 육안 채점 의존
- 지역·학교 편향 채점 가능성, 3박 4일 인력 낭비 문제
- 교수 본인이 4~5년 전 관련 특허 출원 보유
- "이 꽉 막힌 기공 집단이 돈 주고 할 놈은 없다" — B2B 기공소보다 공공기관(국시원) 대상이 예산·명분 유리하다고 판단

## 데이터/기술 관련 논의

### 63.7% 통계 프레이밍 오류 지적

- 발표에서 63.7%(남신은, 2018)를 "치과에서 정보를 잘못 줘서"로 설명
- 교수가 즉각 지적: 해당 통계의 실제 의미는 "임상 인상채득 오류"이며 "의뢰서(정보 전달) 문제"와 분리해야 함
- **데이터 자체는 정확하지만, 이를 설명하는 내러티브가 데이터와 불일치**

### 아날로그 vs 디지털 오류 비교 (김기수 소장 답변)

| 항목 | 소장 답변 |
|---|---|
| 리메이크 1차 원인 | 인상 변형이 가장 크다 |
| 의뢰서發 리메이크 비중 | "요즘은 적은 편" — 기존 프로그램(덴트웍 등)이 이미 완화 중 |
| 의뢰서 매칭 솔루션에 WTP | "안 하죠" — 부정적 |
| 모델리스(완전 디지털) | 생각보다 리메이크 적다, 숙련자가 하면 정확도 높음 |
| 향후 인력 리스크 | 아날로그→디지털 전환 숙련 기공사가 현재 품질 유지 중, 이 세대 이탈 시 신입은 마운팅·교합 기초 없어 품질 하락 우려 |

### 기술적 한계 발언

- "사람마다 구강 조건이 다 달라 '정답' 데이터를 어떻게 다 만들 거냐" — AI 품질 판단의 기술적 난이도 지적
- "심각한 오류는 포착 가능하지만, 사람마다 미묘하게 다른 부분은 어렵다"
- 현재 기공소 인력 구조: 캐드 작업을 외주에 넘기는 방식 증가 → 품질 확인 주체가 사라지는 구조

## 기타 인사이트

### 시장 구조 리스크 (장기)

- 치과의사들이 캐드캠 장비 공동구매(장비 무상+블록 구매 모델)로 자체 밀링, 기공소 거래 축소 트렌드 ("덴티리온" 류)
- 임플란트 단가 하락: 300만원 → 20~30만원 → 기공소 아웃소싱 유인 감소
- "장기적으로 기공이라는 분야가 없어질 것" — 자율주행 비유 사용
- 단, 이는 "장기" 트렌드이며 즉각적 소멸 신호가 아님

### 갑을 구조 악순환

- 기공사가 불량 데이터를 인지해도 치과에 강하게 문제를 제기하지 못함
- "치과에 잘못됐다고 하면 거래처 바꿔버린다"
- 재청구도 못하고 재제작 비용 기공소 부담 → CrownOps가 해결해야 할 구조적 문제와 직결

### 교수의 4D 덴티스트리 연구

- 정적 스냅샷이 아닌 동적 구강 데이터(씹는 움직임 전체) 기반 형상기억 소재 보철 개발 중
- "움직임이 허용된 조건에서 타액·온도에 맞게 스스로 최적화되는 살아있는 보철"
- 현재 네오임플란트 등 기업과 연구 진행 중 — 참고 맥락, 직접 협업 우선순위 낮음

### 포지셔닝 언어 주의

- 발표 중 "대시보드를 만드는 것까지가 저희의 솔루션"이라는 표현 사용
- "리메이크율 대시보드"는 외부 자료 금지 표현에 해당 — 내부에서도 개념이 완전히 대체되지 않은 것으로 보임

## 액션 플랜

### 즉시 (24~48시간)

- [ ] **감사 이메일 발송** — 6줄 이내, "인상채득/스캔이 1차 원인"이라는 통찰 인용, 후속 문서 발송 시점 명시. 이메일 말미에 후속 미팅 일정 제안
- [ ] **63.7% 설명 문구 수정** — 사업계획서·인터뷰 스크립트·커뮤니티 게시글 전반에서 "치과가 정보를 잘못 줘서" → "임상 인상채득 오류로 인한 비율"로 교체

### 단기 (1~2주)

- [ ] **후속 문서 작성 및 발송** — Before/After 반영표(오늘 피드백 기반), 말미에 CAD/CAM 담당 교수 소개 요청 포함 (오늘 못 챙긴 exit ask 보완)
- [ ] **월간 손실액 수치 정합성 확인** — 발표 수치(220~260만원)와 기존 사례(약 80만원/월) 간 차이 원인 규명 (표본·방법론 차이 여부)
- [ ] **현장 인터뷰 질문 수정** — 신구대 파일럿 인터뷰에 추가할 질문:
  - 최근 완전 재제작 사례 10건의 원인이 무엇인가
  - 인상·스캔·바이트·기공 작업 중 어디서 문제가 발생했는가
  - 작업 전 문제를 인지하고도 진행한 케이스가 있는가
  - 치과에 재스캔을 요구하지 못한 이유가 무엇인가
  - 객관적인 오류 리포트가 있다면 치과에 반려할 수 있는가
  - 제작 가능 여부를 자동 판단해준다면 비용을 지불할 의향이 있는가
- [ ] **WTP 직접 재검증** — 파일럿 인터뷰에 "실제로 돈 내고 쓰겠는가" 직접 질문 필수 포함 (김기수 소장 사례 = 부정적 WTP 신호)

### 중기 (2~4주)

- [ ] **"설계 검증(스캔 품질 대조)" 우선순위 상향 검토** — 랜딩페이지 스코프 우려(CAM 투입 전 영역) vs 오늘 피드백(스캔 품질이 핵심) 사이 긴장 해소 방향 결정 → 신구대 파일럿 데이터 확인 후 포지셔닝 재작업 여부 결정
- [ ] **"암묵지 이식" 프레이밍 실험** — 정보오류 방지 각도가 아닌 "은퇴 세대 노하우를 신입에게 이식"하는 각도로 커뮤니티·인터뷰에서 반응 테스트
- [ ] **국시원 AI 채점 아이템 탐색 트랙** (별도, 낮은 우선순위)
  - 치과기공사 실기시험 채점 방식 및 공개 채점기준 확인
  - 신종우 교수 보유 특허 번호 확인 및 내용 검토
  - 대학 실습 채점 방식 교수 인터뷰 (5인 이상)
  - 3D 스캔 기반 프로토타입 개념 실험 (기준 모델 vs 학생 작품 편차 측정)
- [ ] **스캔 품질 검증 기술 조사** — 마진 검출 AI, 스캔 누락·홀 탐지 기술, 3Shape·Medit·exocad 기존 품질검사 기능, FDA·식약처 의료기기 해당 가능성 검토

## 미팅 총평

준비한 Q1~Q3 질문 세션은 사실상 진행되지 않았고, 교수가 발표 초반부터 문제정의를 정면 도전하며 미팅을 주도했다. 이번 미팅의 핵심 수확은 "우리가 겨냥하는 문제가 리메이크의 진짜 1차 원인인가"에 대한 근본적 재점검이었다. 네트워크(제자 직접 전화)를 즉석에서 행동으로 보여준 것은 신뢰 형성 측면에서 큰 자산이나, 명시적 exit ask(CAD/CAM 교수 소개, 2차 접점 구실)는 확보되지 않아 후속 이메일에서 반드시 보완 필요.

> **핵심 판단:** CrownOps를 폐기해야 한다는 신호가 아니라, 문제의 위치를 더 앞단(스캔 품질)으로 이동하라는 강한 피드백이다. 포지셔닝의 큰 틀("제작 전 체크게이트")은 유지하되 검증 항목의 무게중심을 재료·쉐이드 누락에서 스캔 품질(마진·대합치·영역 확인)로 이동하는 방향을 신구대 파일럿으로 검증 후 결정할 것.
