## 슬라이드 1 — 문제 + 후킹 (45초)
> **제목**: 보철물 10개 중 1개는 다시 만들어집니다.
> **부제목**: 국내 치과기공소 재제작률은 10.1%입니다. 원인의 80.9%는 치과에서 오는데, 비용의 67.4%는 기공소가 냅니다.

> 심사 기준: **BM 완성도** — 문제가 명확해야 솔루션과 BM이 설득된다

### 시각화 구성
> 풀스크린 3분할

```
┌─────────────────┬──────────────────────────┬────────────────────┐
│                 │   원인의 80.9%            │                    │
│  치아 보철물    │    치과에서 발생           │  이 구조를 막는    │
│  10개 중 1개는  │         ≠                 │  소프트웨어가      │
│  다시 만들어집니다│   비용의 67.4%           │  없었습니다.       │
│                 │    기공소가 부담           │                    │
│     10.1%       │  [역방향 화살표]           │                    │
└─────────────────┴──────────────────────────┴────────────────────┘
```

**발표 멘트 (45초)**
> "치과에서 씌우는 인공 치아 — 보철물은 치과가 아니라, 치과 옆 골목 치과기공소가 만듭니다.
> 그리고 그 주문 10건 중 1건은 처음부터 다시 만들어집니다.
> 문제는 더 있습니다. 재제작 원인의 80.9%는 치과에서 발생하지만, 비용의 67.4%는 기공소가 냅니다.
> 잘못은 치과에서 나오고, 비용은 기공소가 냅니다.
> 그리고 이 구조를 막는 소프트웨어는 아직 없습니다."

**수치 출처**
- 재제작률 10.1%, 원인 80.9%, 비용부담 67.4% — 대한치과기공학회지(남신은, 2018)
- 국내 10% vs 글로벌 평균 3.8% — 2.5배 차이

## 슬라이드 1-1 — 재제작 손실 (보조)
> **제목**: 재제작 1건, 최소 11만원이 사라집니다.
> **부제목**: 재료비·인건비·전기세·배달비까지 합산한 직접 손실입니다. 월 200케이스 기공소가 재제작률 10%로 운영되면, 연간 3,360만원이 조용히 빠져나갑니다.

## 슬라이드 2 — 솔루션 + BM (45초)
> **제목**: 제작 시작 전, 아무도 없었던 자리에 들어갑니다.
> **부제목**: CrownOps는 기존 소프트웨어를 대체하지 않습니다. 흩어진 정보를 한 화면에 모아 제작 가능 여부를 판단하는 검사대를 추가합니다.

> 심사 기준: **BM 완성도** — 솔루션이 어떻게 수익으로 연결되는가

### 시각화 구성
> 상단: Before/After / 하단: BM 카드

**[상단] Before → After**
```
[Before]
스캔(3Shape) → 의뢰서(PDF) → 카카오톡 ···❌ 수작업 대조 ··· CAD → 납품
                                           ↑
                              하나의 케이스, 채널이 3개
                              수신 알림 없음 → 담당자가 기억으로 맞춤
                              바쁘면 누락 → 재제작

[After]
스캔 → 의뢰서 → 카카오톡 → ✅ CrownOps 검사대 → CAD → 납품
                                      ↑
                       흩어진 정보를 한 화면에 자동 대조
                       🟢 작업 가능  🟡 검증 필요  🔴 최종 확인
```

**[하단] 수익 구조**
```
① 조건부 무료 파일럿           ② 유료 전환             ③ 업셀
─────────────────────────────────────────────────────────────
누적 500케이스까지 무료   →   월 10만원   →   월 30~50만원
(약 3개월)                    재제작 1건        (티핏 대표 지불의향)
                              손실 11만원+로
전환 시:                      ROI 즉각 증명
"파일럿 절감액 XX만원
 데이터로 제시"
```

> 가격이 아닌 리스크를 제거한다
> 기간 기준(30일)이 아닌 케이스 수(500건) 기준 → 기공소는 충분히 써보고 결정, CrownOps는 의미있는 데이터 확보

**발표 멘트 포인트**
> "기존 프로그램을 대체하지 않습니다.
> 제작이 시작되기 전, 아무도 없었던 자리에 검사대 하나를 추가하는 것입니다."

## 슬라이드 3 — 시장 규모 + 사업 전략 (30초)
> **제목**: 기공소가 지금 버리는 돈이 시장입니다.
> **부제목**: SW 예산이 아닌 재제작 손실을 시장으로 정의했습니다. 진입가 10만원에서 시작해 검증 후 단계적으로 확장합니다.

> 심사 기준: **사업 전략 및 향후 계획**

### 시각화 구성
> 좌: TAM/SAM/SOM 동심원 / 우: 3단계 로드맵

**[좌] 단계별 가격 기반 TAM**
```
TAM  1,674억   글로벌 5개국 34,970개소 × 월 39.9만원  (장기 업셀가)
  SAM  139억   국내 전체    4,663개소 × 월 24.9만원  (파일럿 후 평균 ARPU)
    SOM  21.6억  성장형 다인  1,800개소 × 월 10만원   (초기 진입가)
```

_가격 단계 논리: 10만원(진입) → 24.9만원(전환) → 39.9만원(업셀)_
_기공소 수: 공공데이터포털 전수 확정 4,663개소 (2026.07) / 글로벌 5개국 34,970개소_
_SOM 1,800개소: 국내 성장형·다인형 기공소 (전체의 약 39%)_

**[우] 3단계 로드맵**
```
1단계 (0~6개월)     2단계 (6~18개월)    3단계 (18~36개월)
손실을 숫자로 잰다   레퍼런스를 만든다    데이터가 해자가 된다
신구대 실습 파일럿   파일럿 3곳 유료전환  110곳 확대
재제작 규모 실측     PMF 검증            부품·재료 DB 축적
BEP: 28~45곳 유료전환 시 달성 (ARPU 18만원)
```

## 슬라이드 4 — 소셜 임팩트 (30초)
> **제목**: 기공사는 국가 면허 전문직인데, 구조가 을로 만듭니다.
> **부제목**: 의료기사법이 법인 설립을 막고, 지분 투자를 차단합니다. CrownOps는 데이터로 이 불균형을 중화합니다.

> 심사 기준: **임팩트 창출 가능성** — 하나은행 관계자 집중 포인트

### 시각화 구성
> 임팩트 플로우 3레이어

```
[구조적 불평등]
기공사 = 국가 면허 전문직
의료기사법 → 법인 설립 불가 → 지분 투자 차단
→ 업계 자체 혁신 불가 + 갑을 구조 고착

        ↓

[손실의 사회적 규모]
전국 4,663개 기공소 × 재제작률 10.1%
= 매일 수천 건의 보철물이 다시 만들어짐
= 재료·에너지·인력 낭비 / 환자 치료 지연 / 기공사 소득 잠식

        ↓

[CrownOps가 만드는 변화]
재제작 감소 → 기공소 경영 안정 → 폐업 방지 → 청년 일자리 보호
소명 데이터 확보 → 억울한 비용 부담 해소 → 기공사 전문직 권리 회복
환자 보철 품질 향상 · 의료 자원 효율화
```

**발표 멘트**
> "기공사는 국가 면허 전문직입니다.
> 그런데 법이 법인을 막고, 구조가 갑을을 고착시킵니다.
> CrownOps는 데이터로 이 불균형을 중화합니다.
> '억울한 부담'을 없애는 것 — 이게 우리가 만드는 소셜 임팩트입니다."

## 슬라이드 5 — 트랙션 + 팀 + 클로징 (30초)
> **제목**: 현장에서 시작했고, 현장이 먼저 반응했습니다.
> **부제목**: 콜드메일 300통 회신이 거의 없을 때, 인터뷰와 인바운드로 파일럿 기공소 3곳을 확보했습니다.

> 심사 기준: **팀 역량 · 자원 확보 역량**

### 시각화 구성
> 좌: 팀 카드 / 우: 검증 수치 배지 / 하단: 클로징 문장

```
┌───────────────────────┬──────────────────────────────┐
│  신은지 CEO           │  심층 인터뷰     10건         │
│  현장 관계·파일럿 운영 │  파일럿 협의     3곳          │
│                       │  커뮤니티 조회   900회+       │
│  엄주원 COO           │  KDTEX 2026     85부스       │
│  BM·경쟁분석·운영전략 │  신구대 교육 파일럿 협의 중   │
└───────────────────────┴──────────────────────────────┘

파일럿 협의 기공소:
강냉이닷컴 (오류 2건 실시간 목격)  ·  티핏기공소 (매출 2억, 거래처 4천개)  ·  효인덴탈 (인바운드 자발 연락)
```

**클로징 문장**
```
잘못은 치과에서 나오고, 비용은 기공소가 낸다.
CrownOps는 이 억울함을 데이터로 끝냅니다.
```

## v3.0 → v4.0 압축 원칙

| 항목 | v3.0 (10분) | v4.0 (3분) |

| 슬라이드 수 | 12장 | 5장 |
