│               │                           │                     │

## 슬라이드 5 — 솔루션: Before / After
> 목표: "소프트웨어가 어느 단계에 들어가는지" 직관적으로
> 청중별: 멘토 — 개입 지점 명확히

### 시각화 구성
> 2단 레이아웃 — 위: Before (빨간 X) / 아래: After (초록 체크)

**[Before]**
```
치과 스캔 → 의뢰서 전송 ···❌ 공백 ··· 수기 확인 → CAD → CAM → 납품
                                ↑
                    중복·누락·매칭오류 발생 지점
```

**[After]**
```
치과 스캔 → 의뢰서 전송 → ✅ DentalSync → CAD → CAM → 납품
                                ↑
                    자동 매칭·누락 탐지·알람·이력 생성
```

**발표 멘트 포인트**
> "저희가 채운 건 제작 공정이 아닙니다.
> 제작 시작 전, 아무도 없었던 자리입니다."

## 보충 1. 리메이크 1건 비용 크롤링 방법

> 슬라이드 4 스택 차트의 `[크롤링 예정]` 항목을 채우기 위한 가이드

### 채워야 할 수치

| 항목 | 현재 상태 | 크롤링 방법 |
|---|---|---|
| 소재비 (지르코니아 디스크) | **8만원** (확보) | — |
| 인건비 (CAD+CAM 재작업) | 미확보 | 아래 방법 참고 |
| 전기세 (밀링기·소결로) | 미확보 | 아래 방법 참고 |
| 배달비 (재납품) | 미확보 | 아래 방법 참고 |

### 인건비 역산 방법 (크롤링 없이 가능)
```
CAD 재작업 소요: 커스텀 어버트먼트 10~15분 / 자연치 크라운 약 5분 (강냉이닷컴 대표)
CAM 재작업 소요: 밀링 30~60분 (재료·형태 따라 다름)

최저시급 기준 (2026년 기준 크롤링 필요):
  → 인건비 = 시급 × (CAD 시간 + CAM 시간)
  → 기공사 실평균 시급은 월 220만원 ÷ 209시간 ≈ 1만 500원 수준으로 추산 가능
```

### 전기세 추산 방법
```
밀링기 소비전력: 일반적으로 1.5~3kW (기종별 상이)
소결로 소비전력: 3~6kW, 소결 시간 약 6~8시간

크롤링 키워드:
  "치과용 밀링기 소비전력" / "지르코니아 소결로 전기요금" / "CAD CAM 장비 전력"
  → 제조사 스펙시트 또는 덴탈2804 커뮤니티 검색
```

### 배달비
```
크롤링 불필요 — 택배사 고시가 기준 추산 가능:
  CJ대한통운·롯데택배 기준 소형 박스(보철물 케이스) 편도 약 4,000~5,000원
  재납품 = 왕복 약 8,000~10,000원
```

## 보충 2. 덴탈2804 커뮤니티 검증 방법

> 멘토 피드백 2회 공통 언급 — 발표 전 완료 시 슬라이드 9 트랙션이 크게 강화됨

### 왜 중요한가

현재 트랙션의 약점:
- 인터뷰 10건 ✅
- 파일럿 협의 3곳 ✅ (협의 중, 탐지 데이터 아직)
- **커뮤니티 반응 수치 ❌** ← 이게 빠지면 "현장 검증이 얕다"는 인상

커뮤니티 반응이 있으면:
- "실제 현업자들도 같은 문제를 말한다"는 독립 검증원 확보
- 인터뷰 10건의 신뢰도를 보강
- 슬라이드 9 트랙션에 수치 1개 추가 가능 ("커뮤니티 반응 N건 확인")

### 접근 방법

**덴탈2804 (치과기공사 커뮤니티)**

```
사이트: dental2804.com 또는 네이버 카페 검색
접근법: 직접 게시글 작성 or 기존 게시글 검색
```

**방법 A — 기존 게시글 검색 (수동 수집, 빠름)**

검색 키워드:
- "리메이크" / "재제작" / "의뢰서 오류" / "스캔 오류"
- "억울하게 다시 만들었다" / "치과에서 실수" / "파일 누락"
- "어버트먼트 오류" / "스캔바디 각도"

수집 항목:
- 게시글 수 / 댓글 반응 수
- 반복 등장하는 오류 유형
- "비용은 기공소가 낸다"는 언급 빈도

**방법 B — 직접 게시 후 반응 수집 (1~2주 소요)**

게시글 예시 (자연스럽게 문제 상황 공유):
```
"저희 기공소에서 의뢰서랑 스캔 파일 매칭 실수로
재제작이 월 2~3번 발생하는데 다른 곳도 이런 편인가요?
관리 방법 있으시면 공유 부탁드립니다."
```

수집 지표:
- 조회수 / 댓글 수 / 공감 수
- 댓글에서 확인할 3가지 패턴:
  1. 비용 부담 방식 (기공소가 다 낸다 vs 협의)
  2. 오류 유형 (스캔 오류 / 의뢰서 오류 / 파일 누락)
  3. 현재 대응책 (수기 체크리스트 / 전화 재확인)

### 트랙션 슬라이드 반영 방법

검증 완료 시 슬라이드 9 하단에 추가:
```
커뮤니티 반응 (덴탈2804)
  조회 N회 · 댓글 N건
  → "비용은 기공소가 낸다" 패턴 확인
  → "스캔 오류·누락은 전국 공통" 패턴 확인
  → 현재 대응책은 개인 습관(수기 체크리스트) 확인
```

### 주의사항
- 닉네임·원문·스크린샷 인용 금지 (익명·패턴 수준만 사용)
- 발표 자료에는 "커뮤니티 반응 패턴 확인"으로만 표기
- 수집 데이터는 부록에 패턴 요약으로만 정리
