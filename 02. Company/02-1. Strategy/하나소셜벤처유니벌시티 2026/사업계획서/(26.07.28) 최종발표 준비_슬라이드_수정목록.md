# CrownOps 하나소셜벤처 발표자료 수정 목록

> 대상 Figma: `하나소셜벤처` 페이지  
> 확인 기준: 2026-07-28 Figma 화면 구성 + 전달받은 슬라이드별 댓글

## 3줄 요약

- 본편은 **문장 중심 설명을 줄이고, 결론·숫자·사진만 보아도 이해되는 구조**로 전환한다.
- 솔루션은 2장에서 1장으로 합치고, 트랙션은 **개발/영업 2장**, 시장은 **국내/해외 로드맵 2장**으로 나눈다.
- 세부 기능·비용 산식·시나리오·정착가·영업이익률 등은 부록으로 이동하고, 본편에는 **가치·ROI·검증 결과·KPI**만 남긴다.

## 1. 전체 자료 공통 수정 원칙

### P0 — 반드시 반영

- [ ] **1장 1결론** 원칙 적용
  - 슬라이드 상단에서 결론을 먼저 제시한다.
  - 긴 메인 문장과 서브 문장을 연속으로 배치하지 않는다.
  - 본문을 읽지 않아도 도식·사진·숫자만으로 핵심이 이해되어야 한다.
- [ ] **글보다 숫자와 사진 중심**으로 전환
  - 설명문 → 핵심 수치, 전후 비교, 실제 사진, 인터뷰 인용, 기관·협력사 로고로 치환한다.
  - 숫자는 크게, 출처는 작게 배치한다.
- [ ] 기능 설명보다 **가치와 결과**를 먼저 제시
  - 핵심 가치: 비용 절감, 시간 절감, 거래 관계 보호, 법적·책임 리스크 감소.
  - 기능명(OCR, GATE, 파일 매칭 등)은 가치 설명 아래 보조 문구로만 사용한다.
- [ ] 본편과 부록의 역할 분리
  - 본편: 결론, 핵심 숫자, 사진, 검증 결과, KPI.
  - 부록: 세부 산식, 기능 설명, 시나리오, 논문·기사 원문, 시장 추정 방법, 예상 영업이익률, 가격 정착 과정.
- [ ] 현재 하단에 별도로 배치된 수정안 2장
  - `Slide 16:9 - 64` 산업구조 수정안
  - `Slide 16:9 - 65` 문제정의 수정안
  - 최종본 채택 후 기존 장표와 중복되지 않도록 하나만 남긴다.

### P1 — 강하게 권장

- [ ] 본편의 모든 긴 출처 목록을 각주 또는 참고자료로 이동한다.
- [ ] 협력 기공소·교육기관·멘토·자문 인물은 텍스트 목록 대신 로고와 얼굴 사진으로 표현한다.
- [ ] 아직 확보되지 않은 수치는 임의로 채우지 않고 `확인 필요` 상태로 표시한다.
- [ ] 다음 맞춤법·표현을 교정한다.
  - `잘못 됐는지` → `잘못됐는지`
  - `판전 기준` → `판정 기준`
  - `쓸수록` → `쓸수록`
  - `재료 ·케이스` → `재료·케이스`
  - `데이터가  학습합니다` → `데이터가 학습에 활용됩니다`

## ② 오프닝 문제 제기

**현재 프레임:** `Slide 16:9 - 60`  
**현재 핵심 문구:** “오류는 왜 항상 다 만든 뒤에야 발견될까요?”

### 수정

- [ ] 문제 정의에서 나올 핵심 손실을 이 장에서 먼저 제시한다.
- [ ] `검증 부재`, `의뢰서 오류`, `인상 채득 오류`, `재료·케이스 매칭 오류`를 단순 나열하지 말고 **오류 → 결과**로 연결한다.
  - 인상 채득 오류 → 환자 재내원
  - 파일·케이스 매칭 오류 → 잘못된 보철물 제작
  - 의뢰 정보 누락 → 전화 확인·납기 지연
  - 검증 부재 → 재제작 비용이 기공소에 전가
- [ ] 가능하면 충격을 주는 핵심 숫자 1개를 크게 제시한다.
  - 후보: `재제작률 10.1%`
  - 후보: `재제작 1건당 총손실 약 19~21만 원`
- [ ] 설명형 서브 문장은 삭제하거나 발표자 멘트로 이동한다.

**우선순위:** P0

- [ ] 그림만 보고도 치과와 기공소의 역할, 데이터 흐름, 책임 구조가 이해되도록 한다.
- [ ] 환자 진료부터 보철물 장착까지 모든 세부 단계를 동일 비중으로 표현하지 않는다.
- [ ] CrownOps가 개입하는 지점인 **인상 채득 직후·제작 착수 전**을 강조한다.

**제목 후보:**

**도식:**  
`치과: 인상 채득·의뢰 정보 생성` → `검증 공백` → `기공소: 설계·제작·재제작 비용 부담`

### 삭제·축소

- [ ] 이해관계자 범례와 반복 아이콘 축소.
- [ ] 상세 공정명은 핵심 단계만 남기고 나머지는 부록으로 이동.
- [ ] 기존 장표와 수정안 중 최종 1장만 유지.

**우선순위:** P0

## ④ 문제 정의

**현재 프레임:** `Slide 16:9 - 62`  
**수정안 프레임:** `Slide 16:9 - 65`

### 댓글 반영 방향

- [ ] 서브 메인 문장 “워크플로우에서 오류가 심어지는…” 삭제.
- [ ] 현재의 `오류 유형 / 사전 차단 불가 이유` 표를 **오류 유형 / 발생 결과 / 손실 가치** 구조로 변경한다.
- [ ] 기능적 문제보다 돈·시간·환자·거래 관계 측면에서 왜 나쁜지 설명한다.
- [ ] 산업 구조 장표에서 보여준 책임 전가 구조와 자연스럽게 연결한다.

### 권장 콘텐츠

| 오류 유형 | 현장에서 발생하는 결과 | 최종 손실 |
|---|---|---|
| 인상 변형·스캔 범위 누락 | 재채득, 환자 재내원 | 진료시간 손실, 환자 불만 |
| 마진 라인 불명확 | 설계 오류 또는 제작 불가 | 재설계·재제작 |
| STL 미도달·케이스 매칭 오류 | 다른 환자 파일로 제작 가능 | 전량 폐기, 책임 리스크 |
| 쉐이드·재료 정보 누락 | 전화 확인, 제작 대기 | 납기 지연, 업무 중단 |
| 교합 부적합 | 장착 단계에서 불량 발견 | 건당 약 19~21만 원 손실 |

### 시각화

- [ ] 오류별 실제 스캔 이미지 또는 현장 사진을 넣는다.
- [ ] 텍스트는 오류명과 결과 키워드만 남긴다.
- [ ] 각 행의 결과를 아이콘과 숫자로 표현한다.

**우선순위:** P0

## ⑦ 솔루션 — 2장을 1장으로 통합

**현재 프레임:**  
- `Slide 16:9 - 54`: 임상 파일 검증  
- `Slide 16:9 - 45`: 접수 조건 검증

### 댓글 반영 방향

- [ ] 두 솔루션 장표를 한 장으로 통합한다.
- [ ] AS-IS/TO-BE 상세 흐름은 솔루션 다음 장 또는 부록으로 이동한다.
- [ ] OCR, STL 대조, GATE 같은 기능명보다 **비용·시간·책임 리스크 감소**를 중심으로 설명한다.
- [ ] 제품 소개서처럼 보이는 기능 나열을 줄인다.
- [ ] 이 사업을 처음 보는 사람도 솔루션 가치를 이해할 수 있어야 한다.

### 권장 구조

**제목 후보:**  
`환자가 떠나기 전, 제작이 시작되기 전 오류를 막습니다`

| 검증 시점 | CrownOps가 막는 문제 | 고객 가치 |
|---|---|---|
| 인상 채득 직후 | 스캔 누락·형상 불량 | 환자 재내원과 재채득 감소 |
| 제작 착수 전 | 의뢰 정보 누락·파일 불일치 | 재제작 비용·전화 확인·납기 지연 감소 |

**보조 기능 문구:**  
`스캔 품질 판정 · 의뢰서 OCR · 파일 자동 대조 · 누락/불일치 탐지`

### 삭제·이동

- [ ] `AS-IS / TO-BE` 상세 단계 → 부록.
- [ ] `건당 20만 원` 반복 문구 → 한 번만 강조.
- [ ] 기능별 상세 작동 과정 → 제품 상세 부록.

**우선순위:** P0

## ⑧ 비즈니스 모델

**현재 프레임:** `Slide 16:9 - 57`

### 댓글 반영 방향

- [ ] 구독료와 핵심 수치가 장표의 중심이 되도록 재구성한다.
- [ ] 치과 무상 제공 전략은 본 장표에서 축소하고 트랙션·향후 계획으로 이동한다.
- [ ] `GATE 1`, `GATE 2` 용어는 외부 심사위원에게 낯설므로 제거한다.
- [ ] ROI를 핵심으로 표현한다.
- [ ] 예상 영업이익률과 정착가 형성 과정은 트랙션 또는 부록으로 이동한다.

### 권장 핵심 숫자

- `기공소 월 구독료: 50만 원`
- `중형 기공소 월 재제작 손실: 약 380~420만 원`
- `재제작 3건 방지 시 손익분기`
- `구독료는 기존 월 손실의 약 1/8`

### 반드시 재검증할 부분

- [ ] 현재 문구인 `20건 중 3건 방지`와 실제 손익분기 계산의 단위가 맞는지 검증한다.
  - 월 재제작 20건 중 3건인지, 전체 케이스 20건 중 3건인지 명확히 해야 한다.
- [ ] `방지율 15%`의 계산 근거를 부록에 제시한다.
- [ ] 월 10만 원 진입가와 월 50만 원 정착가의 적용 시점·조건을 정리한다.

### 본편에서 제거 또는 축소

- [ ] `500건까지 무료 → 절감 데이터 확보 → 리포트 제시 후 전환` 상세 시나리오.
- [ ] 치과 무상 제공 이유에 대한 긴 설명.
- [ ] 데이터 흐름을 의미하는 중복 화살표와 라벨.

**우선순위:** P0

## ⑪ 신규 — 경쟁사 또는 기존 대안

### 목적

`경쟁 제품이 없다`가 아니라 `고객이 현재 돈과 시간을 써서 해결하는 방식이 있다`는 점을 보여준다.

### 비교 대상 후보

| 기존 대안 | 현재 방식 | 한계 |
|---|---|---|
| 기공사의 육안 확인 | 파일을 열어 경험으로 판단 | 사람마다 기준이 다르고 누락 가능 |
| 전화·카카오톡 재확인 | 정보가 없을 때 치과에 연락 | 업무 중단, 관계 부담, 기록 분산 |
| 스캐너 제조사 도구 | 해당 장비 안에서 기본 품질 확인 | 제조사별 분절, 기공소 접수 정보와 미연결 |
| 재제작 후 사후 대응 | 장착 실패 후 다시 제작 | 가장 비싸고 환자 재내원 발생 |

### 수정

- [ ] 실제 사용 중인 대안의 화면 또는 현장 사진을 추가한다.
- [ ] 비교 기준은 기능 수가 아니라 `발견 시점`, `비용`, `책임`, `데이터 축적`으로 잡는다.
- [ ] 경쟁사 유무와 제품명을 별도로 조사해 부록에 상세 비교표를 만든다.

## 6. 작업 우선순위

### 1차 — 스토리 구조 확정

- [ ] 산업 구조, 문제 정의, 근본 원인의 결론을 각각 한 문장으로 확정.
- [ ] 솔루션 2장을 1장으로 통합.
- [ ] 문제의 크기 장표 중복 제거.
- [ ] 본편 16장 순서 확정.

### 2차 — 숫자·증거 확보

- [ ] ROI 계산 검증.
- [ ] 시장 성장률과 치과 시장 수치 확보.
- [ ] 개발·영업·덴티룸 트랙션 수치 확보.
- [ ] 인터뷰 사진, MVP 화면, 협력 로고 수집.

### 3차 — 디자인 수정

- [ ] 모든 장표의 긴 설명문 삭제.
- [ ] 숫자·사진·도식 확대.
- [ ] 출처 표기 형식 통일.
- [ ] 프레임명과 실제 발표 순서 정리.

### 4차 — 부록 강화

- [ ] 본편에서 빠진 세부 자료를 모두 부록으로 이동.
- [ ] 예상 질문에 대응하는 산식·근거·기술·규제 자료 추가.
- [ ] 발표 리허설 후 본편에서 읽히지 않는 문장 추가 삭제.
