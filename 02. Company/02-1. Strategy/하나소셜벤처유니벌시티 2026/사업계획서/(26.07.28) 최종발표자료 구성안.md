## Slide 1. 문제 제기

**헤드라인:** `오류는 왜 항상 다 만든 뒤에야 발견될까요?`
**핵심 메시지:** 재제작은 기공소 매출의 10%를 태운다

**본문 콘텐츠**

| 오류 유형 | 발생 결과 |
|---|---|
| 인상 채득 오류 | 환자 재내원 + 재스캔 |
| 파일·케이스 매칭 오류 | 잘못된 보철물 제작 |
| 의뢰 정보 누락 | 전화 확인 + 납기 지연 |
| 검증 공백 | 재제작 비용 → 기공소 전가 |

**크게 배치할 숫자 (후보 1개 선택)**
- `재제작률 10.1%` (출처: 자체 인터뷰 조사 또는 남신은 2018 확인 필요)
- `재제작 1건당 약 19~21만 원` (출처: 인터뷰 기반 산식)

**시각 방향**
- 오류 유형 4개를 아이콘 + 결과 키워드로 표현
- 긴 설명문 없이 각 행을 1줄로 제한

**삭제**
- 서브 메인 설명문 전부
- 기능 이름(OCR, GATE 등) 언급

## Slide 2. 산업구조

**헤드라인:** `오류는 치과에서 시작되지만, 손실은 기공소가 부담합니다`
**핵심 메시지:** 치과→기공소 구조에서 오류 유입 지점을 한눈에 보여준다

**본문 콘텐츠**

도식 (좌→우 흐름):
```
치과 (진료·스캔·의뢰서 작성)
  ↓ [오류 유입 지점 — 강조]
기공소 (접수·설계·제작)
  ↓
보철물 장착 / 재제작
```

강조 표시:
- 치과→기공소 화살표: **빨간색 또는 주황색** + "오류 정보 유입" 라벨
- 기공소 하단: "재제작 비용 전가" 라벨

**데이터 (도식 위 배치)**
- `원인의 63.7%: 치과 측 임상 인상채득 오류` (출처: 남신은, 2018)
- `비용의 67.4%: 기공소 부담` (출처: 확인 필요)
- 덴티룸 이야기: **트랙션 슬라이드로 이동**

**시각 방향**
- 그림만 보고 전체 관계가 이해되어야 함
- 이해관계자 범례·상세 공정명 → 최소화 또는 삭제
- CrownOps 개입 지점(제작 착수 전)을 도식 위에 명시

**삭제**
- 모든 설명형 문장
- 수혜자 목록

## Slide 3. 문제 정의

**헤드라인:** `오류 유형마다 돈과 시간이 빠져나갑니다`
**핵심 메시지:** 기능 문제가 아니라 가치 손실의 문제다

**본문 콘텐츠**

| 오류 유형 | 현장 결과 | 손실 |
|---|---|---|
| 인상 변형·스캔 범위 누락 | 환자 재내원·재스캔 | 체어타임 손실, 환자 신뢰 저하 |
| 마진 불명확 | 설계 불가 또는 제작 후 불량 | 재설계·전량 재제작 |
| STL 미도달·케이스 매칭 오류 | 다른 환자 파일로 제작 가능 | 전량 폐기, 법적 책임 리스크 |
| 쉐이드·재료 정보 누락 | 치과에 전화 확인 | 납기 지연, 업무 중단 |
| 교합 부적합 | 장착 단계에서 불량 발견 | 건당 약 **19~21만 원** 손실 |

**시각 방향**
- 실제 오류 스캔 이미지 또는 현장 사진 삽입
- 텍스트는 유형명 + 결과 키워드만
- 손실 수치(원·시간)를 강조색으로 표현

**삭제**
- 서브 메인 문장 ("워크플로우에서 오류가 심어지는…")
- "기능적으로 왜 문제인가" 설명 → 가치 손실로 대체

## Slide 4. 비용 부담 구조

**헤드라인:** `재제작은 발생 원인과 비용 부담 주체가 다릅니다`
**핵심 메시지:** 원인의 63.7%는 치과, 비용의 67.4%는 기공소

**본문 콘텐츠**

크게 표시할 숫자 3개:
- `10.1%` — 재제작 발생 비율
- `63.7%` — 치과 측 임상 인상채득 오류 비중 (출처: 남신은, 2018)
- `67.4%` — 기공소 비용 부담 비중 (출처: 확인 필요)

연간 손실 요약 (1줄):
- `월 200건 기공소 기준 → 재제작 손실 연 약 4,560~5,040만 원`

**시각 방향**
- 숫자 3개를 크고 명확하게 배치 (차콜 또는 진한 주황색, 살구색 금지)
- "원인 주체 ← → 비용 부담 주체" 구조를 간단한 양방향 도식으로 표현
- 세부 산식은 부록으로 이동

**삭제**
- 참고문헌 전체 목록 → 각주 또는 부록
- 월별 시나리오 세부 내역 → 부록

## Slide 5. 근본 원인

**헤드라인:** `구조가 문제라서 20년째 해결되지 않았습니다`
**핵심 메시지:** 개인의 실수가 아니라 구조적 고착

**본문 콘텐츠**

결과 위주로 3개만:

| 근본 원인 | 결과 |
|---|---|
| 오류를 만든 곳과 비용을 내는 곳이 다름 | 오류 예방 투자 유인 없음 |
| 기공소는 거래처 이탈 우려로 반려 불가 | 불완전한 케이스도 제작 착수 |
| 기공소 법인화 불가 → 외부 투자·혁신 불가 | 구조 개선 주체 부재 |

**외부 자료 (충격 근거)**
- 기공사 국시 응시자 10년간 연평균 **3.7% 감소** (출처: 치의신보)
- 2040년 기공사 **최대 1만4,000명 부족** 전망 (출처: 치과신문)
- 기공소 수가: 1980~90년대보다 낮아진 수준 (출처: 덴탈아리랑)
- 기공사 초봉 월 **100만 원** 수준, 최저임금 미달 사례 (출처: 매일노동뉴스)

**인터뷰 인용 (익명)**
> "잘 만들었으나 억울하게 다시 만들어야 되는 상황" — 현직 기공소 대표

**시각 방향**
- 메인·서브 설명문 없이 결과 3개만 카드로 배치
- 기사 헤드라인 또는 인터뷰 인용을 인용부호 시각 요소로 표현
- 법 조항은 본문 배제, 각주 처리

**삭제**
- 수혜자 목록 전부 → 솔루션 이후 또는 사회적 가치 장표로

## Slide 6. 솔루션 (2장 통합 → 1장)

**헤드라인:** `제작이 시작되기 전, 오류를 막습니다`
**핵심 메시지:** CrownOps는 제작 전 검증 게이트다

**본문 콘텐츠**

가치 3개 (메인):
| 검증 시점 | CrownOps가 막는 문제 | 고객 가치 |
|---|---|---|
| 인상 채득 직후 | 스캔 누락·형상 불량 | 환자 재내원 감소 |
| 제작 착수 전 | 의뢰 정보 누락·파일 불일치 | 재제작 비용·납기 지연 감소 |
| 배송 전 | 케이스·라벨 불일치 | 오배송·법적 리스크 감소 |

서브 기능 (작게):
`스캔 품질 판정 · 의뢰서 OCR · 파일 자동 대조 · 누락/불일치 탐지 · 케이스·라벨 검증`

AS-IS / TO-BE:
- 본 슬라이드에서는 제거
- 솔루션 다음 슬라이드 또는 부록으로 이동

**시각 방향**
- 실제 MVP 화면을 오른쪽에 크게 배치
- 왼쪽에 가치 3개를 간결하게 배치
- 기능명(GATE 1/2/3, OCR 등)은 본문에서 제거
- 이 사업을 처음 보는 사람도 가치가 이해되어야 함

**삭제**
- 기존 2장의 상세 작동 흐름 → 부록
- AS-IS/TO-BE 도식 → 부록

## Slide 7. 비즈니스 모델 / ROI

**헤드라인:** `재제작 3건만 막아도 구독료를 회수합니다`
**핵심 메시지:** 월 50만 원 구독료는 기공소 월 손실의 1/8

**본문 콘텐츠**

크게 표시할 숫자:
- `월 50만 원` — 기공소 구독료
- `약 400만 원` — 중형 기공소(월 200건) 월 재제작 잠재 손실
- `3건` — 손익분기에 필요한 최소 예방 케이스 수

ROI 계산 (1표):
| 항목 | 수치 |
|---|---|
| 월 제작량 | 200건 |
| 재제작률 | 10% = 월 20건 |
| 건당 손실 | 약 20만 원 |
| 월 잠재 손실 | 약 400만 원 |
| CrownOps 구독료 | 월 50만 원 |
| 손익분기 | 3건 방지 시 회수 |

연간 비교:
- 연간 잠재 손실: **4,560~5,040만 원**
- 연간 구독료: **600만 원**
- 구독료 = 잠재 손실의 약 **12~13%**

과금 구조:
`무료 파일럿 → 유료 전환 (월 50만 원)`

**시각 방향**
- `월 50만 원` 숫자를 가장 크게
- ROI 계산을 심플한 표 또는 인포그래픽으로
- 치과 무상 제공 → 트랙션 또는 향후 계획으로 이동

**삭제**
- 정착가 전환 시나리오 → 부록
- 예상 영업이익률 → 부록
- 월 10만 원 가격 언급 → 삭제 또는 각주

## Slide 8. 경쟁사 / 기존 대안 (신규)

**헤드라인:** `기존에는 사람이 기억하고 전화로 확인했습니다`
**핵심 메시지:** 제작 전 검증에 특화된 솔루션은 존재하지 않는다

**본문 콘텐츠**

| 기존 방법 | 실제 현장 방식 | 한계 |
|---|---|---|
| 육안 + 수기 일지 | 수기 일지 + 빨간 펜 V자 체크 | 누락 가능, 이력 없음 |
| 전화·카카오톡 재확인 | 정보 불일치 시 치과에 연락 | 업무 중단, 관계 부담 |
| 스캐너 내장 기능 | 스캐너별 분절, 기공소 미연결 | 제조사 생태계 종속 |
| 재제작 후 사후 대응 | 장착 실패 후 재제작 | 가장 비싸고 환자 재내원 |

글로벌 경쟁 솔루션:
- **LabStar, 3Shape Order Management**: 케이스 추적·청구 중심 → 제작 전 오류 탐지 없음
- **이마고웍스**: AI 디자인 중심 → 누적투자 300~400억, BEP 2028년 예상
- **덴트버드**: AI 디자인 건당 과금 → 티핏 6개월 사용 후 중단

CrownOps 차별점:
`CAD 착수 전 품질 게이트` — 기존 솔루션이 없는 포지션

**시각 방향**
- 기존 방식 사진 (수기 일지 캡처 등) 넣기
- 비교 기준: 기능 수 ✗ → 발견 시점 / 비용 / 데이터 축적 ✓

## Slide 9. 국내 시장규모

**헤드라인:** `기공소에서 시작해 치과로, 국내에서 글로벌로 확장합니다`
**핵심 메시지:** 국내 기공소가 초기 시장, 치과는 확장 채널

**본문 콘텐츠**

| 구분 | 대상 | 산식 | 규모 |
|---|---|---|---|
| SOM | 국내 성장형 기공소 (초기 영업 대상) | 직접 영업 가능 기공소 수 × 연 600만 원 | 확인 필요 |
| SAM | 국내 전체 기공소 + 디지털 치과 | 기공소 4,635개 × 연 600만 원 | **약 278억 원** |
| TAM | 글로벌 치과기공 시장 | — | **USD 242억 달러** (2025) / CAGR 6.8% |

국내 기공 시장 추가 데이터:

## Slide 12. 영업 / 커뮤니티 트랙션

**헤드라인:** `16곳의 현장 검증이 문제의 실재를 확인했습니다`
**핵심 메시지:** 사진과 숫자로 현장 검증 증거를 보여준다

**본문 콘텐츠**

가설 → 검증 결과:
| 가설 | 검증 활동 | 결과 |
|---|---|---|
| 기공소는 재제작 손실을 줄일 도구가 필요하다 | 기공소 3곳 공정 관찰 인터뷰 | 방문 당일 오류 케이스 2건 실시간 목격 |
| 오류 비용은 기공소가 부담한다 | 비용 구조 심층 인터뷰 | 6개월 내 재제작 100% 기공소 부담 확인 |
| 치과도 스캔 품질 문제를 인지한다 | 치과 2곳 인터뷰 | 정보 재확인 요청 경험 공통 확인 |

수치 현황:
- 누적 인터뷰: **16곳 이상** (기공소 3, 치과 2, 교수 3, 업체 2, 기타)
- 파일럿 협의: **3곳** 진행 중
- 파일럿 확약 / LOI: **확인 필요** (발표 전 최소 1건 확보 목표)

덴티룸 커뮤니티:
- 게시글 조회수·반응 수: **직접 수치 확인 필요**
- 커뮤니티 활동 화면 캡처 삽입

**시각 방향**
- 기공소 현장 방문 사진 필수
- 인터뷰 현장 사진, 장비, 수기 일지 사진 포함
- 계약 의향서 또는 LOI 사진 (확보 시)
- 숫자는 크게, 텍스트는 최소화
