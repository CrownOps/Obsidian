## Slide 1. 문제 제기

**헤드라인:** `오류는 왜 항상 다 만든 뒤에야 발견될까요?`
**핵심 메시지:** 재제작은 기공소 매출의 10%를 태운다

**본문 콘텐츠**

| 오류 유형 | 발생 결과 |
|---|---|
| 인상 채득 오류 | 환자 재내원 + 재스캔 |
| 파일·케이스 매칭 오류 | 잘못된 보철물 제작 |
| 의뢰 정보 누락 | 전화 확인 + 납기 지연 |
| 검증 공백 | 재제작 비용 → 기공소 전가 |

**크게 배치할 숫자**
- `재제작률 10.1%` — 지르코니아 기준 (출처: 자체 인터뷰 / 남신은 2018 확인 필요)

**재제작 손실 구조 (지르코니아 기준 / 항목별 세부 설명 → 부록 A)**

| 손실 유형 | 건당 추정액 |
|---|---|
| 직접 손실 (재료비·기공료) | 약 **19~21만 원** |
| 간접 손실 (납기 지연·업무 중단·거래처 신뢰) | 미정 |
| 월 총 손실 개산 (월 200건 × 재제작률 10%) | 약 **400만 원 / 월** |

**시각 방향**
- 오류 유형 4개를 아이콘 + 결과 키워드로 표현
- 긴 설명문 없이 각 행을 1줄로 제한

**삭제**
- 서브 메인 설명문 전부
- 기능 이름(OCR, GATE 등) 언급

## Slide 2. 산업구조

**헤드라인:** `오류는 치과에서 시작되지만, 손실은 기공소가 부담합니다`
**핵심 메시지:** 치과→기공소 구조에서 오류 유입 지점을 한눈에 보여준다

**본문 콘텐츠**

도식 (좌→우 흐름):
```
치과 (진료·스캔·의뢰서 작성)
  ↓ [오류 유입 지점 — 강조]
기공소 (접수·설계·제작)
  ↓
보철물 장착 / 재제작
```

강조 표시:
- 치과→기공소 화살표: **빨간색 또는 주황색** + "오류 정보 유입" 라벨
- 기공소 하단: "재제작 비용 전가" 라벨

**데이터 (도식 위 배치)**
- `원인의 63.7%: 치과 측 임상 인상채득 오류` (출처: 남신은, 2018)
- `비용의 67.4%: 기공소 부담` (출처: 확인 필요)
- 덴티룸 이야기: **트랙션 슬라이드로 이동**

**시각 방향**
- 그림만 보고 전체 관계가 이해되어야 함
- 이해관계자 범례·상세 공정명 → 최소화 또는 삭제
- CrownOps 개입 지점(제작 착수 전)을 도식 위에 명시

**삭제**
- 모든 설명형 문장
- 수혜자 목록

## Slide 3. 문제 정의

**헤드라인:** `오류 유형마다 돈과 시간이 빠져나갑니다`
**핵심 메시지:** 기능 문제가 아니라 가치 손실의 문제다

**본문 콘텐츠**

| 오류 유형 | 현장 결과 | 정량 손실 | 비고 |
|---|---|---|---|
| 인상 변형·스캔 범위 누락 | 환자 재내원·재스캔 | 재제작 오류 원인의 **63.7%** 차지 / 환자 체어타임 **30~60분** 소실 | 63.7% → 남신은 2018 (확인됨) / 체어타임 → 추정, 현장 확인 필요 |
| 마진 불명확 | 설계 불가 → 전량 재제작 | 건당 **19~21만 원** 직접 손실 | 확인됨 (부록 A) |
| STL 미도달·케이스 매칭 오류 | 잘못된 환자 파일로 제작 → 폐기 | 건당 **19~21만 원** + 법적 책임 리스크 | 비용 확인됨 / 법적 리스크는 정성 표현 유지 |
| 쉐이드·재료 정보 누락 | 치과 재확인 전화 | 케이스당 **10~30분** 업무 중단 / 납기 **1~2일** 지연 | 인터뷰 기반 추정, 현장 확인 필요 |
| 교합 부적합 | 장착 단계 불량 발견 → 재제작 | 건당 **19~21만 원** + 환자 재예약 | 확인됨 (부록 A) |

> **손실 합산 기준 (슬라이드 하단 또는 콜아웃)**
> 월 200건 기공소 × 재제작률 10% = **월 20건 재제작 → 월 약 400만 원** 잠재 손실

> ⚠️ **수치 확인 필요**: 체어타임(30~60분), 전화 확인 소요 시간(10~30분), 납기 지연(1~2일)은 인터뷰 기반 추정치. 발표 전 파일럿 기공소 1곳 이상에서 실측·확인 권장.

**시각 방향**
- 실제 오류 스캔 이미지 또는 현장 사진 삽입
- 텍스트는 유형명 + 결과 키워드만
- **확인된 수치(원·시간)를 강조색으로 표현**, 추정치는 별도 표기 또는 각주 처리

**삭제**
- 서브 메인 문장 ("워크플로우에서 오류가 심어지는…")
- "기능적으로 왜 문제인가" 설명 → 가치 손실로 대체

## Slide 4. 비용 부담 구조

**헤드라인:** `재제작은 발생 원인과 비용 부담 주체가 다릅니다`
**핵심 메시지:** 원인의 63.7%는 치과, 비용의 67.4%는 기공소

**본문 콘텐츠**

크게 표시할 숫자 3개:
- `10.1%` — 재제작 발생 비율
- `63.7%` — 치과 측 임상 인상채득 오류 비중 (출처: 남신은, 2018)
- `67.4%` — 기공소 비용 부담 비중 (출처: 확인 필요)

연간 손실 요약 (1줄):
- `월 200건 기공소 기준 → 재제작 손실 연 약 4,560~5,040만 원`

**시각 방향**
- 숫자 3개를 크고 명확하게 배치 (차콜 또는 진한 주황색, 살구색 금지)
- "원인 주체 ← → 비용 부담 주체" 구조를 간단한 양방향 도식으로 표현
- 세부 산식은 부록으로 이동

**삭제**
- 참고문헌 전체 목록 → 각주 또는 부록
- 월별 시나리오 세부 내역 → 부록

## Slide 5. 근본 원인

**헤드라인:** `구조가 문제라서 20년째 해결되지 않았습니다` *(구조·운영)*
**핵심 메시지:** 개인의 실수가 아니라 구조적 고착

**본문 콘텐츠**

결과 위주로 3개만:

| 근본 원인                   | 정량 근거 (한국)                                         | 결과                   |
| ----------------------- | -------------------------------------------------- | -------------------- |
| 오류를 만든 곳과 비용을 내는 곳이 다름  | 임상 인상채득 오류 **63.7%** 치과 책임 / 비용의 **67.4%**는 기공소 부담 | 오류 예방 투자 유인 없음       |
| 기공소는 거래처 이탈 우려로 반려 불가   | *"잘 만들었으나 억울하게 다시 만들어야 되는 상황"* — 현직 기공소 대표 인터뷰     | 불완전한 케이스도 제작 착수      |
| 정보 단절 구조 — 치과↔기공소 소통 없음 | 재제작 원인 중 "부정확한 정보제공" **68.6%**                     | 전화·카톡으로 확인, 납기 지연 반복 |

**수치 출처**
- 63.7% (치과 측 임상 인상채득 오류): 남신은 2018 — 신종우 교수 미팅에서 확인
- 68.6% (부정확한 정보제공): 경희치대·신대 공동연구, 대한구강보건학회지 (수도권 기공소 120개소)
- 67.4% (기공소 비용 부담): 출처 확인 필요

> 참고 (부록용, 본문 제외): 미국 출처 — 치과 귀책 78% (LMT), 소통 실패 65% / 기공소 진입 전 오류 82% (TrazaLab·EVISmart) — 방향 동일, 한국 데이터 보완 시까지 부록 보관

> ⚠️ **검토 필요**: 아래 충격 근거 자료(인력 위기·수가 문제)는 산업 구조적 문제를 설명하나, 우리의 문제 정의(**리메이크 손실 + 법적 리스크**)와 직접적으로 핏이 맞지 않음.
> - **현재 방향**: 위 정량 근거로 대체 확정. 아래 인력·수가 자료는 부록으로 이동.

**부록으로 이동할 자료** (슬라이드 본문 제외)
- 기공사 국시 응시자 10년간 연평균 **3.7% 감소** (출처: 치의신보)
- 2040년 기공사 **최대 1만4,000명 부족** 전망 (출처: 치과신문)
- 기공소 수가: 1980~90년대보다 낮아진 수준 (출처: 덴탈아리랑)
- 기공사 초봉 월 **100만 원** 수준, 최저임금 미달 사례 (출처: 매일노동뉴스)

**인터뷰 인용 (익명)**
> "잘 만들었으나 억울하게 다시 만들어야 되는 상황" — 현직 기공소 대표

**시각 방향**
- 메인·서브 설명문 없이 결과 3개만 카드로 배치
- 기사 헤드라인 또는 인터뷰 인용을 인용부호 시각 요소로 표현
- 법 조항은 본문 배제, 각주 처리

**삭제**
- 수혜자 목록 전부 → 솔루션 이후 또는 사회적 가치 장표로

## Slide 5-2. 근본 원인 (법적 구조) — 신규

**헤드라인:** `법이 구조를 고정시켰습니다`
**핵심 메시지:** 오류가 반복되는 건 의지의 문제가 아니라 법적 구조의 문제다

**본문 콘텐츠**

| 법적 근본 원인                 | 법적 근거                                                                  | 결과                   |
| ------------------------ | ---------------------------------------------------------------------- | -------------------- |
| 기공소는 불완전 케이스를 반려할 권한이 없음 | 의료기사 등에 관한 법률 **제11조의3 제1항** — "치과기공사는 … 치과의사가 발행한 치과기공물제작의뢰서에 따라야 한다" | 오류 인지 후에도 제작 착수      |
| 책임은 치과, 손실은 기공소          | 의료사고 법적 책임 → 치과의사 (의료법) / 재제작 비용 → 기공소                                 | 오류를 낸 주체가 고칠 이유 없음   |
| 기공소 법인화 불가 → 외부 투자·혁신 불가 | 의료기사 등에 관한 법률 **제11조의2 제1항** — "치과의사 또는 치과기공사가 아니면 치과기공소를 개설할 수 없다"    | 구조 개선 주체가 법적으로 존재 불가 |

**시각 방향**
- 법 조항명은 각주 또는 작은 텍스트로
- 3개 카드 형태, 각 카드에 법적 근거 → 결과 흐름으로 표현
- 헤드라인 강조: "법이 고정시켰다"는 메시지를 시각적으로 강하게

## Slide 6. 솔루션 (2장 통합 → 1장)

**헤드라인:** `제작이 시작되기 전, 오류를 막습니다`
**핵심 메시지:** CrownOps는 제작 전 검증 게이트다

**본문 콘텐츠**

**GATE 1. 스캔 파일 품질 판정**

탐지 대상: 스캔 범위 누락 / 인상 변형 / 형상 불량

- 제작 착수 전 불량 스캔 차단 → 환자 재내원 없이 재스캔 요청 가능
- 오류 원인의 **63.7%** (임상 인상채득 오류)를 가장 앞 단계에서 제거
- 불량 스캔으로 만들어진 보철물 폐기 비용 **19~21만 원** 회피
- 수기 육안 검수 → 자동 판정으로 대체

**GATE 2. 의뢰서 디지털화 (OCR + 정보 검증)**

탐지 대상: 쉐이드·재료 정보 누락 / 케이스 매칭 오류 / STL 미도달

- 치과 재확인 전화 제거 → 케이스당 **10~30분** 업무 중단 없음
- 납기 지연 **1~2일** 회피
- 케이스 매칭 오류 사전 차단 → 다른 환자 보철물 오제작·법적 책임 리스크 제거
- 검증 이력 자동 저장 → 분쟁 발생 시 근거 데이터 확보

AS-IS / TO-BE:
- 본 슬라이드에서는 제거
- 솔루션 다음 슬라이드 또는 부록으로 이동

**시각 방향**
- 실제 MVP 화면을 오른쪽에 크게 배치
- 왼쪽에 가치 3개를 간결하게 배치
- 기능명(GATE 1/2/3, OCR 등)은 본문에서 제거
- 이 사업을 처음 보는 사람도 가치가 이해되어야 함

**삭제**
- 기존 2장의 상세 작동 흐름 → 부록
- AS-IS/TO-BE 도식 → 부록

> **[참고] 리메이크 위주 가치 설명 — 검토용 초안** *(현행 슬라이드 수정 없음, 아래 내용은 보고 후 반영 여부 결정)*
>
> **헤드라인 후보:** `재제작 3건만 막으면 구독료가 나옵니다`
>

**본문 콘텐츠**

- `약 400만 원` — 중형 기공소(월 200건) 월 재제작 잠재 손실
- `3건` — 손익분기에 필요한 최소 예방 케이스 수

ROI 계산 (1표):
| 항목 | 수치 |
|---|---|
| 월 제작량 | 200건 |
| 재제작률 | 10% = 월 20건 |
| 건당 손실 | 약 20만 원 |
| 월 잠재 손실 | 약 400만 원 |
| CrownOps 구독료 | 월 50만 원 |
| 손익분기 | 3건 방지 시 회수 |

연간 비교:
- 연간 잠재 손실: **4,560~5,040만 원**
- 연간 구독료: **600만 원**
- 구독료 = 잠재 손실의 약 **12~13%**

과금 구조:
`무료 파일럿 → 유료 전환 (월 50만 원)`

**시각 방향**
- `월 50만 원` 숫자를 가장 크게
- ROI 계산을 심플한 표 또는 인포그래픽으로
- 치과 무상 제공 → 트랙션 또는 향후 계획으로 이동

**삭제**
- 정착가 전환 시나리오 → 부록

## Slide 13. 향후 계획 / KPI / 데이터 플라이휠 (신규)
