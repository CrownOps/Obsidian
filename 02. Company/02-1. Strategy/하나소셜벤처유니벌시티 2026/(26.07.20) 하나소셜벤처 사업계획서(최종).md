# 0. 전체 사업 요약

## 사업명

**CrownOps by Paraegis**

## 한 줄 정의

> **CrownOps는 치과기공소가 CAD 작업 파일을 만들기 전에 의뢰서·스캔 파일·제작 조건을 확인해, 작업 가능한 케이스와 검증이 필요한 케이스를 구분하는 제작 전 검증 SaaS입니다.**

## 해결하려는 문제

치과에서 기공소로 전달되는 의뢰서, 스캔 파일, 재료, 쉐이드, 임플란트 관련 정보가 여러 채널과 서로 다른 시점에 도착합니다. 현재 기공소는 이를 작업자의 기억과 수작업 대조에 의존해 확인하고 있습니다. 정보가 빠지거나 잘못 연결된 상태에서 제작이 시작되면 재작업, 납기 지연, 재료 폐기, 거래처와의 책임 갈등이 발생합니다.

## 고객

디지털 케이스가 많고, 여러 작업자와 거래처를 운영하며, 대표가 모든 케이스를 직접 확인하기 어려운 성장형 치과기공소

## 해결 방식

의뢰서와 스캔 파일을 한 케이스로 묶고, 제작에 필요한 필수 정보를 규칙 기반으로 확인합니다. 모든 케이스를 다시 입력하게 하는 것이 아니라, 누락·불일치 가능성이 있는 케이스만 분리해 작업자·책임자·거래처가 확인하도록 합니다.

## 수익모델

20케이스 무료 프리체크 → 4주 파일럿 → 월 구독형 B2B SaaS

## 사회적 가치

- 치과기공사의 반복 확인과 무상 재작업 부담 완화
- 재료 폐기와 불필요한 배송·재생산 감소
- 치과의 재확인 업무와 환자의 재내원·치료 지연 가능성 완화
- 지역 기공소의 디지털 업무 표준화와 청년 치과기공사의 현장 적응 지원

## 6개월 목표

- 실제 기공소 3곳 파일럿
- 누적 1,000케이스 검증
- 제작 전 예방 가능 오류 유형과 손실액 실측
- 최소 2곳 유료 전환 검증
- 현직 치과기공사 도메인 리드 영입 또는 핵심 팀 합류 확정

# 1. 오프닝

## Slide 1. 보철물 제작의 첫 공정은 설계가 아니라 검증이어야 합니다

### 핵심 메시지

> **CrownOps는 더 빨리 만드는 프로그램이 아니라, 잘못 만들기 전에 멈추게 하는 첫 번째 공정입니다.**

### 본문

치과에서 사용하는 크라운·브릿지·임플란트 보철물은 환자마다 다르게 제작됩니다. 치과는 환자의 치아 정보와 제작 조건을 의뢰서와 스캔 파일로 치과기공소에 전달하고, 기공소는 이를 바탕으로 설계와 제작을 시작합니다.

하지만 실제 현장에서는 한 건의 정보가 하나의 완성된 주문으로 도착하지 않습니다.

- 의뢰서는 종이·사진·PDF·메신저로,
- 스캔 파일은 3Shape·Medit·이메일·파일 서버로,
- 재료 변경과 추가 요청은 전화·카카오톡으로,

서로 다른 시간과 채널을 통해 들어옵니다.

CrownOps는 흩어진 정보를 하나의 케이스로 묶고, CAD 작업 파일을 만들기 전에 **지금 제작을 시작해도 되는지** 확인하는 제작 전 검증 체크게이트입니다.

### 권장 화면

```text
치과
  ↓
의뢰서 / 스캔 파일 / 메신저 / 전화
  ↓
[CrownOps 제작 전 검증]
  ↓
작업 가능 / 검증 필요 / 외부 검증 요청
```

### 한 줄 차별성

> 기존 프로그램이 접수·청구·공정을 관리한다면, CrownOps는 실제 설계를 시작하기 전에 **“이 케이스를 지금 만들어도 되는가”**를 확인합니다.

# 2. 문제정의

## Slide 3. 문제 1 — 한 건의 주문이 여러 경로로 나뉘어 도착합니다

### 핵심 메시지

> 기공소가 받는 것은 하나의 완성된 주문이 아니라, 서로 다른 시간과 채널로 도착하는 정보 조각입니다.

### 현장 흐름

| 정보 | 주요 수신 경로 | 발생 가능한 문제 |
|---|---|---|
| 의뢰서 | 종이, 사진, PDF, 메신저 | 의뢰서 누락, 최신본 혼동 |
| 스캔 파일 | 3Shape, Medit, 이메일, 서버 | 미도착, 중복, 다른 케이스와 오연결 |
| 제작 조건 | 의뢰서, 전화, 카카오톡 | 재료·쉐이드·치아번호 상충 |
| 임플란트 정보 | 의뢰서, 스캔 데이터, 별도 메모 | 스캔바디·부품 정보 확인 누락 |

담당자는 환자명, 치과명, 치아번호, 작업 종류를 기준으로 이 정보들이 같은 케이스인지 직접 판단합니다. 이름 규칙이 다르거나 파일이 늦게 도착하면, 파일이 있어도 찾지 못하거나 잘못된 케이스에 연결될 수 있습니다.

### 현장 비유

> 옷은 택배로 보내고, 치수는 문자로, 원단 요청은 전화로, 납기는 이메일로 따로 보내는 것과 같습니다.

---

## Slide 4. 문제 2 — 제작을 시작해도 되는지 판단하는 표준이 없습니다

### 핵심 메시지

> 현재의 검증 시스템은 프로그램이 아니라 숙련자의 기억과 습관입니다.

### 현재 확인 과정

1. 정식 의뢰서가 있는지 찾습니다.
2. 각 스캐너 플랫폼과 메일에서 파일 도착 여부를 확인합니다.
3. 의뢰서와 파일의 환자명·치아번호·작업 종류를 비교합니다.
4. 재료·쉐이드·임플란트 정보를 다시 확인합니다.
5. 애매하면 치과나 책임자에게 전화합니다.
6. 확인 결과는 메모, 포스트잇, 수기 장부 또는 개인 기억에 남습니다.

### 문제의 본질

기공소마다 확인 방식이 다르고, 바쁜 시간에는 검토 단계가 생략될 수 있습니다. 담당자가 바뀌면 기준도 함께 사라집니다.

> **작업자의 부주의 문제가 아니라, 제작 시작 조건이 구조화되어 있지 않은 프로세스 문제입니다.**

---

## Slide 5. 문제 3 — 오류는 완성 후 발견되고, 손실은 현장에 남습니다

### 핵심 메시지

> 산업 전체 재제작 문제 중 CrownOps는 제작 전에 발견 가능한 누락·불일치 오류를 우선 해결합니다.

2018년 치과기공소 대표·임원 126명을 대상으로 한 예비조사에서는 치과보철물의 전체 재제작률이 10.1%, CAD/CAM 영역의 재제작률이 11.8%로 보고됐습니다. 원인과 관계없이 기공소가 재제작 비용을 전액 부담한다고 응답한 비율은 67.4%였습니다.[^2]

다만 모든 재제작을 CrownOps가 막을 수 있는 것은 아닙니다. 환자 구강 상태 변화, 임상 인상 오류, 설계·가공 자체의 품질 문제는 별도의 영역입니다.

### CrownOps가 겨누는 예방 가능 오류

- 정식 의뢰서 누락
- 스캔 파일 미도착·중복·오연결
- 환자명·치아번호·작업 종류 불일치
- 재료·쉐이드 누락 또는 상충
- 임플란트·스캔바디 정보 확인 누락
- 변경 요청이 제작 담당자에게 전달되지 않은 상태

### 경제적 손실

- 재료비·인건비·전기료·배송비 이중 지출
- 납기 지연과 추가 확인 시간
- 거래처와의 책임 갈등

### 사회적 손실

- 치과기공사의 반복 노동과 판단 부담
- 재료 폐기와 불필요한 재생산
- 치과의 재확인 업무 증가
- 환자의 재내원·치료 지연 가능성

### 핵심 문장

> **오류는 전달 과정에서 발생하지만, 손실과 책임은 현장에 남습니다.**

# 3. 해결책

## Slide 6. 해결책 — 제작 라인 앞에 디지털 검사대를 둡니다

### 핵심 메시지

> CrownOps는 기공소 업무 전체를 바꾸지 않고, CAD 작업 파일 생성 전 한 번의 검증 단계를 추가합니다.

### 작동 흐름

```text
의뢰서·스캔 파일 수신
→ 같은 환자·작업 정보로 케이스 묶기
→ 필수 정보 존재 여부 확인
→ 의뢰서와 제작 조건 비교
→ 작업 가능 / 검증 필요 상태 분류
→ 확인·변경 이력 저장
```

### 상태값

| 상태 | 의미 |
|---|---|
| 작업 가능 | 필수 정보가 확인돼 다음 공정 진행 가능 |
| 검증 필요 | 정보가 애매하거나 작업자 확인 필요 |
| 외부 검증 요청 | 치과·거래처의 확인 필요 |
| 최종 확인 필요 | 소장·책임자의 판단 필요 |

### 포지셔닝

> ERP나 MES를 교체하지 않습니다. 기존 접수·관리 시스템과 CAD 작업 사이에 **얇은 검증 레이어**를 추가합니다.

---

## Slide 7. 기능 1 — 흩어진 정보를 하나의 케이스로 연결합니다

### 핵심 메시지

> 파일을 한곳에 저장하는 것이 아니라, 같은 환자와 작업에 필요한 정보가 함께 도착했는지 확인합니다.

### 주요 기능

- 의뢰서, STL·PLY 등 스캔 파일, 재료, 쉐이드, 임플란트 정보를 한 케이스에 연결
- 수취 채널과 도착 시점 기록
- 의뢰서만 있고 파일이 없는 상태 표시
- 파일만 있고 정식 의뢰서가 없는 상태 표시
- 중복 파일과 최신 변경본 구분
- 환자명·거래처·치아번호·작업 종류를 기준으로 매칭 후보 제시

### 사용자 가치

접수 담당자는 여러 플랫폼을 반복 확인하는 시간을 줄이고, CAD 작업자는 제작 조건이 연결된 상태에서 작업을 시작할 수 있습니다.

---

## Slide 8. 기능 2 — 제작 조건을 규칙 기반으로 검증합니다

### 핵심 메시지

> 초기에는 모든 것을 AI가 판단한다고 약속하지 않고, 현장에서 반복되는 검증 규칙부터 정확하게 적용합니다.

### 1차 검증 항목

- 정식 의뢰서 존재 여부
- 스캔 파일 도착 여부
- 환자명·치아번호·작업 종류 일치 여부
- 재료·쉐이드 필수 입력 여부
- 임플란트·스캔바디 관련 정보 확인 여부
- 거래처별 필수 체크 항목
- 변경 요청 반영 여부

### 개발 원칙

1. 규칙 기반 체크리스트로 시작
2. 실제 케이스에서 탐지율·오경보율 측정
3. 반복되는 패턴부터 자동 매칭 확대
4. 최종 제작 판단은 기공사의 전문 판단을 보조

### 제품 철학

> CrownOps는 기공사를 대체하지 않습니다. 기공사가 판단해야 할 케이스를 놓치지 않도록 돕습니다.

---

## Slide 9. 기능 3 — 위험한 케이스만 분리하고 검증 이력을 남깁니다

### 핵심 메시지

> 모든 케이스에 업무를 추가하는 것이 아니라, 확인이 필요한 예외만 빠르게 보이게 합니다.

### 예외 처리 흐름

```text
작업 가능 케이스 → 바로 다음 공정
검증 필요 케이스 → 작업자 확인
판단이 어려운 케이스 → 최종 확인 필요
거래처 확인이 필요한 케이스 → 외부 검증 요청
```

### 검증 리포트

- 어떤 정보가 언제 도착했는가
- 어떤 항목이 누락되거나 변경됐는가
- 누가 어떤 판단을 했는가
- 제작 시작 전 어떤 확인이 완료됐는가

### 기대 가치

| 이해관계자 | 가치 |
|---|---|
| 작업자 | 확인해야 할 케이스를 빠르게 찾음 |
| 소장·책임자 | 모든 케이스를 직접 검수하지 않아도 됨 |

**초기 SAM 가설: 약 700~1,400곳**

- 기공소별 예외 처리 흐름
- 기존 프로그램과의 연동 경험

> 단순 체크리스트는 복제할 수 있지만, 여러 현장에서 검증된 규칙과 오류 결과 데이터가 누적된 워크플로우는 쉽게 대체하기 어렵습니다.

# 6. 비즈니스모델

## Slide 13. 고객의 경제적 가치와 사회적 가치가 같은 방향으로 발생합니다

### 핵심 메시지

> 기공소가 비용을 절감할수록 현장 전문인력의 반복 노동과 재료 폐기도 함께 줄어드는 구조입니다.

### 가치 1 — 고객이 돈을 내는 이유

- 파일과 의뢰서를 찾는 반복 시간 감소
- 제작 전 누락·불일치 발견
- 잘못된 제작과 납기 지연 감소 가능성
- 책임자 검수 부담 감소
- 거래처와의 소통 근거 확보

### 가치 2 — 사회적 성과

| 사회문제 | CrownOps의 개입 | 측정할 지표 |
|---|---|---|
| 기공사의 반복 확인 노동 | 예외 케이스만 분리 | 케이스당 확인시간, 월 절감시간 |
| 무상 재작업·책임 부담 | 검증·변경 이력 기록 | 제작 전 수정 건수, 재작업 방지 건수 |
| 재료·배송 낭비 | 잘못된 제작 전 차단 | 절감 재료량, 방지 배송 건수 |
| 치과 재확인·환자 지연 | 누락정보 조기 확인 | 재문의 건수, 재내원 방지 추정 건수 |
| 지역 기공산업의 비표준 업무 | 검증 규칙과 교육 콘텐츠 축적 | 도입 기공소 수, 교육 참여자 수 |

### 임팩트 원칙

- 현재는 사회성과가 **발생했다**고 주장하지 않습니다.
- 파일럿에서 경제성과와 사회성과를 같은 데이터로 측정합니다.
- 사회적 가치가 고객의 비용 절감과 충돌하지 않아 구독형 사업으로 지속 가능합니다.

## Slide 14. 무료 프리체크로 손실을 보여주고, 구독으로 전환합니다

### 핵심 메시지

> 제품 설명으로 설득하는 것이 아니라, 고객의 실제 케이스에서 발견된 문제를 보여준 뒤 구매를 제안합니다.

### 1단계 — 20케이스 무료 프리체크

- 의뢰서·파일 도착 현황
- 누락·불일치 항목
- 외부 검증 요청 건
- 확인에 소요된 시간
- 예방 가능 손실 추정 리포트

### 2단계 — 4주 파일럿

- 실제 업무에 검증 단계를 적용
- 작업자·책임자 사용성 측정
- 탐지율·오경보율·확인시간 측정
- 유료 전환 의향 확인

### 3단계 — 월 구독

| 요금제 가설 | 월 요금 | 대상 | 핵심 기능 |
|---|---:|---|---|
| Starter | 15만원 | 소규모 디지털 기공소 | 케이스 통합, 필수항목 확인, 기본 리포트 |
| Pro | 30만원 | 다중 작업자 기공소 | 승인 흐름, 거래처별 규칙, 팀 권한 |
| Partner | 50만원 이상 | 대형·네트워크 기공소 | 채널 연동, API, 맞춤 규칙 |

가격은 확정값이 아니라 파일럿에서 검증할 가설입니다. 요금제는 직원 수보다 월 케이스 수, 사용자 수, 연동 범위에 따라 구분합니다.

### 고객 획득 흐름

```text
교수·학회·기공소 네트워크·커뮤니티
→ 무료 프리체크
→ 오류·손실 리포트
→ 4주 파일럿
→ 월 구독
→ 동료 기공소 추천
```

### 법적 경계

CrownOps는 특정 기공소에 환자나 주문을 알선하고 수수료를 받는 플랫폼이 아닙니다. 의뢰서를 대신 발행하지 않고, 기공소가 받은 정식 의뢰서와 제작 정보를 내부에서 확인하는 SaaS입니다. 의료기사법은 치과기공사가 치과의사가 발행한 제작의뢰서에 따라 업무를 수행하도록 하고, 영리 목적의 특정 기공소 고객 알선을 금지합니다.[^4]

- 전체 케이스 중 제작 전 예방 가능한 오류의 실제 비중
- CrownOps의 탐지 정확도와 오경보율
- 추가 업무 부담 없이 현장에 정착할 수 있는지
- 월 15만~50만원의 실제 지불의향
- 3개월 이상 반복 사용하는지

### 표현 원칙

> **문제 가설과 주요 오류 유형은 반복 확인했습니다. 제품 효과와 유료 전환은 실제 케이스 파일럿으로 검증해야 합니다.**

# 10. 클로징

## Slide 20. 현장 전문인력이 불완전한 정보와 책임을 혼자 떠안지 않도록 합니다

### 각인 메시지

> **CrownOps는 치과기공사의 일을 대신하는 기술이 아닙니다.**
>
> **현장 전문인력이 불완전한 정보와 불분명한 책임을 혼자 떠안지 않도록 돕는 제작 전 안전망입니다.**

한 건의 보철물에는 의뢰서, 스캔 파일, 재료, 쉐이드, 임플란트 정보와 여러 사람의 판단이 연결됩니다. 지금까지 이 연결은 작업자의 기억과 책임감에 의존해 왔습니다.

CrownOps는 제작 가능한 케이스와 검증이 필요한 케이스를 설계 전에 구분하고, 어떤 정보가 언제 확인됐는지를 기록합니다.

### 고객에게는

- 잘못된 제작 가능성과 재확인 비용을 줄이는 구독형 도구

### 현장 전문인력에게는

- 반복 확인과 책임 부담을 줄이는 업무 안전망

### 지역사회에는

- 소규모 전문 제조업의 디지털 표준화와 청년 전문인력의 현장 참여 기반

### 6개월 실행 약속

- 실제 기공소 3곳
- 누적 1,000케이스
- 예방 가능 오류와 절감액 실측
- 최소 2곳 유료 전환 검증
- 치과기공사 도메인 리드 영입

### 최종 요청

> **본 사업의 우수팀 선정을 요청드립니다.**
>
> 지원기간 동안 ‘발견한 문제’가 아니라 **실제로 방지한 손실과 줄어든 현장 부담**을 데이터로 증명하겠습니다.

# Appendix D. 예상 심사 질문과 답변

## Q1. 재제작률 10.1%를 CrownOps가 모두 줄일 수 있습니까?

> 아닙니다. 해당 수치는 임상 오류와 제작 오류를 모두 포함한 산업 전체 재제작률입니다. CrownOps는 그중 의뢰서, 파일, 재료 조건처럼 제작 전에 확인 가능한 오류만을 대상으로 하며, 실제 비중은 파일럿에서 측정합니다.

## Q2. 기존 관리 프로그램에 기능을 추가하면 끝나는 것 아닙니까?

> 기술적으로 일부 기능을 추가할 수 있습니다. 다만 기존 프로그램의 중심 업무는 접수·청구·공정관리입니다. CrownOps는 여러 채널의 정보를 묶고, 제작 시작 조건을 거래처·재료·임플란트 규칙으로 검증하는 업무를 제품의 중심으로 설계합니다. 초기에는 기존 프로그램을 대체하지 않고 보완재로 진입해 도입 저항을 낮춥니다.

## Q3. 치과가 정보를 정확히 입력하면 해결되는 문제 아닌가요?

> 장기적으로 정보 표준화가 필요하지만, 치과마다 사용하는 프로그램과 전달 방식이 달라 단기간에 행동을 통일하기 어렵습니다. CrownOps는 치과의 행동 변화를 선행 조건으로 두지 않고, 기공소가 이미 받은 정보를 제작 전에 확인하도록 합니다.

## Q4. 사회적 가치가 단순한 비용 절감과 무엇이 다릅니까?

> 비용 절감의 원인이 기공사의 반복 확인, 무상 재작업, 재료 폐기, 환자 일정 지연을 줄이는 데 있습니다. 고객이 경제적 이익을 얻는 과정에서 전문인력의 노동 부담과 환경적 낭비가 함께 줄어듭니다. 별도의 기부나 지원에 의존하지 않고 구독 매출과 사회성과가 같은 방향으로 발생합니다.

## Q5. 왜 지역 기반 사업이라고 볼 수 있습니까?

> 문제는 전국 공통이지만 초기 실행은 거점대학과 인근 치기공 교육기관·기공소를 연결하는 지역 실증 모델로 시작합니다. 지역 기공소의 업무 표준화, 지역 청년 기공사의 공동설계·채용, 교육기관의 현장형 체크리스트로 이어지는 구조를 만든 뒤 다른 지역에 확산합니다.

## Q6. 기공사 팀원이 없는 것이 가장 큰 약점 아닌가요?

> 맞습니다. 그래서 이를 숨기지 않고 핵심 영입 과제로 설정했습니다. 현재는 교수·현직 기공사·기공소 자문으로 문제를 좁히고, 파일럿 단계에서 검증 규칙 설계와 현장 온보딩을 책임질 치과기공사를 도메인 리드로 영입합니다. 한 명의 경험에만 의존하지 않고 복수 현장 데이터로 규칙을 검증합니다.

## Q7. 300만원으로 무엇을 증명할 수 있습니까?

> 완성형 플랫폼을 만드는 것이 아니라, 3개 기공소의 1,000케이스를 대상으로 누락·불일치 발생률, 탐지 정확도, 확인시간, 제작 전 수정 건수, 절감액과 유료 전환을 측정합니다. 지원금의 핵심 산출물은 기능 수가 아니라 고객검증 데이터와 첫 유료 전환입니다.
