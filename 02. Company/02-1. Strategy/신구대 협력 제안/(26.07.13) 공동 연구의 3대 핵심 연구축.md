### 요약

신구대에 가장 강하게 어필할 연구축은 **① 제작 전 Case Data Model·정합성 검증 ② 3D Scan QC·제작 가능성 판정 ③ Human–AI 공동 판단·교육**입니다.

기존의 **OCR/NLP는 ①의 구현 기술**, 일반적인 **AI/ML은 ③을 확장하는 기술 기반**으로 흡수하는 편이 제안서 구조상 더 강합니다.

세 축은 각각 **산업 표준화 → 기술 연구 → 교육·논문화**로 연결되어, CrownOps와 신구대 모두에게 결과물이 남습니다.

# 연구축 1. 제작 전 Case Data Model과 데이터 정합성 검증

## 핵심 연구 질문

> **“보철 제작을 시작하기 전에, 하나의 케이스에는 최소한 어떤 정보가 있어야 하는가?”**
> 
> **“의뢰서·3D 파일·재료 조건이 서로 일치하는지를 어떤 기준으로 검증할 것인가?”**

## 현재 연구가 해결한 부분

2023년 국내 치과 보철물 주문 플랫폼 연구에서는 치과 관련 종사자 53명을 대상으로 조사한 결과, **정확한 정보 입력, 효과적인 의사소통, 변형 없는 인상 전달, 데이터 전송·저장 편의성, 안정성과 경제성**이 중요한 요구사항으로 확인됐다. citeturn602754view2

이는 치과–기공소 사이에서 **정보가 정확하게 전달되어야 한다**는 필요성을 뒷받침한다.

그러나 연구의 중심은 대체로 다음에 있다.

```
정보 입력
→ 주문
→ 전달
→ 저장
```

CrownOps가 연구하려는 영역은 그 다음이다.

```
의뢰 정보
+ STL / PLY / OBJ
+ Upper / Lower / Bite 구성
+ 재료 조건
+ 임플란트·어버트먼트 정보
        ↓
하나의 Case Data Model로 연결
        ↓
누락·불일치·확인 필요 조건 검증
        ↓
PASS / CHECK / REQUERY
```

즉, **“정보를 전달했는가”가 아니라 “전달된 모든 정보가 실제 제작을 시작할 수 있을 만큼 완전하고 서로 일치하는가”**를 연구한다.

최근 치과 AI 연구에서도 현재 모델 상당수가 단일 데이터 모달리티에 머물러 있으며, 향후 연구 방향으로 **구강스캔·의료기록 등 서로 다른 데이터의 멀티모달 통합**이 제시되고 있다. 2010~2024년 치과·구강외과 ML 문헌 2,234건을 분석한 연구에서도 multimodal data와 foundation model이 향후 중요 연구 방향으로 제시됐다. citeturn836671view0

## CrownOps가 만들 수 있는 연구적 차별점

### 기존

> “치과 의뢰 정보를 잘 입력하고 전달하자.”

### 본 공동연구

> **“제작에 필요한 서로 다른 종류의 데이터를 하나의 케이스로 연결하고, 제작 가능 여부를 판단할 수 있는 데이터 구조를 만들자.”**

이 차이는 중요하다.

단순 OCR 정확도 연구도 아니고,

단순 전자 의뢰서 연구도 아니며,

단순 파일 관리 시스템 연구도 아니다.

**텍스트 정보와 3D 제조 데이터를 결합하여 실제 작업 전 의사결정을 가능하게 하는 데이터 모델 연구**가 된다.

# 연구축 2. 3D Scan QC와 ‘제작 가능성’ 판정

## 핵심 연구 질문

> **“이 스캔이 얼마나 정확한가?”를 넘어,  
> “이 데이터를 지금 실제 제작에 사용해도 되는가?”**

## 왜 성장성이 높은 연구축인가

구강스캐너와 디지털 치의학 연구 331건을 분석한 2024년 bibliometric study에서는 1998~2023년 해당 분야의 **연평균 연구 성장률이 15.9%**로 나타났다. 연구는 향후 과제로 다양한 임상 조건에서의 검증, 평가 방법 표준화, 어려운 조건에서의 이미지 품질 평가, workflow integration, error reduction 등을 제시했다. citeturn375825view0

또한 구강스캔 정확도는 단순히 스캐너 기기 하나의 성능만으로 결정되지 않고, 임상 조건과 스캔 방식 등 여러 요인의 영향을 받는다는 systematic review들이 계속 발표되고 있다. citeturn453993search0

즉, 학계에서는 이미 **정확도 문제**를 많이 연구하고 있지만 실제 제작 현장에서 필요한 질문은 조금 다르다.

### 기존 연구

```
Scanner A vs Scanner B
Trueness
Precision
Deviation
Scanning strategy
```

### CrownOps 공동 연구

```
이 파일을 제작에 사용해도 되는가?
        ↓
PASS
CHECK
RE-SCAN
```

## 연구적 차별점

### Device-level Accuracy

> 이 스캐너는 얼마나 정확한가?

### Case-level Production Readiness

> **이 특정 케이스는 현재 제작에 투입 가능한가?**

CrownOps는 후자를 연구 대상으로 삼을 수 있다.

이는 **측정값 연구를 실제 의사결정 연구로 전환**하는 것이다.

---

## 구체적 공동 연구 주제

### 1. Scan QC Taxonomy 구축

검증 후보:

- 파일 자체의 존재 여부
- Upper / Lower / Bite 구성 완전성
- 메시의 hole
- mesh discontinuity
- 불필요한 geometry
- 스캔 범위 부족
- margin 확인 가능성
- bite 관계 확인 필요
- scan body 관련 확인 필요

중요한 점은 처음부터 AI가 모든 오류를 자동 검출한다고 주장하는 것이 아니다.

먼저 교수진과 함께,

> **“실제 제작 전에 사람이 무엇을 보고 문제라고 판단하는가?”**

를 체계화하는 연구부터 시작하는 것이 타당하다.

---

### 2. 제작 가능성 3단계 기준 개발

|판정|의미|
|---|---|
|**PASS**|현재 데이터로 제작 진행 가능|
|**CHECK**|제작 가능할 수 있으나 전문가 확인 필요|
|**RE-SCAN**|현재 데이터로 안정적 제작이 어려워 재스캔 필요|

그리고 다음을 연구할 수 있다.

- 동일 케이스에 대한 전문가 간 판정 일치도
- 숙련도에 따른 판정 차이
- 오류 유형별 판정 차이
- AI와 전문가의 판정 일치도

---

### 3. 단순 정확도가 아닌 Actionable QC 연구

기존:

> deviation = 80 μm

CrownOps 방식:

> deviation 또는 결함이 확인됨
> 
> → **그래서 제작할 것인가?**
> 
> → **확인할 것인가?**
> 
> → **다시 스캔할 것인가?**

즉, **측정 결과를 실제 작업 행동과 연결하는 QC**다.

- PASS / CHECK / RE-SCAN benchmark dataset
- 학생 실습용 스캔 품질 평가 자료
- 향후 AI Scan QC 모델 학습 데이터

> **기존 구강스캔 연구가 ‘정확도’를 측정했다면, 신구대와 CrownOps는 ‘실제 제작 가능성’을 판단하는 기준을 만들 수 있습니다.**

# 연구축 3. Human–AI 공동 판단과 치기공 교육

## 핵심 연구 질문

> **“학생·교수자·AI는 동일한 케이스를 어떻게 다르게 판단하는가?”**
> 
> **“전문가가 암묵적으로 수행하던 제작 전 판단을 교육 가능한 기준으로 바꿀 수 있는가?”**

## 왜 신구대에 가장 직접적인 가치가 있는가

2025년 치과 AI 교육 scoping review는 547개 연구를 검토해 실제 조건에 맞는 실증 연구 17편을 분석했다. 연구 결과 AI는 진단, 평가, 피드백 등에 가능성을 보였지만, **복잡한 임상적 판단과 맥락적 역량 평가에는 한계가 있고**, 실시간 procedural assessment와 interactive case-based reasoning이 여전히 연구 공백으로 남아 있다고 정리했다. 또한 AI 개발에 치과 전문가의 주도적 참여가 부족하다는 점도 지적했다. citeturn602754view0

이는 CrownOps–신구대 협력과 매우 잘 맞는다.

CrownOps가 AI 모델만 만드는 것이 아니라,

```
학생 판단
+
교수자의 전문가 판단
+
AI 판단
```

을 함께 수집할 수 있기 때문이다.

---

## 기존 AI 교육 연구의 전형적 질문

> AI가 시험 문제를 잘 푸는가?
> 
> AI가 방사선 영상을 잘 판독하는가?

## 우리가 제안할 수 있는 질문

> **학생이 실제 제작 케이스를 보고 어떤 판단을 하는가?**

> **교수자는 왜 그 케이스를 제작 가능 또는 재문의 대상으로 판단하는가?**

> **AI는 어디에서 교수자와 다르게 판단하는가?**

이 구조는 단순한 AI 성능 평가보다 교육적 가치가 높다.

---

## 구체적 공동 연구 설계

### Step 1. 동일 케이스 제공

```

+
3D 파일
+
재료 조건
```

### Step 2. 독립 판정

```
학생      → PASS / CHECK / REQUERY
교수자    → PASS / CHECK / REQUERY
AI        → PASS / CHECK / REQUERY
```

### Step 3. 판단 이유 기록

예:

- 필수 정보 부족
- 스캔 범위 문제
- 파일 구성 문제
- 임플란트 정보 부족
- 제작 조건 확인 필요

### Step 4. 비교

연구 지표 예시:

- 학생–교수자 일치도
- AI–교수자 일치도
- 학생–AI 일치도
- 오류 유형별 오판율
- 학년·실습 경험별 판단 차이
- 교육 전·후 판정 정확도 변화

---

## 여기서 가장 중요한 연구 자산: ‘판단 근거 데이터’

일반적인 데이터셋:

```
Input → Label
```

신구대 × CrownOps 데이터:

```
Input
→ Decision
→ Reason
→ Reviewer
→ Confidence
→ Correction
```

즉,

> **“정답이 무엇인가”뿐 아니라  
> “전문가는 왜 그렇게 판단했는가”**

까지 데이터화할 수 있다.

이는 향후 설명 가능한 AI와 Human-in-the-loop 시스템으로도 연결된다. 치과·구강외과 ML 연구에서도 멀티모달 데이터, 의사결정 지원, 설명 가능성, 임상 검증은 주요 미래 연구 과제로 제시되고 있다. citeturn836671view0

- 케이스 기반 교육 콘텐츠
- 학생–전문가 판단 차이 데이터
- 제작 전 검증 교육 루브릭
