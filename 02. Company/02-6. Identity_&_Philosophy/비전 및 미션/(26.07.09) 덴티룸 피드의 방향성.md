맞아. **초반부터 밈/유머 계정으로 가는 것보다, 먼저 “치과계 정보 커뮤니티”로 신뢰와 팔로워 볼륨을 만든 뒤 그 안에서 나온 제보·해프닝·유머를 올리는 게 훨씬 좋다.**

처음부터 웃긴 계정으로 가면 팔로우 이유가 약해져.

“몇 번 웃기고 끝나는 계정”이 되기 쉽고, 치과인 입장에서는 너무 가볍거나 직군 조롱처럼 보일 수도 있어.

반대로 정보 커뮤니티로 시작하면 **저장·공유·팔로우 명분**이 생긴다.

> “이 계정 팔로우하면 치과계 흐름, 실무 정보, 직군 이야기, 업계 이슈를 볼 수 있네.”

이 인식이 먼저 생겨야 나중에 유머도 힘을 받는다.

# 덴티룸 방향 재정의

## 기존 방향

> 치과인 웃픈 일상·썰 계정

## 수정 방향

> **치과계 사람들이 함께 보는 정보형 커뮤니티**

조금 더 정확히는:

> **치과의사·치위생사·치기공사·학생이 함께 보는 치과계 실무 정보와 현장 이야기를 모으는 커뮤니티**

이게 훨씬 오래 간다.

# 콘텐츠 비율

초반에는 이렇게 가는 게 좋아.

|콘텐츠 유형|비율|역할|
|---|---|---|
|정보형 콘텐츠|60%|저장/공유/신뢰 확보|
|직군 이해 콘텐츠|20%|치과의사·위생사·기공사 연결|
|참여형 콘텐츠|10%|댓글·DM 제보 유도|
|유머/공감 콘텐츠|10%|계정의 인간미 유지|

나중에 팔로워가 쌓이면 유머 비중을 25~30%까지 올려도 돼.

근데 초반에는 **정보로 들어오게 만들고, 유머로 머물게 만드는 구조**가 맞아.

# 두 번째 피드 추천

두 번째 피드는 이걸로 가는 게 좋아.

## **“보철물 하나가 만들어지는 과정”**

왜 이게 좋냐면, 덴티룸의 타깃인 치과의사·치위생사·치기공사·학생을 전부 자연스럽게 묶을 수 있어.

치과 쪽은 진료/스캔/의뢰를 이해하고,

기공소 쪽은 디자인/제작/납품을 이해하고,

학생들은 전체 흐름을 배울 수 있어.

그리고 너희 CrownOps가 보는 문제인 **치과-기공소 간 정보 전달, 의뢰서, STL, 쉐이드, 재료 조건**과도 자연스럽게 연결돼.

하지만 제품 홍보처럼 보이지는 않음.

---

# 두 번째 피드 캐러셀 구성

## 1장

```
보철물 하나는
어떻게 만들어질까?
```

작게:

```
치과와 기공소가 함께 만드는 과정
```

---

## 2장

```
1. 진료 계획
```

본문:

```
어떤 보철물이 필요한지
치아 상태, 위치, 재료, 치료 계획을 정합니다.
```

---

## 3장

```
2. 프렙 / 스캔 / 인상
```

본문:

```
치아를 형성하고
구강스캔 또는 인상채득으로
제작에 필요한 데이터를 만듭니다.
```

---

## 4장

```
3. 의뢰 정보 전달
```

본문:

```
치아 번호, 보철 종류, 재료, 쉐이드,
임플란트 정보 등이 기공소로 전달됩니다.
```

강조:

```
여기서 정보가 빠지면 제작 전 확인이 필요합니다.
```

---

## 5장

```
4. 디자인 / 제작
```

본문:

```
기공소에서는 전달받은 정보와 파일을 바탕으로
CAD 디자인, 밀링/프린팅, 후처리 과정을 진행합니다.
```

---

## 6장

```
5. 확인 / 납품 / 장착
```

본문:

```
완성된 보철물은 치과로 전달되고,
환자 구강 내에서 적합·교합·색조 등을 확인합니다.
```

---

## 7장

```
보철물은
한 사람이 아니라
여러 치과인이 함께 만듭니다.
```

마무리:

```
치과계 실무 흐름을 쉽게 정리하는 곳,
덴티룸
```

---

# 캡션

```
보철물 하나는 혼자 만들어지지 않습니다.

치과에서는 진료 계획을 세우고,
프렙·스캔·인상채득을 하고,
치아 번호, 재료, 쉐이드, 임플란트 정보 등을 기공소에 전달합니다.

기공소에서는 그 정보를 바탕으로
디자인, 제작, 후처리, 납품 과정을 진행합니다.

그래서 치과와 기공소 사이의 정보 전달은 정말 중요합니다.
작은 누락이나 불일치도 다시 확인, 수정, 재제작으로 이어질 수 있기 때문입니다.

덴티룸은 치과계 사람들이 함께 이해하면 좋은
실무 흐름과 현장 이야기를 쉽게 정리합니다.

다음에는 어떤 주제를 다뤄볼까요?
```

# 앞으로의 게시물 방향

초반 10개는 이렇게 가면 좋아.

|순서|주제|목적|
|---|---|---|
|1|덴티룸 소개|계정 정체성|
|2|보철물 하나가 만들어지는 과정|정보 커뮤니티 포지션|
|3|치과에서 자주 쓰는 용어 정리 1탄|저장 유도|
|4|치과의사·치위생사·치기공사는 각각 어떤 일을 할까?|직군 이해|
|5|구강스캔과 인상채득 차이|학생/실무 정보|
|6|쉐이드가 중요한 이유|치과-기공소 연결|
|7|치과기공소는 무슨 일을 할까?|기공소 인식 개선|
|8|치과 실습생이 알아두면 좋은 기본 용어|학생 타깃|
|9|치과계에서 자주 생기는 소통 오류|문제 공감|
|10|덴티룸 제보 받습니다|커뮤니티 전환|

# 중요한 운영 원칙

덴티룸은 초반에 **“밈 계정”이 아니라 “가볍게 읽히는 치과계 정보 계정”**으로 보여야 해.

문체는 너무 딱딱하면 안 되고, 이런 톤이 좋아.

> 어렵게 설명하면 논문 같고, 너무 가볍게 말하면 밈 계정 같다.
> 
> 덴티룸은 “치과계 실무를 쉽게 풀어주는 사람”처럼 말해야 한다.

결론적으로 네 판단이 맞아.

**정보로 신뢰를 만들고, 볼륨이 생긴 뒤 팔로워 제보 기반 유머를 얹는 전략**이 훨씬 오래 간다.
