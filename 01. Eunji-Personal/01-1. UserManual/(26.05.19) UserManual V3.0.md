**1.** **왜 움직이는가**

|   |   |
|---|---|
|**철학**|오래보다 깊게. 축적보다 흔적|
|**남기고 싶은 것**|무형적 유산 — 기억, 영향, 인과|
|**지키고 싶은 것**|선하고 약한 존재들|
|**돈의 위치**|삶을 지속하게 할 수단. 넘치면 더 큰 가치로 돌려야 함|
|**살아있는 감각**|치열하게 무언가를 할 때. 성과를 이룰 때|

|   |
|---|
|_야망이 없는 게 아니다. 야망의 방향이 축적이 아니라 흔적이다._|

**2.** **두 개의 나**

대부분의 사람은 한 쪽 면만 본다.

|   |   |
|---|---|
|**처음 보는 사람이 보는 나**|**친한 사람이 보는 나**|
|어른스럽고 나이스함|친근하고 장난기 많다|
|강하고 결단력 있음|장난기 많고 애처럼 굶|
|논리적이고 직접적|유치한 장난 치고 같이 노는 사람|
|리더|글라스 데코 사서 노는 사람|

|   |
|---|
|_친해지기 전까지 두 번째 열은 보이지 않는다. 두 번째 열을 보게 됐다면, 신은지가 당신을 믿는다는 신호다._|

**3.** **일상의 질감**

**좋아하는 순간들**

•  아침에 잠에서 깰 때 — 오늘 뭘 배울지 설레는 그 순간

•  커피 내릴 때

•  목욕 후 이불에 들어갈 때

**순수하게 즐기는 것들**

음악(장르 안 가림) · 게임(건축 및 모험) · 그림 그리기 · 뭔가 만들기 · 앤틱한 그릇·찻잔 수집 · 철학적 대화 · 창업

**기분 좋을 때 신호**

장난을 많이 친다. 기분이 좋은 티가 많이 난다.

**수면 패턴**

주중 수면 부채를 주말에 몰아서 해소한다. 주말 오전 연락이 늦을 수 있음. 업무적 이슈가 아니라, 그냥 신은지를 이해하는 정보로 알아두면 된다.

**4.** **작동 방식**

|   |   |
|---|---|
|**✅**  **이럴 때 잘 작동한다**|**❌**  **이럴 때 힘들다**|
|✓  혼돈과 불확실성 — 정해진 게 없을수록 에너지 올라감|✗  통제당하는 느낌 (이유 설명해주면 수용 가능)|
|✓  선례 없는 일 — '아무도 못 한 것'에서 가장 강하게 작동|✗  할 수 있는데 안 하려는 사람 — 의지 부재|
|✓  제품 만들 때 — 완전한 몰입 상태|✗  감정으로만 대응 (감정+논리 연결해주면 됨)|
|✓  혼자 집중 → 의견 나누기 순서|✗  에둘러 말하기 — 불편해도 직접 말해줘|
|✓  격렬한 토론 — 토론 ≠ 갈등. 반박 환영|✗  책임 회피 — 직면 피하는 것 납득 안 됨|
|✓  자율성 보장 환경 — 맥락과 방향을 주면 알아서 함|✗  피상적이거나 근거 없는 말 반복|

**5.** **일하는 방식  ★ UPDATED**

|   |   |
|---|---|
|**작동 원리**|**설명**|
|데이터 중심|주관적 판단보다 데이터로 먼저 검증한다. 감이 아니라 근거로 움직인다.|
|연구적 문제 분석|자료·데이터를 먼저 수집하고 구조화한 뒤 접근한다. 감으로 판단하기 전에 구조를 먼저 잡는다. 피상적인 설명은 납득이 안 된다.|
|과업의 의미|의미가 없으면 동기부여가 안 된다. 설명 없이 일이 주어지면 에너지가 안 붙는다. 왜 이 일을 하는지 납득이 돼야 제대로 움직인다.|
|문서화 습관|모든 작업과 의사결정은 노션에 기록. 출처와 링크를 반드시 남긴다.|
|AI 활용 관점|반복 업무는 AI에게. 인사이트·아이디어는 인간의 영역이다.|
|AI와 나의 역할 구분|AI만큼의 배경지식을 갖추고, 그 위에서 통찰·고뇌하는 것이 내 역할이다.|
|창업 방향성|AI 이전엔 접근 어려웠던 도메인 + AI로만 가능한 혁신 솔루션의 교차점에 기회가 있다.|

|   |
|---|
|_AI__는 반복을 잘 한다. 하지만 인사이트는 결국 사람의 것이다. AI 만큼 알아야 AI를 넘을 수 있다._|

**6.** **화가 났을 때**

|   |
|---|
|_바꿀 수 있으면 행동한다. 바꿀 수 없으면 삼키고 반면교사한다._|

감정을 무작정 표현하거나 무작정 삼키지 않는다. 바꿀 수 있는지 먼저 판단한다. 이게 기준이다.

**7.** **질투와 경쟁**

|   |   |
|---|---|
|**이 사람을 보면**|**반응**|
|좋은 사람이 잘되거나 운이 좋음|부러움을 표현하고 배우려 한다|
|그렇지 않은 사람이 잘됨|질투난다. 속으로 시기한다|

_솔직하게 인정한다. 숨기지 않는다._

**8.** **소통법**

|   |   |
|---|---|
|**✓**  **잘 통하는 말**|**✗**  **막히는 말**|
|✓  "이 방향 맞는 것 같은데 네 생각은?"|✗  "그냥 이렇게 해"|
|✓  "이게 걱정돼서 — 왜냐하면 ___"|✗  "느낌이 좀 그래" (이유 없음)|
|✓  "네 판단이 맞았어"|✗  "잘했어" (이유 없는 칭찬)|
|✓  반박할 거면 논리로|✗  감정으로만 반박|
|✓  구체적인 데이터나 사례와 함께|✗  "그게 뭔지는 모르겠는데..." 식의 두루뭉술한 표현|
|✓  왜(Why)와 어떻게(How)를 구체적으로|✗  의미 설명 없이 일 시키기|

**9.** **인정 방식**

|   |   |
|---|---|
|**이게 아니라**|**이게 닿는다**|
|"잘했어"|"네 판단이 맞았어"|
|"고생했어"|"이게 되네"|
|결과만 본 칭찬|맥락을 알고 하는 말|
|처음 본 사람의 칭찬|오래 지켜본 사람의 한 마디|

**10.** **강압적으로 보일 때**

**언제 나타나나**

•  답답함이 올라올 때 → 말 짧아짐, 톤 강해짐

•  결론이 보이는데 상대가 못 따라올 때

•  내 기준의 "당연한 것"을 상대가 안 할 때

•  피상적이거나 근거 없는 말이 반복될 때

•  과업의 의미를 모르고 형식적으로 움직이는 것 같을 때

**이럴 때 나에게 할 말**

|   |
|---|
|_"__지금 좀 강하게 느껴져."  한 마디면 된다. 방어 안 한다. 듣는다._|

_나는 내가 얼마나 강하게 느껴지는지 둔감하다. 숨기지 말고 그냥 말해줘._

**11.** **스트레스 신호**

|   |   |
|---|---|
|**신호**|**실제 상태**|
|말이 짧아짐|소진 중|
|냉정해짐 · 분석 모드|화난 게 아닐 수 있음|
|혼자 있으려 함|충전 필요|
|주말 오전에 연락이 안 닿음|수면 부채 해소 중. 정상 상태임|

|   |   |
|---|---|
|**✅**  **이럴 때 잘 작동한다**|**❌**  **이럴 때 힘들다**|
|✓  "괜찮아?" 한 마디|✗  더 많은 일 밀어넣기|
|✓  혼자 있을 공간|✗  "왜 그래?" 추궁|
|✓  그냥 옆에 있어주기|✗  감정적으로 반응|

**12.** **오해 vs 진실**

|   |   |
|---|---|
|**오해**|**진실**|
|감정이 없다|드러내기 낯선 것. 없는 게 아님|
|항상 강하고 진지하다|친한 사람 앞에선 애처럼 군다|
|무능력을 싫어한다|의지 부재를 싫어하는 것|
|혼자 다 하려 한다|혼자 해온 경험이 많아서. 연습 중|
|성과만 중요하다|좋은 사람이고 싶다는 것도 진심|
|AI에 의존적이다|AI는 도구. 인사이트와 고뇌는 내가 한다|
|일이면 의미 없어도 한다|왜 하는지 납득이 돼야 제대로 움직인다|
